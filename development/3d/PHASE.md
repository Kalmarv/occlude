# Source-chain modifier phase

Constructed 3D runs now retain a shared immutable reference polyline, its cumulative paper arclength and their selected source intervals. Source topology, selected features, deterministic chaining and corner rules define that reference before visibility and style-range cuts. Different line sets can keep different chaining recipes. A visibility cut cannot change a reference orientation or make an ambiguous source junction connect.

The paper adapter groups intervals by reference and named pen. The ordinary shape pipeline receives the complete reference plus `strokeRanges`, expressed as segment index plus projected fraction. Fractions are measured after projection, including perspective foreshortening; they are not world-space segment parameters. Existing ordered post modifiers evaluate the full source. Propagated run coordinates trim their output to selected source intervals, followed by ordinary paper clips, masks and occluders. Neither hidden distance nor paper cropping restarts dash phase or wobble sampling. Removed intervals remain protected through routing. Cleanup uses only selected geometry as coverage, so an invisible reference cannot erase another mark. Source selections also refuse new optimization connectors that would need a 3D visibility certificate.

`strokeRanges` is a generic polyline drawing option. It requires one polyline without a fill or topology-changing pre-stage modifiers. Empty ranges select no ink; invalid/overlapping/out-of-bounds intervals are rejected. Ordinary shapes without the option retain their existing behavior. Selected polylines bypass early geometric culling so bounded displacement can enter the page; they still clip to the page after styling. This conservatively evaluates complete source polylines and has not yet been benchmarked at the M5 workload.

The shared scene protocol retains the existing u32 shape and primitive strides. Scenes with source selections use shape f64 records of stride 5: z, bridge, native spacing, source-range tape offset (-1 absent), range count. Range pairs occupy the f64 tape outside modifier instructions. Ordinary scenes retain their stride-3 encoding unchanged; the Rust decoder also accepts legacy stride-2 buffers. A WASM test compares ordinary stride-3 output with its equivalent stride-5 encoding. TS encoding and Rust decoding change together.

Near/far clipping still defines the available reference anchor; geometry behind the eye is not projected. Persistence, source-linked picking, stable seeded per-source decimation identity and the remaining M2–M5 requirements are not claimed here.
