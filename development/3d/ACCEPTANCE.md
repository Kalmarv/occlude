# M0–M5 acceptance audit

Scope: the original [specification](spec.md), byte-identical to the user's `working/3d.md`, plus explicit [user deferrals](USER-FOLLOWUPS.md). Audited implementation: `20347d9`, incorporating the paper-budget fix `566070e`. This document distinguishes implemented requirements from deferred requirements and measured limitations. Historical milestone notes describe their commit's state; this audit and [handoff](HANDOFF.md) supersede their old “pending” statements.

The tables below map the specification's clauses to inspected implementation and concrete assertions. `packages/occlude/test/` is abbreviated **library tests**; **Studio tests** are under `packages/occlude-studio/src/`. Tests are evidence for their assertions, not proofs for arbitrary floating-point geometry.

## Ownership, coordinates and procedural operations (§6–9)

| Requirement | Inspected implementation and assertion |
| --- | --- |
| Four distinct data layers | Editable `Surface3`; immutable `lineArt3`/feature snapshot; `ClassifiedScene3`/`Stroke3`; existing Execution/recorded plan. Capture serializes data, not callbacks or GPU objects. `three-selection`, `three-style`, `three-capture`/Studio capture tests verify ownership and round trips. |
| Explicit persistent GPU host, one worker, reusable leases | `GpuSceneCompute3` is passed into async execution; lazy device/pipelines and serialized resource tail. Same render worker handles modeling, interval visibility and retained construction. OffscreenCanvas stays worker-owned; only ImageBitmaps cross to UI and stale images close. No GPU structured cloning. |
| Cache dependencies | Scene construction captures geometry/membership/generators. Same captured scene shares pending/completed classification inside one Execution (`three-style`: call count 1). A new scene rebuilds dependent snapshot; retained camera commit reclassifies only changed scene and does not regenerate model (`three-camera-commit`). All resolved pens participate in precision budget; paper/camera belong to execution. Hatch addition creates new captured candidates. No global active scene. |
| Snapshotting mutable inputs and owned readback | `lineArt3` freezes/copies geometry, transforms and attributes; selections snapshot domains; GPU submission copies arrays, readback copies before unmapping. Tests mutate source positions/attributes/transforms and verify prior values unchanged. Eight interleaved executions compare exact standalone geometry/SVG and captured inputs. |
| Coordinates and projection | RH Z-up world, scene units independent of paper, negative camera Z, positive near/far, vertical span/FOV, [0,1] depth. `three-visibility` checks near=0/far=1 depth, y-down paper, clipping before division and invalid eye/up/span; `three-scene` compares actual 2D primitives under margins/origin/yUp and explicit perspective viewport. |
| Polygon/triangle distinction | Deterministic normalized ear clipping, robust orientation/crossing tests; source triangles retain face identity. Concave L area=5 and four triangles; planar diagonal suppressed; deformed quad retains its diagonal only for an actual facing transition. Nonplanar initial polygons, winding conflicts, crossings/touches, invalid indices and >2-face edges diagnose. Holes are unsupported by the simple polygon input. |
| Normal transforms and mirrors | Transform positions then recompute geometric normals; reverse winding for negative determinant. `three-model` asserts outward signed volume under rotation/nonuniform negative scale; `three-selection` compares transformed-instance and explicitly transformed mesh snapshots; hatch/precision tests cover mirrored views. |
| IDs and attribute domains | Point/edge/face IDs and attributes are distinct; source operation/parent/ordinal names new elements. Tests preserve unchanged IDs, cap/side parentFace, edge parentEdge and marked values; extensive mass total stays 12 while labels copy. Incident face attributes remain separate; scalar point interpolation stays explicit in curve support data. No corner/UV parity claim. |
| Selections and state-bound edits | Face normal/area/attribute/adjacency filters; point position/boundary/attribute and edge adjacency/length filters. Group/union/map share relational conventions. Old-state selections and cross-capture unions throw. A throwing edit leaves original geometry unchanged. |
| Frozen passes | `stepsSurface3` freezes each prior input, commits ordered output, supports deterministic count/bounded history. Test sees prior heights [0,1,2,3], history [3,4], and rejects stale extrusion selection. |
| Independent extrusion semantics | Selected cap replacement, translated private vertices, perimeter side faces, untouched shared input vertices; positive/negative distance volume checks, zero deep-copy/no topology change. Adjacent independent extrusions reject as nonadjacent-required, rather than silently deleting coincident walls. |
| GPU procedural batch | CPU evaluates arbitrary callbacks; explicit fixed-topology displacement and gather CSR adjacency use ping-pong GPU buffers across iterations. CPU reference checks exact neighbor order/pins and translation equivariance. Hardware demos assert actual dispatch counts, changed geometry and same-seed repeatability. No arbitrary JS-to-WGSL compilation or per-scalar dispatch. |
| Queries | Prepared ray/segment/nearest batches carry source face, barycentrics and distance. CPU tests cover both sides, clipped segment t, no-hit, face/edge/vertex nearest, ties, rotated index vs all triangles, empty/invalid inputs. Hardware relief verifies a query changes 16 vertices before subsequent drawing. |
| Async API and ordinary 2D | Additive sketchAsync/compileSketchAsync/renderAsync; sync entry points reject async scenes explicitly. Per-execution toolkit and single-use lifecycle; closed toolkit use rejects. No adapter request on CPU import/path. Existing stable non-3D docs ink and church toolpath remain unchanged. |
| Cancellation and publication | CANCELLATION-ISOLATION.md/robustness/report.json: upload, dispatch, readback, pre-refinement abort; 513-pair control after each, queued middle abort, zero explicit buffers after disposal, failed generation, prior export and eight interleaved cases. Final Playwright adoption report holds successful obsolete render/camera replies, then fails replacement: no accept, explicit discard, exact prior plan/SVG preserved. Synchronous JS cannot process new cancellation messages until it yields. |
| Committed camera/output | Camera exploration changes neither model seed nor committed plan; explicit Commit view captures camera overrides in configuration. Final construction/camera-commit/camera-config/persistence reports verify no remodeling, changed camera output, portable download and prior-result preservation. Saved plan remains export/timing authority. |

## Rendering, strokes, hatch and physical output (§10–14)

| Requirement | Inspected implementation and assertion |
| --- | --- |
| Feature categories/provenance | Original boundaries, geometric creases, facing silhouettes, marked edges, wire, section, hatch; all flags retained without default duplicate ink. Box test has 12 source edges, no artificial boundaries, 6 silhouettes, marks+crease overlap; flat ground has 30 exactly non-crease edges across cameras; real 1e-10 fold survives. Crease API artistic threshold remains user-deferred. |
| Line sources versus occluders | Separate `lineSource`/`occluder`; mesh test line-disabled front plane hides wire [.25,.75], occluder-disabled plane does not. Two-sided triangle rule and reversed-winding visibility tested. Support provenance excludes own support only, not whole object; cube self-hidden edges and hatch on blocked same-source surfaces tested. |
| Classified graph and selections | Immutable frame/features/support IDs/flags/crease angles/attrs/visible-hidden ranges/source parameters; FeatureSelection3 explicit snapshot ownership, filter/group/union. Distinct face labels remain inspectable rather than averaged. Constructed Stroke3 retains source/points/parts/length/arclength/breaks and can be reinterpreted with ordinary supported modifiers. |
| Overlapping styles | Priority and stable set-ID tie break own intervals; partial overlap [.25,.75] leaves both residual outer ranges; input set reorder unchanged; explicit overdraw adds authored ink. A multi-flag feature is emitted once per set. |
| Chain/split/filter | Same source/style/visibility and topology endpoint compatibility; screen crossings/unrelated endpoints do not join. Ambiguous branch test stops three chains; cornerDegrees splits; closed-loop start/orientation stable under permutation; three short segments qualify as one 3 mm chain before minLength=2 filtering. |
| Phase and random identity | Source reference/intervals survive visibility and paper crop. `three-phase` checks eight exact dash extents through a box and actual wasm_plan_svg. Rust source-selection tests compare dash/wobble stack orders/cropping, protect 0.00008 mm gaps and off-page wobble, and prevent invisible reference coverage erasing unrelated ink. `three-style-identity` verifies actual planned survivors under row reorder/source removal and pass/seed changes. |
| Modifier domains/limits | Model transforms/deform rebuild surfaces; support-attached hatch/sections require same captured surface; paper modifiers deliberately stylize after visibility. Source-range adapter rejects fills/topology-changing pre-stage modifiers and invalid ranges; full finite reference is retained for bounded overscan, then final 2D clipping applies. No unbounded new modifier API, shader texture, alpha/pressure or raster edge tracing masquerades as vector output. |
| Clipping and robust broad phase | Segment/triangle near/far clipping precedes projection; original source ranges and support retained, no synthetic visible cut edges. Expanded projected f64 BVH bounds, nonfinite projection diagnostic, streamed candidate capacity. Mesh tests compare indexed output with all triangles in both cameras on overlap/thin geometry and retain off-page features. |
| Pairwise visibility and union | Normalized f32 half-space kernel returns hidden parameter interval plus uncertainty; independent f64 robust-predicate oracle refines flagged cases. No atomic append ordering, object-depth sort or ray sampling in final visibility. Stable unions/complement retain positive gaps; cross-batch near-touch refinement distinguishes true contacts and tiny gaps. |
| Precision and completeness | 36 shared analytical CPU/GPU cases plus four paper/nib negative controls; see PRECISION-CASES.md and PAPER-PRECISION.md. Cases include scale 1e-9/1e9, offset 1e12, coplanarity, contacts, thin shadows, overlap, mirrors, eye crossing, near split, strong depth slope, zero wire. Other tests cover empty/capacity/source-only/self-support and independent rays. Runtime uses physical nib/paper bound; topology never intentionally merges by visual tolerance. Numeric limits and separate 0.005 mm input snap displacement documented, not arbitrary-magnitude guarantees. |
| Viewport | Retained world GPU vertex/instance buffers, uniform camera updates, depth-tested two-sided triangles and quad-expanded wires. Source-face BVH picking returns original object/face/attributes/barycentrics. Final construction report proves orbit/zoom/reset/pick keep render count and SVG/plan unchanged; performance reports distinguish worker rate from presented FPS. |
| GPU infrastructure/timing | Lazy feature/limit checks, bounded batches and reusable staging; timestamp-query optional with 32-byte explicit budget reserve and 16-byte transfer per pass. Hardware timed/untimed/min-budget/hidden-feature tests verify repeated readback and disposal. No unconditional timestamp requirement; hidden-feature test is capability simulation on one adapter. |
| Hatch/crosshatch | Required physical view-dependent paper lattice lifted to supporting triangles; one family across triangulated face. Tests assert seven full 80 mm rows, two parts per row without seams, 14 crosshatch rows, preserved 10 mm spacing under zoom, folded/perspective barycentric reconstruction, near clipping/mirrors/edge-on omission, attributes and actual occlusion. Capacity/stale support errors explicit. |
| Sections | Mesh-plane intersections with captured support and plane/face attributes, coplanar boundary/duplicate handling, stable chaining and explicit tolerance/capacity. Tests and relief verify section heights and shared realized surface; box-box intersection curves remain later scope. |
| Existing paper/pen/plan semantics | Physical named pens feed existing recording/WASM/planning/SVG/G-code; full pen feed/lift/delay preserved. Protected ordered runs prohibit invented gap bridges but allow normal tour ordering/reversal. Imperial composition tests Letter dimensions, two imported colors/one-off pen, mask/labels and portable definitions. One existing timing model; no physical plotter run. |
