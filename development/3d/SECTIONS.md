# Plane-section contours (M4 in progress)

`section3(surface, planes, options)` intersects the fixed source triangulation in model coordinates and returns an owned frozen surface plus inspectable, source-supported segments. Scene objects pair `surface: curves.surface` with `curves`; mismatched sources are rejected before capture or classification. Instance transforms move both geometry and barycentric curve positions together, including mirrored winding. Plane attributes and supporting face attributes reach classified features; `FeatureKind3.section` permits downstream selection without another visibility dispatch.

Topology supplies endpoint IDs. Adjacent triangle pieces chain across artificial diagonals. Different planes have independent endpoint namespaces. Coplanar patches contribute only their boundary; duplicate shared edges are emitted once, while isolated tangencies produce no line. Concave faces and folded fixed triangles use the same triangle intersection. The zero-distance policy is an explicit model-unit tolerance, defaulting to 64 machine epsilons times the greatest mesh coordinate relative to the plane origin. Intermediate segment candidates are bounded (one million by default), with an actionable capacity error rather than dropped curves.

The captured curve representation retains endpoint positions and source barycentric weights, supporting triangle indices and generated attributes. Validation rejects invalid support, inconsistent endpoint IDs, nonfinite or invalid weights, and positions inconsistent with their source weights. The visibility snapshot maps support to the same occluder IDs as mesh features. Other faces of the same mesh remain valid occluders. The ordinary classified-stroke, phase, pen, clipping, planning and SVG paths remain shared.

Tests cover the exact central cube perimeter, closed chaining across triangulation, coplanar boundaries, tangent/no-hit planes, oblique hexagon lengths across 1e-9 to 1e9 scales, normal reversal, concave and folded faces, mirrored instance placement, same-object visibility, captured attributes, stale/invalid source rejection and candidate limits.
