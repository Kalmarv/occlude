# Main Studio construction view

The main Studio now exposes a **3D** toggle when the current execution contains captured line-art scenes. Its scene menu, drag orbit, scroll zoom, camera reset/copy and click-to-inspect controls operate on the realized source geometry retained by the render worker. A picked face exposes its original object/face identity, source attributes, world position, triangle and barycentric weights. Transformed and mirrored instances retain their source identity.

The worker lazily prepares each requested construction scene once. Mesh triangles and authored mesh/wire edges stay in worker memory. Camera interaction projects that retained world geometry and uses a depth-tested `GpuViewport3` on the same lazy `GpuSceneCompute3` device as modeling and visibility. The host renders into an owned OffscreenCanvas and transfers only the completed ImageBitmap. No GPU object or scene geometry crosses to the main thread. Unadopted bitmaps are closed.

The panel permits one request in flight and keeps only the latest desired camera. Replies are adopted only for the current view revision. Worker requests also name the execution that owns the geometry; an obsolete execution is rejected. The existing worker queue serializes construction, rendering and plan export. Replacing/restarting the worker does not require retransferring a DOM canvas. The next successful sketch render supplies fresh construction metadata. Pole-clamped orbit respects the captured up axis; picking uses world-space surface BVHs and the camera's near/far depth interval.

The construction preview is separate from committed paper output: orbiting performs no modeling, surface-query compute or visibility dispatch. It does not mutate the drawing plan. Copy camera returns explicit values for use in sketch source. Committing a view through retained drawing composition, saved camera/model/backend provenance and the full changed-library persistence round trip remain unfinished. Surface picking currently inspects faces; richer point/edge/stroke selection and edit gestures remain to be audited against the full spec.
