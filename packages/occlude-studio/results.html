occlude·results
Studio Sketches Fills Machine Docs

A saved result is a chosen ordered drawing kept as resolved output: the selected chains as exact plan bytes, the frozen SVG of that selection, and the settings that made it. It shows, exports and plots later without running the sketch — changing the source, the pens or the machine never changes what was kept. Only the selection is saved, so a reopened result cannot grow back into the rest of the plan.
