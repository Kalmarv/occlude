---
title: Slack
description: A net hung from three nails, where every thread has a rest length of its own.
---

Three nails hold a lattice at its top corners and its middle. Everything else falls. Each thread carries a rest length of its own. A noise field gives it, read at the thread's own middle. `smooth` then gathers the slack into broad bands. Tension pulls a thread only by the part of its length beyond that rest. A short rest holds the weave tight. A long one lets it sag.

That second step is what makes this a drawing. The raw field gives neighbouring threads unrelated rests, and the net hangs in a crumpled hash. Fourteen passes over the edge column make regions the eye can follow.

The threads with the most slack take a heavier pen. You can then see where they run. The hem is the result: it dips where the slack gathers.

Uses: `material` with `withEdges`, `edgeAttribute` reading `e.center`, and `m.smooth` on an EDGE column. Then `steps` with `next.move` over a selection, `force.tension` with a rest for each edge, `force.sum`, `extent`, `edges.subtract` and `strokes`.

```ts live
import { sketch, strokes, circle, material, force, mul, extent } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 3 }, (t) => {
  const b = t.bounds();
  const cols = 36, rows = 18;
  const gap = (0.84 * b.w) / (cols - 1);
  const x0 = 0.08 * b.w, y0 = 0.075 * b.h;
  const pts = [];
  const edges = [];
  for (let r = 0; r < rows; r++) for (let c = 0; c < cols; c++) {
    pts.push([x0 + c * gap, y0 + r * gap]);
    const i = r * cols + c;
    if (c > 0) edges.push([i - 1, i]);
    if (r > 0) edges.push([i - cols, i]);
  }
  const nails = new Set([0, (cols / 2) | 0, cols - 1]);
  const net = material(pts).withEdges(edges)
    .edgeAttribute('rest', (e) => gap * (1 + 0.8 * t.noise(e.center[0] / 34, e.center[1] / 34)))
    .smooth('rest', { steps: 14 });
  const hung = net.steps(300, (cur, next) => {
    const pull = force.sum(force.tension(cur, { rest: (e) => e.rest }), () => [0, 0.42 * gap]);
    next.move(cur.points.filter((p) => !nails.has(p.index)), (p) => mul(pull(p), 0.1));
  });
  const [lo, hi] = extent(hung.edgeAttrs.rest);
  const slack = hung.edges.filter((e) => e.rest > lo + 0.62 * (hi - lo));
  return [
    strokes(hung.edges.subtract(slack), { pen: 'pigma-005-black' }),
    strokes(slack, { pen: 'pigma-05-black' }),
    [...nails].map((i) => circle(pts[i][0], pts[i][1], 0.012 * b.h, { pen: 'stabilo-88-blue' })),
  ];
});
```
