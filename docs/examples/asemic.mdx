---
title: Asemic script
description: A page of writing that says nothing, from a pen with inertia.
---

Each line is one material. The targets are vertices with a `kind` of 1, in order, tagged by word. The pen is a tip vertex with velocity columns and a `goal`. Each step pulls the tip toward its goal, damps it, and extrudes one vertex forward. When it comes within reach, the goal advances. A step into a new word marks the new vertex with `lift`. The drawing is every edge that is not a lift. The letterforms are never drawn. They are what a spring-damped point does on its way past the targets.

Uses: `material` with columns, `steps` with `extrude`, `set` and `filter`, `edges.filter` on a column, `strokes` of an edge selection.

```ts live
import { sketch, strokes, material } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 3 }, (t) => {
  const lines = 17, lh = 84 / lines;
  return t.times(lines, (j) => {
    const y = 10 + j * lh;
    // targets: zigs of tops and bottoms, the odd tall one, a gap between words
    const targets = [], word = [];
    let x = 10, w = 0;
    while (x < 86) {
      const n = Math.round(t.rnd(3, 11));
      for (let i = 0; i < n; i++) {
        const up = i % 2 === 0, tall = up && t.chance(0.12);
        targets.push([x + i * t.rnd(1.1, 1.7), y + (up ? -(tall ? 3.4 : t.rnd(0.9, 1.7)) : t.rnd(0.3, 1.1))]);
        word.push(w);
      }
      x = targets[targets.length - 1][0] + t.rnd(2, 4.5);
      w++;
    }
    const pen = [targets[0][0] - 0.8, y];
    const page = material([pen, ...targets], {
      kind: [0, ...targets.map(() => 1)], tip: [1, ...targets.map(() => 0)], word: [0, ...word],
      vx: 0, vy: 0, goal: 0, lift: 0,
    });
    const written = page.steps(700, (cur, next) => {
      const goals = cur.points.filter((p) => p.kind === 1);
      const tips = cur.points.filter((p) => p.tip === 1);
      next.extrude(tips, (p) => {
        if (p.goal >= goals.length) return [];
        const g = goals.at(p.goal);
        const vx = (p.vx + (g.x - p.x) * 0.16) * 0.72, vy = (p.vy + (g.y - p.y) * 0.16) * 0.72;
        const nx = p.x + vx, ny = p.y + vy;
        const reached = Math.hypot(g.x - nx, g.y - ny) < 0.35 ? 1 : 0;
        const goal = p.goal + reached;
        const lift = goal < goals.length && goals.at(goal).word !== g.word ? 1 : 0;
        return { position: [nx, ny], attributes: { kind: 0, tip: 1, word: g.word, vx, vy, goal, lift } };
      });
      next.set(tips, { tip: 0 });
    });
    return strokes(written.edges.filter((e) => e.b.lift === 0 && e.a.lift === 0), { pen: 'stabilo-88-blue' });
  });
});
```
