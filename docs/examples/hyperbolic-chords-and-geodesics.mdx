---
title: Chords and geodesics
description: Seven points in the hyperbolic plane, every pair joined two ways.
---

Seven points, every pair joined twice. The sketch sets `space` to the hyperbolic plane, so a coordinate is a position by steps from the centre of the drawable, and each of the seven is a place of that plane.

The ink pen draws `line`. A line is the shortest path between two points, so `line` is the one word that asks for a geodesic, and the engine draws that geodesic.

The faint pen walks the same pair in forty small steps of the sketch's own coordinates. Each step is a plain share of the difference between the two, the way a sketch adds up numbers. The path that comes out is a real path of the plane, and it is not the shortest one.

A geodesic is an arc that cuts the rim at a right angle. Near the middle of the disk the two paths almost agree, and the two pens run together. Away from the middle they part, and the geodesic always bows toward the centre.

The rim is infinitely far off. A path that keeps clear of it is shorter than a path near it. The bow is that saving. The further a pair sits from the centre, the more the ink line gains by pulling inward.

Twenty-one pairs, and no other rule. The shape between the two pens is the difference between a step of the space and the shortest way across it.

Uses: `space.hyperbolic`, `t.space`, `line`, `stroke`, `circle`, `t.times`, `t.rnd`, `pen`, `mm`.

```ts live
// CHORDS AND GEODESICS
//
// Seven points in the hyperbolic plane, every pair joined twice. `line`
// asks for the shortest path, so the ink pen draws the geodesic. The
// faint pen walks the same pair in forty small steps of the sketch's own
// coordinates, which is a path of the plane but not the shortest one.
// Near the middle the two agree. Near the rim the geodesic bows inward,
// because the rim is infinitely far and a line saves length by keeping
// clear of it.
import { sketch, stroke, line, circle, pen, mm, space } from 'occlude';

export default sketch(
  { aspect: [1, 1], seed: 3, space: space.hyperbolic({ radius: 46 }), pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), faint: pen({ width: mm(0.2), color: '#9AA4B2' }) } },
  (t) => {
    const c = t.space.center;
    const R = t.space.radius;
    const pts = t.times(7, (k) => {
      const a = (k / 7) * Math.PI * 2 + t.rnd(-0.25, 0.25), r = 0.55 + t.rnd(0.4);
      return [c[0] + R * r * Math.cos(a), c[1] - R * r * Math.sin(a)];
    });
    // The rim is the horizon: a circle drawn far enough out that the chart
    // has nowhere left to put it.
    const out = [circle(c[0], c[1], 400, { pen: 'ink' })];
    for (let i = 0; i < pts.length; i++) for (let j = i + 1; j < pts.length; j++) {
      out.push(stroke(t.times(41, (_, u) => [pts[i][0] + (pts[j][0] - pts[i][0]) * u, pts[i][1] + (pts[j][1] - pts[i][1]) * u]), { pen: 'faint' }));
      out.push(line(pts[i][0], pts[i][1], pts[j][0], pts[j][1], { pen: 'ink' }));
    }
    return out;
  },
);
```
