---
title: Reach
description: A network whose loose ends reach for each other, written as one relation.
---

Points scattered and settled, then joined wherever the space between them is empty enough. That leaves a web with loose ends: vertices with one edge and nowhere else to go. The drawing is about what those ends do next. Every pair of ends within reach of each other, and not already joined, gets a thread. That is one relation, stated once. `points.near` finds each end's neighbours, one pass over the ends keeps the pairs, and `edges.add` joins them. The web becomes one piece where it can.

The pen then tells the pieces apart. `points.components()` gives one selection for each connected piece. The largest piece gets the heavy pen and the rest stay faint. The drawing then shows the body of the web, and what is still adrift.

Uses: `t.scatter`, `t.relax`, `connect.unimpeded`, `p.edges`, `points.near`, `p.adjacent.has`, `edges.add`, `points.components()`, `without`.

```ts live paper=180x120
import { sketch, strokes, circle, connect } from 'occlude';

export default sketch({ aspect: [3, 2], seed: 11 }, (t) => {
  const cloud = t.relax(t.scatter({ spacing: 8.5 }), { iterations: 3 });
  const web = connect.unimpeded(cloud, { room: 2.4 });

  // A loose end is a vertex with one edge. Two of them reach for each
  // other when they are close and not already joined.
  const ends = web.points.filter((p) => p.edges.length === 1);
  const pairs = [...ends].flatMap((p) => [...ends.near(p, { radius: 18 })].filter((q) => q.index > p.index && !p.adjacent.has(q)).map((q) => [p, q]));
  const reached = web.edges.add(pairs);

  const pieces = reached.points.components();
  const body = pieces.reduce((a, b) => (b.length > a.length ? b : a));
  const adrift = reached.points.without(body);
  return [
    strokes(adrift.edges, { pen: 'pigma-005-black' }),
    strokes(body.edges, { pen: 'pigma-05-black' }),
    adrift.map((p) => circle(p, 0.9, { pen: 'stabilo-88-blue' })),
  ];
});
```
