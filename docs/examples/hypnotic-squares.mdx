---
title: Hypnotic squares
description: "After William Kolomyjec: nested squares that drift toward one corner of each tile."
---

Each tile holds a stack of squares, each one smaller than the last. The stack drifts toward a corner that chance picks for the tile. After [William Kolomyjec](https://generativeartistry.com/tutorials/hypnotic-squares/), through the Generative Artistry tutorial (MIT).

Uses: `rect`, `t.pick`.

```ts live
import { sketch, rect } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 13 }, (t) => {
  const size = 100, tiles = 7, tile = size / tiles, finalSize = 1, steps = 5;
  const out = [];
  for (let i = 0; i < tiles; i++) {
    for (let j = 0; j < tiles; j++) {
      const mx = t.pick([-1, 0, 1]), my = t.pick([-1, 0, 1]);
      let x = i * tile, y = j * tile, w = tile;
      for (let s = steps; s >= 0; s--) {
        out.push(rect(x, y, w, w));
        const next = tile * (s / steps) * 0.8 + finalSize;
        x += ((w - next) / 2) * (1 + mx * 0.5);
        y += ((w - next) / 2) * (1 + my * 0.5);
        w = next;
      }
    }
  }
  return out;
});
```
