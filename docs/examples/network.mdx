---
title: Growing network
description: Tips that grow upward, sense the lines ahead, steer, and join what they hit.
---

Nine tips start at the bottom with a heading. Each step, a tip looks ahead with `edges.nearest` and `edges.firstHit`. If a line is near, it steers away from it, or toward it when `steer` is negative. If its next move would cross a line, it cuts that line with a new point and joins it, and the tip stops. Now and then a tip forks. The tips of one step grow in turn, and each one senses the lines the tips before it drew. Each point keeps the step it grew in, and the noise that bends a tip reads that step. A rock in the middle is a ring of points that the tips treat like any other line.

Uses: `material` with columns, `append` with `fill`, `t.steps` inside a pass, `extrude`, `point` with `points.add`, `edges.remove` and `edges.add`, `edges.nearest` and `edges.firstHit`, `cross`, `ui`.

```ts live
import { sketch, circle, strokes, material, append, point, add, mul, polar, fromAngle, cross, ui } from 'occlude';

export default sketch({ aspect: [2, 1], seed: 7 }, (t) => {
  const steps = ui(34, { min: 0, max: 60, step: 1 });
  const branch = ui(0.06, { min: 0, max: 0.3, step: 0.01, label: 'branch chance' });
  const sense = ui(6, { min: 0, max: 14, step: 0.5, label: 'sensing distance' });
  const steer = ui(0.5, { min: -1, max: 1, step: 0.05, label: 'steer (+ away, − toward)' });
  const rock = t.sample(circle(100, 46, 16), { count: 40 });
  const seeds = material(t.times(9, (i, u) => [14 + u * 172, 96]), { active: 1, heading: -Math.PI / 2, step: 0 });
  const side = (heading, toward) => Math.sign(cross(fromAngle(heading), toward)) || 1;
  const living = (g) => g.points.filter((p) => p.active === 1 && p.y > 4 && p.x > 3 && p.x < 197);
  // One tip grows: the oldest living one. It senses the lines as they are now.
  const grow = (g) => {
    const p = living(g).at(0);
    const lines = g.edges;
    let h = p.heading + t.noise(p.x / 10, p.y / 10, p.step) * 0.35;
    const ahead = add(p, mul(fromAngle(h), sense));
    const near = lines.nearest(ahead, { within: sense, excludeIncident: p });
    if (near) h -= side(h, [near.position[0] - p.x, near.position[1] - p.y]) * steer * (1 - near.distance / sense);
    const target = add(p, mul(fromAngle(h), 2.2));
    const hit = lines.firstHit(p, target, { excludeIncident: p });
    const stopped = g.points.set('active', 0, p);
    if (hit) {
      // The tip joins the line it hits: a new point on that line, the line
      // cut in two through it, and the tip's last stroke to it.
      const q = point(hit.position, { active: 0, heading: h, step: p.step + 1 });
      return stopped.points.add(q).edges.remove(hit.edge).edges.add([[hit.edge.a, q], [q, hit.edge.b], [p, q]]);
    }
    const headings = t.chance(branch) ? [h - 0.5, h + 0.5] : [h];
    return headings.reduce((m, hh) => m.extrude(p, polar(2.2, hh), { active: 1, heading: hh, step: p.step + 1 }), stopped);
  };
  // One step is a generation: every tip living at its start grows once.
  const generation = (g) => t.steps(living(g).length, g, grow);
  const paths = t.steps(steps, append(rock, seeds, { fill: { active: 0, heading: 0, step: 0 } }), generation);
  return [strokes(paths), paths.points.filter((p) => p.active === 1).map((p) => circle(p, 0.8))];
});
```
