---
title: Composition after Mondrian
description: A page split by chance into pieces, with three of them filled solid in three pens.
---

The page starts as one piece. Lines at even steps split the pieces they cross, each with a coin flip, so some pieces stay large. Three pieces get a solid fill, each in its own pen. After the [Generative Artistry tutorial](https://generativeartistry.com/tutorials/piet-mondrian/) (MIT).

Uses: `t.chance`, `rect` with `fill('solid')` and `fillPen`.

```ts live
import { sketch, rect, fill } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 3 }, (t) => {
  const size = 100, step = size / 7;
  const pens = ['stabilo-88-blue', 'stabilo-88-green', 'pigma-01-black'];
  let pieces = [{ x: 0, y: 0, w: size, h: size, pen: null }];
  const split = (axis, at) => {
    pieces = pieces.flatMap((s) => {
      const len = axis === 'x' ? s.w : s.h;
      if (!(at > s[axis] && at < s[axis] + len) || !t.chance(0.5)) return [s];
      return axis === 'x' ? [{ ...s, w: at - s.x }, { ...s, x: at, w: s.x + s.w - at }] : [{ ...s, h: at - s.y }, { ...s, y: at, h: s.y + s.h - at }];
    });
  };
  for (let i = step; i < size; i += step) { split('y', i); split('x', i); }
  for (const pen of pens) pieces[Math.floor(t.rnd(pieces.length))].pen = pen;
  return pieces.map((s) => rect(s.x, s.y, s.w, s.h, s.pen ? { fill: fill('solid'), fillPen: s.pen } : {}));
});
```
