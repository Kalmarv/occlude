---
title: Rose window
description: Straight chords on a circle, and the curves that nobody drew.
---

Every black line is straight. Place `n` points on a circle and join point `k` to point `m·k`. The pile of chords is tangent to a curve with `m − 1` cusps, and `envelope` finds that curve. The chords are the leading and the envelope is the stone. Each band goes down first. Then the next ring inward covers it as an opaque disc. One band's leading never crosses the next band's tracery.

Uses: `connect.chain`, `append`, `envelope`, `opaque`.

```ts live paper=140x140
import { sketch, strokes, envelope, append, material, connect, circle } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 4 }, (t) => {
  const pile = (cx, cy, R, n, m) => append(...t.times(n, (k) => {
    const a = (k / n) * Math.PI * 2 - Math.PI / 2;
    const b = ((m * k) % n / n) * Math.PI * 2 - Math.PI / 2;
    return connect.chain(material([{ x: cx + R * Math.cos(a), y: cy + R * Math.sin(a) }, { x: cx + R * Math.cos(b), y: cy + R * Math.sin(b) }]));
  }));
  const band = (R, n, m) => {
    const fam = pile(t.cx, t.cy, R, n, m);
    return [strokes(fam), strokes(envelope(fam), { pen: 'stabilo-88-blue' })];
  };
  return [
    band(46, 126, 7),
    circle(t.cx, t.cy, 30.5, { opaque: true }),
    band(29, 84, 5),
    circle(t.cx, t.cy, 15.8, { opaque: true }),
    band(15, 54, 3),
    circle(t.cx, t.cy, 46),
  ];
});
```
