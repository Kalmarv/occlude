---
title: Span
description: A network inked by how far the pen travels without lifting, which is not the same as how long an edge is.
---

The geometry is a scatter of points joined wherever nothing sits between them. Every edge is much the same length. On this drawing they run from 6mm to 13mm, and half sit within a millimetre of 8mm. No edge asks to be heavier than another.

The shader reads `ctx.length`. That is the STROKE: the path the pen draws between two lifts. The planner merges the network's 209 edges into chains, and those chains run from 8mm to 294mm. A short stroke is a stub the pen dabs on its own. A long one sweeps across the sheet through a dozen junctions.

So the ink says something the geometry never did. A stub gets the heavy pen. A medium stroke is solid and fine. A long one breaks into dashes, and the longest into dust. The drawing shows the pen's own path, not the network's.

The steps are that distribution's quartiles. I measured the sketch to find them.

Uses: `t.scatter`, `connect.unimpeded`, `t.plan({ shader })` reading `ctx.length`, `pen` and `dash` in one program, `strokes`, `polygon`.

:::note
`ctx.length` is a plan chain, not a source edge. A rule or a fill that made many short pieces may reach the shader as one long stroke. Two shapes that never touched in the sketch may be one chain by the time the pen draws them. Measure the distribution before choosing thresholds.
:::

```ts live
import { sketch, strokes, polygon, circle, connect, shader, pen, mm } from 'occlude';

export default sketch({
  aspect: [1, 1], seed: 21, margin: 6,
  pens: { ink: pen({ width: mm(0.3), color: '#16181d' }), fine: pen({ width: mm(0.14), color: '#16181d' }) },
}, (t) => {
  const b = t.bounds();
  const points = t.scatter({ spacing: b.w * 0.062 }).points
    .filter((p) => Math.hypot(p.x - b.w / 2, p.y - b.h / 2) < b.w * 0.46);
  const net = connect.unimpeded(points.extract(), { room: 1.25 });
  t.plan({
    shader: shader((s, p, ctx) => {
      if (ctx.length <= 20) return { pen: 'ink' };
      if (ctx.length <= 37) return {};
      if (ctx.length <= 82) return { dash: [mm(2.4), mm(1.1)] };
      return { dash: [mm(0.8), mm(2.2)] };
    }),
  });
  return [
    strokes(net.curves(), { pen: 'fine' }),
    net.points.map((p) => polygon(circle(p.x, p.y, 0.7), { pen: 'ink' })),
  ];
});
```
