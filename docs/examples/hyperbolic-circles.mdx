---
title: Circles
description: Eight rings about one point, drawn as steps of the space, once by circle and once by t.space.circle.
---

Eight rings about one point, at eight equal radii, drawn twice. The sketch draws in the hyperbolic plane, so a coordinate is a position by steps from the centre of the drawable.

The ink family is the circle of the plane: every point one step `r` away from the middle point, in every direction. `t.space.circle` gives those points, and the sketch joins them up.

The faint family is what `circle` draws. A round shape is steps from its centre, so `circle` draws the same circle of the plane. The two families are one family, and each faint ring lies under an ink ring.

The rings are equal steps apart in the plane. The disk draws each one as a round circle, but the circles get closer together and drift toward the rim. A step far from the centre of the disk takes less of the page.

The small dot marks the point that all the rings are about. The rim is the horizon of the picture. It is one more ring, at a radius so far out that the chart has nowhere left to put it.

Uses: `space.hyperbolic`, `t.space`, `circle`, `stroke`, `t.times`, `pen`, `mm`.

```ts live
// CIRCLES OF THE HYPERBOLIC PLANE, TWO WAYS
//
// Eight rings about one point, at eight equal radii, drawn two ways. The
// ink ones are joined from t.space.circle: every point one step out. The
// faint ones are what `circle` draws — a round shape is steps from its
// centre, so they are the same rings, and each faint ring lies under an
// ink one.
import { sketch, stroke, circle, pen, mm, space } from 'occlude';

export default sketch(
  { aspect: [1, 1], seed: 4, space: space.hyperbolic({ radius: 46 }), pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), faint: pen({ width: mm(0.2), color: '#9AA4B2' }) } },
  (t) => {
    const c = t.space.center;
    const at = [c[0] + 12, c[1] - 7];
    const step = 6;
    const rim = circle(c[0], c[1], 400, { pen: 'ink' });
    // The circle of the space: one step `r` in every direction, joined up.
    const metric = (r) => {
      const ring = t.space.circle(at, r, 240);
      return stroke([...ring, ring[0]], { pen: 'ink' });
    };
    return [
      rim,
      t.times(8, (k) => circle(at[0], at[1], (k + 1) * step, { pen: 'faint' })),
      t.times(8, (k) => metric((k + 1) * step)),
      circle(at[0], at[1], 0.5, { pen: 'ink' }),
    ];
  },
);
```
