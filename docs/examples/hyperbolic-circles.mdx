---
title: Circles
description: Eight rings about one point, drawn as steps of the space and as XY and sin/cos.
---

Eight rings about one point, at eight equal radii, drawn twice. The sketch draws in the hyperbolic plane, so a coordinate is a position by steps from the centre of the drawable.

The ink family is the circle of the plane: every point one step `r` away from the middle point, in every direction. `t.space.circle` gives those points, and the sketch joins them up.

The faint family is what `circle` draws: `XY` and sin/cos in the coordinates the sketch writes. It is a shape like any other, and a shape is its anchor plus offsets.

The two start together. A step at the centre of the drawable is one drawable unit, so near the middle the two families almost agree.

After that they part. A row of the coordinates opens out away from the base, and an offset along it is worth more than its number. So the faint rings hold more of the plane to the left and right than up and down. They stretch that way. The ink rings stay round in the metric. The disk draws each one as a round circle that drifts toward the rim.

The small dot marks the one point both families are about. The rim is the horizon of the picture. It is one more ring, at a radius so far out that the chart has nowhere left to put it.

Uses: `space.hyperbolic`, `t.space`, `circle`, `stroke`, `t.times`, `pen`, `mm`.

```ts live
// CIRCLES, BY THE METRIC AND BY THE COORDINATES
//
// Eight rings about one point, at eight equal radii, drawn two ways. The
// ink ones are the circles of the hyperbolic plane: every point one step
// out. The faint ones are what `circle` draws — XY and sin/cos in the
// sketch's own coordinates, placed by the same steps as everything else.
// They start together at the middle and part as the rows open out.
import { sketch, stroke, circle, pen, mm, space } from 'occlude';

export default sketch(
  { aspect: [1, 1], seed: 4, space: space.hyperbolic({ radius: 46 }), pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), faint: pen({ width: mm(0.2), color: '#9AA4B2' }) } },
  (t) => {
    const c = t.space.center;
    const at = [c[0] + 12, c[1] - 7];
    const step = 6;
    const rim = circle(c[0], c[1], 400, { pen: 'ink' });
    // The circle of the space: one step `r` in every direction, joined up.
    const metric = (r) => {
      const ring = t.space.circle(at, r, 240);
      return stroke([...ring, ring[0]], { pen: 'ink' });
    };
    return [
      rim,
      t.times(8, (k) => circle(at[0], at[1], (k + 1) * step, { pen: 'faint' })),
      t.times(8, (k) => metric((k + 1) * step)),
      circle(at[0], at[1], 0.5, { pen: 'ink' }),
    ];
  },
);
```
