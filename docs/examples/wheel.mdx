---
title: Wheel
description: One walk, grown as a material, drawn twelve times around a centre.
---

The walk is a material with one tip. Each step extrudes the tip one vertex forward. The heading, the mode and the birth step are columns, so the walk is data that later rules can query. A slow noise switches the tip between running and tangling. When it runs, a pull toward the tangent of the circle round the centre keeps the wheel together. A slab is a stretch of the walk, selected by its birth step. The sketch extracts it and sweeps it along its own normal ten times. Every state comes back from the history. Six rotations and a mirror make the wheel.

Uses: `material` with columns, `steps` with `extrude`, `edges.filter` on a column, `extract`, `history`, `connectedPoints`, `group` with `rotate` and a mirror `scale`.

```ts live
import { sketch, strokes, ellipse, group, fill, mm, material, add, sub, perp, unit, mul, fromAngle } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 11 }, (t) => {
  const C = [50, 50];
  const seed = material([[50, 24]], { heading: 0, tip: 1, tangle: 0, born: 0 });
  const walk = seed.steps(700, (cur, next, k) => {
    const tips = cur.points.filter((p) => p.tip === 1);
    next.extrude(tips, (p) => {
      const tangle = t.noise(k / 45, 3) > 0.1 ? 1 : 0;
      const round = Math.atan2(p.x - C[0], -(p.y - C[1]));           // heading that circles the centre
      const pull = Math.atan2(Math.sin(round - p.heading), Math.cos(round - p.heading)) * 0.05;
      const h = p.heading + (tangle ? 0.27 + t.noise(k / 5, 8) * 0.5 : t.noise(k / 9, 8) * 0.28 + pull);
      return { position: add(p, mul(fromAngle(h), 0.24)), attributes: { heading: h, tip: 1, tangle, born: k + 1 } };
    });
    next.set(tips, { tip: 0 });
  });

  // Slabs: a stretch of the walk, selected by when it was born, extracted and
  // swept along its own normal one small step at a time; every state is drawn.
  const alongNormal = (prev, next) =>
    next.move(prev.points, (p) => {
      const nb = prev.connectedPoints(p);
      const along = nb.length === 2 ? sub(nb[1], nb[0]) : nb.length === 1 ? sub(nb[0], p) : [1, 0];
      return mul(unit(perp(along)), 0.22);
    });
  const slabs = t.times(4, (i) => {
    const from = 60 + i * 150 + Math.floor(t.rnd(0, 40));
    const stretch = walk.edges.filter((e) => e.a.born >= from && e.a.born < from + 22).extract();
    return stretch.steps(10, alongNormal, { every: 1 }).history.map((h) => strokes(h.material, { pen: 'pigma-005-black' }));
  });

  // Beads where the walk was tangling.
  const beads = walk.points
    .filter((p) => p.tangle === 1 && p.born % 120 === 60)
    .map((p) => ellipse(p.x, p.y, 1.4, 0.8, t.rnd(0, 180), { stroke: false, fill: fill('hatch', { angle: 0, spacing: mm(0.3) }) }));

  const one = [strokes(walk, { pen: 'pigma-005-black' }), ...slabs, ...beads];
  return t.times(6, (k) => [
    group({ rotate: k * 60, origin: C }, ...one),
    group({ rotate: k * 60, origin: C }, group({ scale: [-1, 1], origin: C }, ...one)),
  ]);
});
```
