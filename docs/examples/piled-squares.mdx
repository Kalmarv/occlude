---
title: Piled squares
description: The same falling grid, with each square opaque, so the pile hides what is under it.
---

The same rule as Cubic disarray, with one change: every square is opaque. A square that falls over another one hides it, so the pile reads as a heap of tiles. The disorder eases in with `ease.quadIn`, so the top rows stay almost straight.

Uses: `group`, `rect` with `opaque`, `ease`.

```ts live
import { sketch, rect, group, ease } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 17 }, (t) => {
  const size = 100, n = 11, sq = size / n;
  return t.times(n - 1, (row) => {
    const fall = ease.quadIn((row + 1) / (n - 1));
    return t.times(n - 1, (col) => {
      const x = sq + col * sq, y = sq + row * sq;
      return group({ translate: [x + t.rnd(-1, 1) * fall * 5, y], rotate: t.rnd(-1, 1) * fall * 22 }, rect(-sq / 2, -sq / 2, sq, sq, { opaque: true }));
    });
  });
});
```
