---
title: Veil
description: One even cloud of points, a close mesh in the middle and filigree at the rim.
---

One cloud of points, evenly spread. `connect.unimpeded` joins two points when the space between them is empty, and `room` says how much space that takes. Here `room` is a field: almost none at the centre and a great deal at the rim. The same points are a close mesh in the middle and come apart into filigree at the edge. Nothing thins, masks or fades the drawing. The lattice only stops agreeing that distant pairs are neighbours.

Uses: `t.scatter` with `within`, `t.relax`, `connect.unimpeded` with a field.

```ts live
import { sketch, strokes, circle, connect } from 'occlude';

export default sketch({ aspect: [2, 1], seed: 8 }, (t) => {
  const veil = circle(100, 50, 46);
  const pts = t.relax(t.scatter({ spacing: 3.4, within: veil }), { iterations: 3, within: veil });
  const room = (x, y) => 1 + Math.pow(Math.min(1, Math.hypot(x - 100, y - 50) / 46), 2.2) * 2.1;
  return strokes(connect.unimpeded(pts, { room }));
});
```
