---
title: Shoal
description: A distance field makes the form, a rewrite rule roughens its coast, and one shader inks the result by the same field.
---

Three mechanisms, one drawing, and each does the part it is best at.

`field.blend` folds four discs into one body. `t.isolines(body, 0)` gives its outline, and `resample` coarsens that outline to edges seven millimetres long. Long edges are what a rewrite rule wants. `rule.edge().replace(motif)` then swaps every edge for a bump, twice, so the smooth blob grows a fractal coast.

The shader reads the same field that made the form. Deep inside the body the hatch runs solid, and near the coast it breaks into dashes. The steps come from the field's own maximum, measured over a grid. Nothing here is a number picked by eye.

`ctx.pen` is what keeps the coast crisp. The coastline draws in its own pen, and the shader returns an empty record for it. A shader sees what the engine knows about a stroke, so it can ink the fill and leave the outline alone.

Uses: `t.throw`, `field.circle`, `field.blend`, `t.isolines`, `resample`, `rule.edge().replace`, `t.plan({ shader })`, `ctx.pen`, `polygon` with a `fill`, `strokes`.

:::note
The coastline goes down first, before the filled shape. A stroke on a filled shape's boundary is coincident with it, and the engine culls it. Draw the outline afterwards and it disappears.
:::

```ts live
import { sketch, polygon, strokes, circle, material, field, rule, shader, fill, pen, mm } from 'occlude';

export default sketch({
  aspect: [1, 1], seed: 12, margin: 6,
  pens: { ink: pen({ width: mm(0.32), color: '#16181d' }), fine: pen({ width: mm(0.14), color: '#16181d' }) },
}, (t) => {
  const b = t.bounds();

  // One body from four discs.
  const body = t.throw(circle(b.w / 2, b.h / 2, b.w * 0.24), { count: 4 })
    .points.map((p) => field.circle(p.x, p.y, b.w * 0.2))
    .reduce((acc, f) => field.blend(acc, f, 11));

  // A coarse outline, roughened twice by one motif.
  const h = Math.sqrt(3) / 10;
  const motif = material([[0, 0], [1 / 3, 0], [0.5, h], [2 / 3, 0], [1, 0]], { edges: [[0, 1], [1, 2], [2, 3], [3, 4]] });
  const coast = t.isolines(body, 0).resample({ spacing: 7 })
    .steps(2, rule.edge().replace(motif, { flip: (e) => e.index % 2 === 0 }));

  // The field's own depth decides the ink. The coast keeps its pen.
  let deepest = 0;
  for (let gx = 0; gx <= 40; gx++) for (let gy = 0; gy <= 40; gy++) {
    deepest = Math.max(deepest, body((gx / 40) * b.w, (gy / 40) * b.h));
  }
  t.plan({
    shader: shader((s, p, ctx) => {
      if (ctx.pen === 0) return {};
      const d = body(p[0], p[1]) / deepest;
      if (d < 0.22) return { dash: [mm(0.7), mm(2.4)] };
      if (d < 0.48) return { dash: [mm(1.8), mm(1.3)] };
      if (d < 0.74) return {};
      return { pen: 'ink' };
    }),
  });

  return [
    strokes(coast.curves(), { pen: 'ink' }),
    polygon(coast.curves(), { fill: fill('hatch', { angle: 38, spacing: mm(1.5) }), pen: 'fine' }),
  ];
});
```
