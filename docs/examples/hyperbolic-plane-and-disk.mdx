---
title: Plane and disk
description: One motif under {4, 5}, five squares at every corner, where the plane has room for four.
---

One motif under a law the flat plane cannot keep. A square cell holds a smaller square turned inside it. On a flat sheet the cell repeats under `p4m`, the wallpaper group of the square grid. There, four squares meet at every corner.

Here the same motif repeats under `{4, 5}`. Five squares meet at every corner. No flat grid can do that, because five right angles do not close. The hyperbolic plane has the room for the fifth square. The price is size: each ring of cells comes out smaller than the ring inside it.

Nothing shrinks in the metric of the disk. Every cell there is the same square, at the same size, and the rim lies infinitely far away. The shrinking belongs to the picture, not to the plane the picture shows.

The sketch draws in hyperbolic space, because `{4, 5}` is a tiling of that space. `t.tiling` refuses a symbol of another geometry. A wall is a geodesic, so it draws as an arc that meets the rim at a right angle. The sketch writes the turned square once, inside the cell, and every placement carries it. `strokes(tiles)` draws each wall once, because two cells that meet share the wall.

Uses: `t.tiling`, `t.space`, `strokes`, `line`, `circle`.

```ts live
// ONE MOTIF, FIVE AT A CORNER
//
// A square cell with a smaller square turned inside it, repeated under
// {4, 5}: five squares at every corner, which no flat grid can do, so
// the cells shrink toward the rim. The sketch draws in the tiling's own
// space, so every wall is a geodesic and draws as an arc. The turned
// square is written once in the cell, and every placement carries it.
import { sketch, strokes, line, circle, pen, mm, space } from 'occlude';

export default sketch(
  { aspect: [1, 1], seed: 5, space: space.hyperbolic({ radius: 50 }), pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), faint: pen({ width: mm(0.2), color: '#9AA4B2' }) } },
  (t) => {
    const tiles = t.tiling(4, 5, { depth: 4 });
    const c = t.space.center;
    // The turned square: the middle of each wall, pulled toward the
    // middle of the cell along the geodesic between them.
    const quad = tiles.cell;
    const inner = quad.map((v, i) => t.space.geodesic(c, t.space.geodesic(v, quad[(i + 1) % 4], 0.5), 0.72));
    const ring = (pts) => pts.map((v, i) => line(v, pts[(i + 1) % pts.length], { pen: 'faint' }));
    return [
      // The rim, drawn at a radius so far out that the chart has nowhere
      // left to put it.
      circle(c[0], c[1], 300, { pen: 'ink' }),
      strokes(tiles, { pen: 'ink' }),
      tiles.placements.map((f) => ring(inner.map((v) => f.point(v)))),
    ];
  },
);
```
