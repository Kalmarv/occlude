---
title: Plane and disk
description: One motif under two symmetries, p4m on the sheet and {4, 5} inside the disk.
---

One motif, drawn twice under two different laws. A square cell holds a smaller square turned inside it. On the sheet the cell repeats under `p4m`, the wallpaper group of the square grid. Four squares meet at every corner, and every cell is the same size.

Inside the disk the same motif repeats under `{4, 5}`. Five squares meet at every corner. No flat grid can do that, because five right angles do not close. The hyperbolic plane has the room for the fifth square. The price is size: each ring of cells comes out smaller than the ring inside it.

Nothing shrinks in the disk's own metric. Every cell there is the same square, at the same hyperbolic size, and the rim lies infinitely far away. The shrinking belongs to the picture, not to the plane the picture shows.

The disk is an opaque polygon, so it hides the flat grid beneath it. The two geometries meet at one hard edge, and the same motif sits on both sides of it.

Uses: `hyperbolic.polygon`, `hyperbolic.geodesic`, `hyperbolic.tiling`, `hyperbolic.map`, `t.symmetry`, `group`, `clip`, `path`, `polygon` with `opaque`, `stroke`.

```ts live
// ONE MOTIF, TWO GEOMETRIES
//
// A square cell with a smaller square turned inside it, repeated twice.
// Across the sheet it repeats under p4m: four squares at every corner,
// every cell the same size. Inside the disk it repeats under {4, 5}:
// five squares at every corner, which no flat grid can do, so the cells
// shrink toward the rim. The disk is opaque and hides the plane beneath
// it.
import { sketch, stroke, polygon, group, clip, rect, path, pen, mm, hyperbolic } from 'occlude';

export default sketch(
  { aspect: [1, 1], seed: 5, pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), faint: pen({ width: mm(0.2), color: '#9AA4B2' }) } },
  (t) => {
    const b = t.bounds();
    const R = Math.min(b.w, b.h) * 0.3, cx = b.cx, cy = b.cy;
    const S = (p) => [cx + R * p[0], cy - R * p[1]];
    // The plane: a square cell with a smaller square turned inside it.
    const cell = 11;
    const motif = [
      path().moveTo(0, 0).lineTo(cell, 0).lineTo(cell, cell).lineTo(0, cell).close().build(),
      path().moveTo(cell / 2, cell * 0.2).lineTo(cell * 0.8, cell / 2).lineTo(cell / 2, cell * 0.8).lineTo(cell * 0.2, cell / 2).close().build(),
    ];
    const plane = clip(rect(0, 0, b.w, b.h), t.symmetry('p4m', { cell }).map((p) => group({ ...p, pen: 'faint' }, motif)));
    // The disk: the fundamental square of {4, 5}, its edges as geodesics,
    // and the same turned square inside, mapped by every placement.
    const sq = hyperbolic.polygon(4, 5);
    const edges = sq.map((v, i) => hyperbolic.geodesic(v, sq[(i + 1) % 4], { count: 12 }));
    const inner = sq.map((v, i) => {
      const w = sq[(i + 1) % 4];
      return [(v[0] + w[0]) / 2 * 0.72, (v[1] + w[1]) / 2 * 0.72];
    });
    const innerEdges = inner.map((v, i) => hyperbolic.geodesic(v, inner[(i + 1) % 4], { count: 8 }));
    const cells = hyperbolic.tiling(4, 5, { depth: 4 }).flatMap((m) => {
      const f = hyperbolic.map(m);
      return [...edges, ...innerEdges].map((line) => stroke(line.map((p) => S(f(p))), { pen: 'ink' }));
    });
    const disk = polygon(t.times(181, (_, u) => S([Math.cos(u * Math.PI * 2), Math.sin(u * Math.PI * 2)])), { opaque: true, pen: 'ink' });
    return [plane, disk, cells];
  },
);
```
