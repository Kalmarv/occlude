---
title: Tonal hatch
description: A torus hatched along its surface, with the lines thinning where the light falls.
---

One call to `t.hatch` walks the lines across the torus in the direction of the chart. The tone is a field of the surface normal. The top keeps every third lane. The sides and the inner throat fill in as the surface turns away from the light. The hatch follows the surface, so the lines bend with the tube.

Uses: `torus`, `t.hatch` with a direction and a tone field, `sketchAsync`.

```ts live
import { sketchAsync, pen, mm } from 'occlude';
import { torus, view, orthographic } from 'occlude/3d';

export default sketchAsync({ aspect: [1, 1], seed: 42, pens: { ink: pen({ width: mm(0.2), color: '#18202A' }) } }, async (t) => {
  const model = torus(1.4, 0.45, { segments: 36, tubeSegments: 14 });
  const marks = await t.hatch(model, { direction: (s) => s.tangentU, spacing: 0.1, tone: (s) => 0.3 + 0.7 * (1 - Math.max(0, s.normal[2])) });
  return view([model, marks], { camera: orthographic({ eye: [5, 7, 5], span: 5 }), stroke: 'ink', creaseAngle: 180 });
});
```
