---
title: Delta
description: A network grown from a mouth, thickened into one body.
---

Points spread over the page, denser toward the mouth at the bottom. The network grows from the mouth. Each step, every point within reach of the network joins its nearest joined point, and remembers the step it joined in: one past the latest join already on the network. Early joins are the trunk and late joins are the twigs. `thicken` turns the tree into one body, with a radius that falls with that step, and one `polygon` fills it.

Uses: `t.scatter` with a density, `t.relax`, `points.set`, `t.steps` with `points.near`, a selection's `set` and `edges.add`, `edges`, `extract`, `thicken`, `polygon` with a fill.

```ts live
import { sketch, strokes, polygon, fill, mm, material, distance } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 4 }, (t) => {
  const pts = t.relax(t.scatter((x, y) => 0.3 + 0.7 * Math.pow(y / 100, 1.5), { spacing: 4.5 }), { iterations: 2 });
  const root = [...pts.points].reduce((a, b) => (distance(b, [50, 97]) < distance(a, [50, 97]) ? b : a));
  const seeded = pts.points.set('when', (p) => (p.index === root.index ? 0 : -1));
  const tree = t.steps(40, seeded, (g) => {
    const now = 1 + Math.max(...g.points.map((p) => p.when));
    const reach = (p) => g.points.near(p, { radius: 9 }).filter((q) => q.when >= 0);
    const nearest = (p) => [...reach(p)].reduce((a, b) => (distance(p, b) < distance(p, a) ? b : a));
    const joining = g.points.filter((p) => p.when < 0 && reach(p).length > 0);
    return joining.set('when', now).edges.add(joining.map((p) => [p, nearest(p)]));
  });
  const grown = tree.points.filter((p) => p.when >= 0).edges.extract();
  const most = Math.max(...grown.points.map((p) => p.when));
  const body = grown.thicken({ radius: (p) => 0.35 + 2.6 * Math.pow(1 - p.when / most, 2.4) });
  return [polygon(body, { fill: fill('hatch', { angle: 90, spacing: mm(0.7) }), pen: 'pigma-005-black' }), strokes(grown, { pen: 'pigma-005-black' })];
});
```
