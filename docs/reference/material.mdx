---
title: Material
description: Points with columns and an edge list. The editable form of geometry.
---

A material is a set of vertices and an edge list. Each vertex has `x`, `y` and any number of named columns. A ring, an open chain, a tree and a cloud of loose points are all materials. Every operation returns a new material and changes nothing, so you can keep any state and come back to it.

:::note
A row index belongs to one state. After a step adds or removes vertices, the rows get new numbers. Hold a value, not an index.
:::

The value. `n` is the number of vertices. `points` and `edges` are collections of rows: iterate them, or use `length`, `at(i)`, `map` and `filter`. `pts` is the positions as pairs. `x`, `y` and `attrs.name` are the raw columns. `closed` is true for one ring. `strokes(m)` draws every chain once. Here a rectangle becomes four vertices and four edges.

```ts live
import { sketch, rect, circle, strokes } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const m = t.material(rect(15, 20, 70, 60));
  return [strokes(m), m.points.map((p) => circle(p.x, p.y, 1.5, { pen: 'stabilo-88-blue' })), m.edges.map((e) => circle((e.a.x + e.b.x) / 2, (e.a.y + e.b.y) / 2, 0.8))];
});
```

`pts` is what a `stroke` wants, and `n` is what turns a row number into a fraction of the way round.

```ts live
import { sketch, stroke, circle } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const ring = t.sample(circle(50, 50, 38), { count: 26 });
  return [stroke([...ring.pts, ring.pts[0]]), ring.points.map((p) => circle(p.x, p.y, 0.5 + (3.4 * p.index) / ring.n, { pen: 'stabilo-88-blue' }))];
});
```

## What a geometry value can say

A value answers `contours()` for areas, `curves()` for chains, and `points` for positions. A consumer asks for the one it needs, and it refuses a value that cannot answer, by name.

A shape is not geometry until the toolkit lowers it. Every word on `t` takes a shape. The plain import takes geometry. `t.distanceTo(circle(...))` works and `distanceTo(circle(...))` does not, because a shape needs the paper, the units and its own transform before it has points.

A shape enters the point world through two doors only. `t.material(shape)` keeps the boundary's own vertices. `t.sample(shape, { count })` redistributes along it by arc length. `connect.*`, `voronoi` and `t.quadtree` take points, so give them the material one of those doors made.

| value | answers |
| --- | --- |
| material | `contours()`, `curves()`, `points` |
| point selection | `points`, `curves()` |
| edge selection | `points`, `curves()` |
| face collection or face selection | `points`, `edges`, `contours()` |
| one face | `points`, `edges`, `contours()` |
| contour records and loops | themselves |

## What a point or an edge is, across states

Every vertex and every edge has an `id` for as long as it exists. An id is opaque: you cannot do arithmetic with it, and it is equal only to itself. It is never reused.

New geometry mints new ids. A step that moves or sets keeps them. A split retires the edge it cut and gives both halves ids of their own, so `edgeOf(parentId)` finds nothing afterwards.

A selection can then outlive the state that made it. `sel.in(state)` reads a selection against a later state and drops the members that are gone. `sel.has(view)` asks by identity, so a vertex you kept from an earlier step is the same vertex. A step verb takes a selection from an earlier state and finds the rows itself.

Store an id in an ordinary column and look it up later with `m.pointOf(id)` or `m.edgeOf(id)`. `m.points.at(row)` and `m.edges.at(row)` ask the same question by position in one state. An id and a row are both numbers. The two have different names, and neither guesses.

Here the sketch splits a ring of twelve vertices three times, then pushes it about. The ring ends with ninety-six rows, in a new order. Three vertices held from the first state still answer in the last one. An id kept in a plain variable finds its vertex again.

```ts live
import { sketch, strokes, circle } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 3 }, (t) => {
  const ring = t.sample(circle(50, 50, 34), { count: 12 });
  const held = ring.points.filter((p) => p.index % 4 === 0);
  const anchorId = ring.points.at(2).id;
  const grown = ring.steps(
    3,
    (cur, next) => next.splitEdges(cur.edges, { at: 0.5 }),
    (cur, next) => next.move(cur.points, (p) => [t.noise(p.x / 16, p.y / 16) * 5, t.noise(p.y / 16, p.x / 16) * 5]),
  );
  const anchor = grown.pointOf(anchorId);
  return [
    strokes(grown),
    held.in(grown).map((p) => circle(p.x, p.y, 2.5, { pen: 'stabilo-88-blue' })),
    circle(anchor.x, anchor.y, 4.5),
  ];
});
```

## material()

<include>/_sig/material.mdx</include>

Builds a material from positions. Give pairs or `{ x, y }` objects. The points have no edges unless you give `edges`, as pairs of row numbers. Every other option is a column. A number sets the value on every row. An array sets one value for each row. A point that carries a `w` becomes a column too.

```ts live
import { sketch, circle, strokes, material } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const m = material([[12, 30], [50, 12], [88, 30], [50, 88]], { edges: [[0, 1], [1, 2], [0, 3], [2, 3]], weight: [1.5, 3, 1.5, 4] });
  return [strokes(m), m.points.map((p) => circle(p.x, p.y, p.weight, { pen: 'stabilo-88-blue' }))];
});
```

## curve()

<include>/_sig/curve.mdx</include>

Builds one chain from positions, in the order given. `closed: true` makes a ring. The other options are columns, as in `material()`.

```ts live
import { sketch, strokes, curve } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const zig = t.times(9, (k) => [10 + k * 10, k % 2 ? 20 : 45]);
  return [strokes(curve(zig, { closed: false })), strokes(curve([[15, 65], [85, 65], [50, 92]], { closed: true }))];
});
```

## t.material()

<include>/_sig/Toolkit.material.mdx</include>

Reads shapes as material and keeps their own vertices: the four corners of a rectangle, the points of a path. A curved part becomes segments, with `tolerance` (0.05 mm by default) as the largest error. A closed outline becomes a ring, an open one a chain. Several shapes become several outlines in one material. Nothing joins them.

```ts live
import { sketch, rect, ngon, strokes, circle } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const m = t.material(rect(8, 30, 38, 40), ngon(72, 50, 6, 24));
  return [strokes(m), m.points.map((p) => circle(p.x, p.y, 1.2, { pen: 'stabilo-88-blue' }))];
});
```

## t.sample()

<include>/_sig/Toolkit.sample.3.mdx</include>

Reads a shape as material with new vertices, spaced evenly along the outline by arc length. Give `count` or `spacing`. The samples need not land on the shape's corners. Use `t.material()` to keep the corners, and `t.sample()` to get even spacing.

```ts live
import { sketch, rect, circle } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const m = t.sample(rect(12, 20, 76, 60), { count: 28 });
  return [rect(12, 20, 76, 60), m.points.map((p) => circle(p.x, p.y, 1.4, { pen: 'stabilo-88-blue' }))];
});
```

## append()

<include>/_sig/append.mdx</include>

Puts several materials in one, in the order given. The rows of each one come after the rows of the one before. The edges get new row numbers. All of them must have the same columns. If one has a column that another does not, `fill` gives the value that the other gets.

```ts live
import { sketch, strokes, curve, append, connect, circle } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const parts = t.times(4, (k) => curve([[12 + k * 22, 12], [24 + k * 22, 88]], { closed: false }));
  const one = append(...parts);
  return [strokes(one), strokes(connect.nearest(one, { count: 1 }), { pen: 'stabilo-88-blue' }), one.points.map((p) => circle(p.x, p.y, 1.2))];
});
```

## attribute() · attributes()

<include>/_sig/Material.attribute.mdx</include>
<include>/_sig/Material.attributes.mdx</include>

Adds a column to every vertex and returns the new material. The value is a number, or a function of the vertex. `attributes` adds several columns at once. Each function reads the material as it was, so a new column never sees another new column. A second call sees the first call's columns, because by then they are part of the material. `transfer` says what a column does at a new vertex, after a split or a resample. `'interpolate'` (the default) blends the two values. `'nearest'` copies the nearer one.

```ts live
import { sketch, strokes, circle } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const ring = t
    .sample(circle(50, 50, 40), { count: 36 })
    .attribute('lift', (p) => (p.y < 50 ? 1 : 0))
    .attributes({ reach: (p) => 0.6 + p.x / 40, side: (p) => (p.x < 50 ? 0 : 1) });
  return [strokes(ring), ring.points.filter((p) => p.lift === 1).map((p) => circle(p.x, p.y, p.reach, { pen: p.side === 1 ? 'stabilo-88-blue' : undefined }))];
});
```

## edgeAttribute() · edgeAttributes()

<include>/_sig/Material.edgeAttribute.mdx</include>
<include>/_sig/Material.edgeAttributes.mdx</include>

The same for edges: one value for each edge, read from the edge view. `transfer` for an edge column is `'copy'` (the default) or `'distribute'`. `'distribute'` shares a quantity over the parts of a split edge.

```ts live
import { sketch, strokes, circle } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const ring = t
    .sample(circle(50, 50, 40), { count: 40 })
    .edgeAttribute('long', (e) => (e.a.x > 50 ? 1 : 0))
    .edgeAttributes({ high: (e) => (e.a.y < 50 ? 1 : 0) });
  return [
    strokes(ring.edges.filter((e) => e.attrs.long === 1 && e.attrs.high === 1), { pen: 'pigma-05-black' }),
    strokes(ring.edges.filter((e) => e.attrs.long === 1 && e.attrs.high === 0), { pen: 'stabilo-88-blue' }),
    strokes(ring.edges.filter((e) => e.attrs.long === 0)),
  ];
});
```

## What keeps a column

A column belongs to the material that declares it. An operation that makes a
new material decides what to carry, and the three answers differ. We measured this table. It is
what the code does, not what it should do.

| operation | point columns | edge columns | transfer policies |
|---|---|---|---|
| `warp`, `snap`, `resample`, `trails`, `planarize`, `append`, `withEdges`, `steps` | kept | kept | kept |
| `oscillate` | kept, and an edge column arrives as a POINT column | dropped | edge policies dropped |
| `thicken`, `envelope`, `interlace` | dropped | dropped | dropped |

The third row matches its geometry. An envelope's vertices are crossings of a
family, and come from no vertex at all. An interlace cuts a chain where it
passes under. Neither has one source row to read a value from.

`thicken` is different: it CAN trace an output vertex back, and
`{ point: (event) => … }` is how you ask it to. The event carries every
source candidate for that vertex. Each candidate's columns are already read
by the column's own transfer policy, and what you return becomes the row.
Most output vertices have one candidate. The few with several are the outer
corners and the junctions. There the candidates disagree, so the decision is
yours and there is no default.

The second row is a trap. `oscillate` walks the chains as stations. A station
carries an edge's sampled value as an ordinary point value. So an edge
quantity that `'distribute'` conserves, such as a rest length, comes out as a
point value under the same name. Rename the column before you oscillate, or
write it back afterwards.

To keep a column through an operation in the third row, read it off the source
first. Then set it again on the result.

## withEdges()

<include>/_sig/Material.withEdges.mdx</include>

Replaces the edge list. Give pairs of row numbers. The vertices and their columns stay as they are.

```ts live
import { sketch, strokes, circle } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const ring = t.sample(circle(50, 50, 42), { count: 12 });
  const star = ring.withEdges(t.times(12, (k) => [k, (k + 5) % 12]));
  return strokes(star);
});
```

## resample()

<include>/_sig/Material.resample.mdx</include>

Puts new vertices along each chain at even spacing by arc length. Give `spacing` or `count`, in material units. An open chain keeps both ends. A closed chain keeps its seam. A corner between two new vertices does not survive. Chains only: a junction is an error.

```ts live
import { sketch, strokes, circle, curve } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const rough = curve([[8, 75], [28, 22], [50, 68], [72, 20], [92, 60]], { closed: false });
  const even = rough.resample({ spacing: 6 });
  return [strokes(rough, { pen: 'pigma-005-black' }), even.points.map((p) => circle(p.x, p.y, 1.4, { pen: 'stabilo-88-blue' }))];
});
```

## along()

<include>/_sig/Material.along.mdx</include>

Reads stations along each chain and changes nothing. A station is plain data. It has `x` and `y`, the unit `tangent` and `normal` of the chain under it, and the `heading` in radians. It has the arc length `s`, its fraction `u`, and the point columns in `attrs`. With no option, there is one station at each vertex. Use `resample()` when the material must be even. Use `along()` to put things on it.

```ts live
import { sketch, strokes, circle, line } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const ring = t.material(circle(50, 50, 34));
  const ticks = ring.along({ spacing: 9 }).map((s) => line(s.x, s.y, s.x + s.normal[0] * 8, s.y + s.normal[1] * 8));
  return [strokes(ring), ticks];
});
```

## station.place()

<include>/_sig/Station.place.mdx</include>

Puts a drawable on a station, turned to the station's heading. `offset: [alongTangent, alongNormal]` moves it in the station's own frame. `rotate` adds degrees to the heading. `scale` comes before the rotation. A negative value mirrors.

```ts live
import { sketch, strokes, circle, rect } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const ring = t.material(circle(50, 50, 34));
  return [strokes(ring), ring.along({ count: 14 }).map((s) => s.place(rect(-4, -2, 8, 4), { offset: [0, 7] }))];
});
```

## curves()

<include>/_sig/Material.curves.mdx</include>

The chains of the material, each one once, as records that `stroke` and `polygon` accept. A chain runs from an end or a junction to the next one. `strokes(m)` is the same walk with the drawing done for you.

```ts live
import { sketch, stroke, material } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const y = material([[10, 12], [50, 50], [90, 12], [50, 92]], { edges: [[0, 1], [1, 2], [1, 3]] });
  return y.curves().map((c, i) => stroke(c, { pen: i === 1 ? 'stabilo-88-blue' : undefined }));
});
```
