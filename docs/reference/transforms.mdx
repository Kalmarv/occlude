---
title: Transforms
description: Operations that take a material and return a changed material.
---

Each transform is a method on the material: `m.warp({ from, to })`. It reads the material, in the material's own coordinates, and returns a new material. The numbers on this page are flat numbers, and a curved sketch changes that for four words only. The [geometry](/docs/reference/geometry#space--projection) page holds the table of the words that read the metric. `m.resample`, `m.along` and `m.trim` measure by the metric when the caller hands them a space. `m.transform` moves points by an isometry of one. Most keep the columns. `thicken` returns a new boundary, and `envelope` adds one column. They read no seed and no paper, so the same input always gives the same output. `segmentRuns`, `banding` and `extent` stay imports.

## m.warp()

<include>/_sig/Material.warp.mdx</include>

<AutoTypeTable path="../occlude/src/warp.ts" name="WarpOpts" />

Moves every point by a cage. `from` and `to` are two loops with the same number of corners. Each point becomes a weighted blend of the `from` corners. The same weights then rebuild it from the `to` corners. Only positions move. Structure, columns and row order stay. A straight edge with two vertices stays straight, so resample first when a line must bend.

`where` bends only part of the material and leaves the rest where it is. The edge between a bent point and a still one simply stretches. The result is still one material. That is the point of the option. Filter a selection and extract it, and the joining edge is gone with the rest. See [where](/docs/reference/selections#where).

```ts live
import { sketch, strokes, line, append } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const across = t.times(9, (k, u) => t.sample(line(15, 15 + u * 70, 85, 15 + u * 70), { count: 30 }));
  const down = t.times(9, (k, u) => t.sample(line(15 + u * 70, 15, 15 + u * 70, 85), { count: 30 }));
  const lattice = append(...across, ...down);
  const from = [[15, 15], [85, 15], [85, 85], [15, 85]];
  const to = [[15, 15], [85, 15], [93, 62], [7, 90]];
  return strokes(lattice.warp({ from, to }));
});
```

## m.trim()

<include>/_sig/Material.trim.mdx</include>

Cuts a length off each open chain's two ends, by arc length. This makes gaps where strokes meet. It makes a taper that starts short of a corner, and a hatch that stops before the boundary. Lengths are the material's own coordinates, as `oscillate` and `thicken` take them.

A closed chain has no ends and comes through whole. A chain with nothing left after the cut draws nothing. Junctions are an error, as they are for `along` and `resample`.

The vertices between the two cuts are the same vertices, with the same ids. Each new end is a fresh vertex, and the transfer policies give it its columns. The edge it sits on keeps the lineage of the edge the cut divided.

```ts live
import { sketch, strokes, circle, line, append } from 'occlude';

export default sketch({ aspect: [2, 1] }, (t) => {
  const b = t.bounds();
  const disc = circle(0.5 * b.w, 0.5 * b.h, 0.44 * b.h);
  const rules = append(...t.times(40, (k, u) => t.material(line(0, (0.02 + 0.96 * u) * b.h, b.w, (0.02 + 0.96 * u) * b.h))));
  const inside = t.within(rules, disc);
  return [
    strokes(inside.trim({ start: 0.06 * b.h, end: 0.06 * b.h })),
    strokes(t.material(disc), { pen: 'stabilo-88-blue' }),
  ];
});
```

## m.oscillate()

<include>/_sig/Material.oscillate.mdx</include>

<AutoTypeTable path="../occlude/src/oscillate.ts" name="OscillateOpts" />

Swings each chain from side to side as it goes. `wavelength` is the distance along the chain for one cycle and `amplitude` how far it swings. Both are numbers or fields, so tone can drive them. The result keeps the source's point columns and its edge columns, and each new span reads the source edge it starts on. A swing makes the chain longer. An edge column with the `'distribute'` policy has no length left to share over, and `oscillate` refuses one by name. The [material](/docs/reference/material#what-keeps-a-column) page holds the whole table.

```ts live
import { sketch, strokes, line } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => t.times(7, (k, u) => strokes(t.sample(line(8, 12 + u * 76, 92, 12 + u * 76), { count: 80 }).oscillate({ wavelength: 6 + u * 14, amplitude: 1 + u * 3 }))));
```

## m.coil()

<include>/_sig/Material.coil.mdx</include>

<AutoTypeTable path="../occlude/src/coil.ts" name="CoilOpts" />

Winds each chain into a coil. `oscillate` swings from side to side and crosses the chain twice a turn. A coil never crosses it: the loop goes round, and the chain stays inside it. `radius` is how far the loop reaches, so the coil is twice that wide. `pitch` is the arc length of one turn. Both are numbers or fields, so tone can drive them. A closed chain winds a whole number of turns, and the seam does not step.

Below, one wave winds into a coil. The radius grows along the wave and the pitch shrinks. The loops run open at the left and overlap at the right.

```ts live
import { sketch, strokes, curve } from 'occlude';

export default sketch({ aspect: [2, 1] }, (t) => {
  const wave = curve(t.times(60, (k, u) => [12 + u * 176, 50 + 22 * Math.sin(u * Math.PI * 2)]), { closed: false });
  return strokes(wave.coil({ radius: (x) => 1 + 9 * (x / 200), pitch: (x) => 14 - 11 * (x / 200) }));
});
```

## m.interlace()

<include>/_sig/Material.interlace.mdx</include>

<AutoTypeTable path="../occlude/src/interlace.ts" name="InterlaceOpts" />

At every crossing of two edges that do not share a vertex, it decides the strand on top. Then it removes `gap` of the other strand around the crossing. `over(c)` reads one crossing. `c.x` and `c.y` are where it happens, and `c.chainA` and `c.chainB` are the two chain numbers. Return true to put chain A on top. The default alternates. The result is ordinary material.

```ts live
import { sketch, strokes, circle, append, add, mul, fromAngle } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const rings = append(...t.times(5, (k) => t.sample(circle(add([50, 50], mul(fromAngle(k * 1.26), 18)), 26), { count: 120 })));
  return strokes(rings.interlace({ gap: 3 }));
});
```

## m.envelope()

<include>/_sig/Material.envelope.mdx</include>

The curve that a family of chains is tangent to: where each chain crosses the next one, in stored order. A denser family gives a closer curve. Each vertex carries a `member` column, the index of the family member that crossed there. Two chains that share an endpoint meet without crossing and add nothing.

```ts live
import { sketch, strokes, line, append } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const chords = append(...t.times(28, (k, u) => t.material(line(10 + u * 80, 90, 10, 10 + u * 80))));
  return [strokes(chords, { pen: 'pigma-005-black' }), strokes(chords.envelope(), { pen: 'stabilo-88-blue' })];
});
```

## m.thicken()

<include>/_sig/Material.thicken.mdx</include>

<AutoTypeTable path="../occlude/src/thicken.ts" name="ThickenOpts" />

Turns points and edges into an area. Each edge becomes a ribbon of width twice `radius`. Each loose point becomes a disc. Parts that overlap join. The result is a boundary material. Fill it with `polygon(body, { fill })`, and the holes stay holes. Or trace it with `strokes`. `thicken` is also a method on a point selection and an edge selection.

```ts live
import { sketch, strokes, polygon, fill, mm, connect } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 6 }, (t) => {
  const tree = connect.tree(t.scatter({ spacing: 16 }));
  const body = tree.thicken({ radius: 2.5 });
  return polygon(body, { fill: fill('hatch', { angle: 60, spacing: mm(1.2) }) });
});
```

## segmentRuns() · banding() · extent()

<include>/_sig/segmentRuns.mdx</include>
<include>/_sig/banding.mdx</include>
<include>/_sig/extent.mdx</include>

`segmentRuns(m, key)` classifies every edge and gathers consecutive equal keys into runs, chain by chain. Together the runs draw every edge once. The key reads the EDGE, in stored order. It can use the edge's own columns, and also `e.a` and `e.b`. A vertex attribute needs an interpretation before it can own an edge: the start's, the end's or their mean are different drawings. `banding({ min, max, count })` maps a value to one of `count` bands. `extent(column)` is `[min, max]`.

```ts live
import { sketch, stroke, circle, segmentRuns, banding, extent } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const ring = t.sample(circle(50, 50, 38), { count: 60 }).attribute('h', (p) => p.y);
  const [lo, hi] = extent(ring.attrs.h);
  const band = banding({ min: lo, max: hi, count: 3 });
  const pens = ['pigma-05-black', 'stabilo-88-blue', 'stabilo-88-green'];
  return segmentRuns(ring, (e) => band((e.a.h + e.b.h) / 2)).map((run) => stroke(run, { pen: pens[run.key] }));
});
```

## symmetry()

<include>/_sig/symmetry.mdx</include>

<AutoTypeTable path="../occlude/src/symmetry.ts" name="SymmetryOptions" />

The seventeen wallpaper groups, as placements. `symmetry(group, { cell, cols, rows })` answers with plain transform records, one for each copy of the motif. A record holds the same `{ translate, rotate, scale, origin }` that `group(…)` takes. Draw the motif once and hand each record to `group`. Nothing here draws, and nothing here knows what a motif is. `t.symmetry(group, { cell })` is the same list, with the block sized to cover the drawable.

Read a record as "turn or flip the motif about `origin`, then move it by `translate`". The `origin` of a record is a point. A `group` also takes `'center'` for the middle of its children and `'centroid'` for their area centroid, because `origin` is the one `Origin` type of every pivot. A rotation is `rotate`. A mirror is a negative `scale` about the right pivot. A glide is a mirror whose `translate` carries the half step along the mirror line. To make the wallpaper one material, give each record to `m.transform` of the motif: `t.symmetry('p6m', { cell: 24 }).map((p) => motif.transform(p))`. The record has the same meaning there as in `group`. A material has no drawable, so the lengths are numbers in its own units.

One cell holds as many placements as the group's point group has members. p1 has one. p2, pm, pg and cm have two. p3 has three. pmm, pmg, pgg, cmm and p4 have four. p3m1, p31m and p6 have six. p4m and p4g have eight. p6m has twelve.

`cell` is `[w, h]` where the lattice is rectangular or oblique, and one length where it is hexagonal (p3, p3m1, p31m, p6, p6m). A square group (p4, p4m, p4g) takes one length, or a pair that is square. A cell of the wrong shape refuses by name. Below, three arcs in one small motif fill the page under p6m, cut to the drawable.

```ts live
import { sketch, group, clip, rect, path } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const b = t.bounds();
  const motif = [
    path().moveTo(1.5, 1.2).arcTo(10.5, 4.2, 13).build(),
    path().moveTo(3.4, 2.6).arcTo(9.2, 7.6, -8).build(),
    path().moveTo(1.0, 4.4).arcTo(6.4, 1.6, 6).build(),
  ];
  return clip(rect(0, 0, b.w, b.h), t.symmetry('p6m', { cell: 26 }).map((p) => group(p, motif)));
});
```

## m.map()

<include>/_sig/Material.map.mdx</include>

Moves every vertex through a point map. The callback reads a vertex and answers where that vertex lands. It gives a position, not a displacement, and that is what marks it apart from `.steps(1, { move })`.

Nothing else changes. The rows keep their order, their ids and their point, edge and face columns. A projection, a fold about a line, a plain shift and a transform of the hyperbolic disk are all this one verb.

Only the vertices move, so a straight edge between two of them stays straight. Resample first (`m.resample({ spacing })`) when the map bends what the two ends cannot show. Below, one band of straight bars at 120 samples each goes round a whirlpool.

```ts live
import { sketch, strokes, line, append, add, mul, fromAngle } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const b = t.bounds();
  const bars = append(...t.times(28, (k, u) => t.sample(line(0, u * 100, 100, u * 100), { count: 120 })));
  return strokes(bars.map((p) => {
    const a = (p.x / 100) * 5.6 + (p.y / 100) * 2.2 - 2.8;
    const r = 5 + p.y * 0.4;
    return add([b.cx, b.cy], mul(fromAngle(a), r));
  }));
});
```
