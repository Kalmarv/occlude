A vector is a pair `[x, y]`. Every function here takes `[x, y]` or `{ x, y }`, so a vertex goes straight in, and returns a new pair. Nothing is changed in place. Angles are in radians, from +x toward +y.

`add`, `sub` and `mul` are the arithmetic; `mul` scales by a number. `unit` is the direction with length 1, and `unit([0, 0])` is `[0, 0]`. `perp` turns a vector a quarter turn. `length` and `distance` measure. `limit` caps a length. `dot` and `cross` are the two products; the sign of `cross(a, b)` says which side of `a` the vector `b` lies on. `fromAngle` and `angleOf` convert between an angle and a unit vector. `sum` and `sumBy` add vectors up.

```ts live
import { sketch, line, circle, add, sub, unit, mul, perp } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const a = [12, 72], b = [88, 32];
  const n = mul(unit(perp(sub(b, a))), 22);
  const mid = mul(add(a, b), 0.5);
  return [line(a[0], a[1], b[0], b[1]), line(mid[0], mid[1], mid[0] + n[0], mid[1] + n[1], { pen: 'stabilo-88-blue' }), circle(mid[0], mid[1], 1.2)];
});
```
