---
title: Fields
description: Seeded randomness, noise, and functions of position that shapes, fills and materials read.
---

A field is a function of position. A scalar field is `(x, y) => number`. A vector field is `(x, y) => [dx, dy]`. A field receives drawable units. Fills, modifiers, `scatter`, `isolines` and `streamlines` read them, so one function can decide tone, spacing and direction in the same drawing.

## curl() · grad() · vectorField()

<include>/_sig/curl.mdx</include>
<include>/_sig/grad.mdx</include>
<include>/_sig/vectorField.mdx</include>

`grad(f)` is the gradient of a scalar field: it points uphill. `curl(f)` is the gradient turned 90°, so it runs along the contours of `f`. `vectorField(fn)` marks your own vector function. Then `rotate` turns its arrows too. At the bottom left, the same east-pointing function is turned 45° twice: plain in green, still east, and marked in blue, turned.

```ts live
import { sketch, line, circle, strokes, curl, grad, vectorField, rotate } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const hill = (x, y) => t.noise(x / 30, y / 30);
  const arrow = (x, y, [dx, dy], len, pen) => { const k = len / Math.hypot(dx, dy); return [line(x, y, x + dx * k, y + dy * k, { pen }), circle(x + dx * k, y + dy * k, 0.6, { pen })]; };
  const arrows = (vf, pen) => t.grid({ cols: 10, rows: 10 }).map((c) => arrow(c.cx, c.cy, vf(c.cx, c.cy), 3.5, pen));
  const plain = rotate((x, y) => [1, 0], 45), marked = rotate(vectorField((x, y) => [1, 0]), 45);
  return [strokes(t.isolines(hill, [-0.4, -0.2, 0, 0.2, 0.4]), { pen: 'pigma-005-black' }), arrows(grad(hill), undefined), arrows(curl(hill), 'stabilo-88-blue'), arrow(8, 92, plain(0, 0), 8, 'stabilo-88-green'), arrow(8, 92, marked(0, 0), 8, 'stabilo-88-blue')];
});
```

## t.within()

<include>/_sig/Toolkit.within.1.mdx</include>
<include>/_sig/Toolkit.within.2.mdx</include>
<include>/_sig/Toolkit.within.3.mdx</include>
<include>/_sig/Toolkit.within.4.mdx</include>

Keeps only what lies inside an area. A field becomes absent outside it, so generators make nothing there and contours stop at the edge. It cuts a material at the boundary. It filters a point selection or a face collection. For faces, `{ faces: 'contained' }` (the default) keeps a face whose whole area is inside. `'centroid'` keeps a face whose centroid is inside. `area` is a shape, a loop of pairs, a face, or a contour material.

```ts live
import { sketch, circle, rect, strokes } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 2 }, (t) => {
  const stripes = (x, y) => Math.sin(x / 3);
  const disc = circle(30, 50, 24);
  const web = t.streamlines((x, y) => [1, 0.4 * Math.sin(y / 8)], { spacing: 4 });
  return [strokes(t.isolines(t.within(stripes, disc), 0)), circle(30, 50, 24, { pen: 'stabilo-88-blue' }), strokes(t.within(web, rect(62, 20, 34, 60))), rect(62, 20, 34, 60, { pen: 'stabilo-88-blue' })];
});
```

## translate() · rotate() · scale()

<include>/_sig/translate.mdx</include>
<include>/_sig/rotate.mdx</include>
<include>/_sig/scale.mdx</include>

Transforms of a field's sampling. `translate` moves it, `rotate` turns it about the origin, and `scale` scales it, with `[sx, sy]` for each axis. The result is a plain function again. A vector field marked with `vectorField` turns its arrows too.

```ts live
import { sketch, circle, strokes, translate, rotate, scale } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const stripes = (x, y) => Math.sin(x / 2.5);
  const disc = (cx, cy, f, pen) => [strokes(t.isolines(t.within(f, circle(cx, cy, 15)), 0), { pen }), circle(cx, cy, 15, { pen: 'pigma-005-black' })];
  return [disc(28, 30, stripes), disc(72, 30, translate(stripes, 4, 0), 'stabilo-88-green'), disc(28, 70, rotate(stripes, 30), 'stabilo-88-blue'), disc(72, 70, scale(stripes, 2), 'stabilo-88-green')];
});
```

## t.isolines()

<include>/_sig/Toolkit.isolines.mdx</include>

<AutoTypeTable path="../occlude/src/isolines.ts" name="IsoOpts" />

The contours where the field is at a value, as one material. Each contour is a chain, or a ring when it closes. Every edge carries its `level`. Give one value or a list of them. `strokes(m)` draws them, `polygon(m)` fills a level set with its holes, and `m.edges.groupBy((e) => e.attrs.level)` splits the levels (see [Selections](/docs/reference/selections)).

```ts live
import { sketch, strokes } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 2 }, (t) => {
  const ground = (x, y) => t.noise(x / 28, y / 28);
  return t.isolines(ground, [-0.4, -0.2, 0, 0.2, 0.4]).edges.groupBy((e) => e.attrs.level).map((sel) => strokes(sel, { pen: sel.key > 0 ? 'stabilo-88-blue' : undefined }));
});
```

## distanceTo()

<include>/_sig/distanceTo.mdx</include>

A signed distance field from a boundary: positive inside, zero on it, negative outside. `t.isolines(d, 2)` is a ring 2 units inside the boundary, and `t.isolines(d, -2)` a halo 2 units outside. There is no separate offset function. The boundary is loops, contour records, a face, or a chain material.

```ts live
import { sketch, strokes, ngon, distanceTo } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const d = distanceTo(t.material(ngon(50, 50, 5, 34)));
  return strokes(t.isolines(d, [-6, -3, 0, 3, 6, 9, 12]));
});
```

## t.streamlines()

<include>/_sig/Toolkit.streamlines.mdx</include>

<AutoTypeTable path="../occlude/src/streamlines.ts" name="StreamOpts" />

Evenly spaced flow lines of a vector field, as one material of open chains. A line stops at the edge of the drawable, at a `within` bound, and half a spacing from other lines. Lines never cross or bunch. `spacing` is a length or a field of lengths. A field of lengths turns density into tone. The result does not read the seed.

```ts live
import { sketch, strokes, curl, mm } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 4 }, (t) => strokes(t.streamlines(curl((x, y) => t.noise(x / 35, y / 35)), { spacing: mm(2.5) })));
```

## t.ridges()

<include>/_sig/Toolkit.ridges.mdx</include>

<AutoTypeTable path="../occlude/src/ridges.ts" name="RidgeOpts" />

The crest lines of a scalar field: where the field is at a maximum across the line. Contours show where the field is at a height. Ridges show where it runs along a top. Each crest is a chain, and each vertex carries `strength`, how sharply the ground falls to either side, and `height`. The result has no threshold. Filter by `strength` (see [Selections](/docs/reference/selections)) to keep the crests that earn ink. Valleys are the ridges of the negated field.

```ts live
import { sketch, strokes } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 6 }, (t) => {
  const ground = (x, y) => t.noise(x / 22, y / 22);
  const crests = t.ridges(ground);
  return [strokes(t.isolines(ground, [-0.3, 0, 0.3]), { pen: 'stabilo-88-blue' }), strokes(crests.points.filter((p) => p.strength > 0.004).inducedEdges())];
});
```
