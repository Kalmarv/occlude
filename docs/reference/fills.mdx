A fill is texture inside a closed shape: parallel lines, crossed lines, dots, nested contours, or solid ink. Pass it through the shape's `fill` option. A filled shape is opaque: it hides what lies beneath it. The outline uses the shape's `pen`. The fill uses the same pen unless `fillPen` names another one.

## fill()

<include>/_sig/fill.3.mdx</include>

A built-in pattern by name, with its parameters in one object. Spacing is a length. A bare number is drawable units. `mm()` is the usual choice, because the gap between lines is what reads as tone. Angle is in degrees from the x axis.

| Pattern | Parameters | Marks |
|---|---|---|
| `'hatch'` | `angle`, `spacing`, `offset`, `align` | parallel lines |
| `'crosshatch'` | `angles`, `spacing`, `offset`, `align` | one hatch pass per angle |
| `'stipple'` | `density` 0 to 1, `minDist` | dots, each one a pen tap |
| `'contour'` | `spacing`, `connectors` | nested loops that follow the boundary, joined into long runs |
| `'solid'` | `angle` | rows at 0.9 nib widths, so they overlap |

```ts live
import { sketch, circle, fill, mm } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => [
  circle(27, 27, 20, { fill: fill('hatch', { angle: 45, spacing: mm(1.2) }) }),
  circle(73, 27, 20, { fill: fill('crosshatch', { angles: [0, 60, 120], spacing: mm(1.6) }) }),
  circle(27, 73, 20, { fill: fill('stipple', { density: 0.6 }) }),
  circle(73, 73, 20, { fill: fill('contour', { spacing: mm(1.5) }) }),
]);
```

## align

`align: 'paper'` (the default) anchors a hatch to the page. One ruling covers the sheet, and every shape samples it where it sits. Two shapes side by side share one ruling, so the marks line up across the join. `align: 'shape'` anchors the ruling to the shape's own centre and axes. Every shape carries the same marks, and the ruling turns with the shape.

```ts live
import { sketch, rect, fill, mm } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => t.grid({ cols: 4, rows: 4, gap: 3 }).map((c) => rect(c.x, c.y, c.w, c.h, { rotate: c.i * 10, origin: [c.cx, c.cy], fill: fill('hatch', { angle: 0, spacing: mm(1.4), align: c.j < 2 ? 'paper' : 'shape' }) })));
```

## fillPen · stroke

The outline and the texture can use different pens. `fillPen` names the pen for the texture. `stroke: false` draws no outline and leaves the texture alone.

```ts live
import { sketch, ngon, fill, mm } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => [ngon(32, 50, 6, 26, { fill: fill('hatch', { angle: 30, spacing: mm(1.5) }), fillPen: 'stabilo-88-blue' }), ngon(72, 50, 6, 22, { fill: fill('solid'), stroke: false, pen: 'stabilo-88-blue' })]);
```

## A custom fill

<AutoTypeTable path="../occlude/src/fillModule.ts" name="FillRegion" />

A fill is a function of the region: `(region, ctx) => strokes`. `region.bbox` is the bounding box in millimetres, `region.contains(x, y)` the point test, and `ctx.rnd()` the seeded random stream. It runs during the render, for that one shape, and returns strokes in paper millimetres as records: `{ type: 'line', x1, y1, x2, y2 }`, `{ type: 'arc', cx, cy, r, start, sweep }`, `{ type: 'cubic', … }` or `{ type: 'polyline', pts }`. The engine clips them to the region and occludes them like every other mark. Use `ctx.rnd()`, not `Math.random()`, so the fill follows the seed.

```ts live
import { sketch, circle } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => circle(50, 50, 40, {
  fill: (region, ctx) => {
    const { x, y, w, h } = region.bbox;
    const out = [];
    for (let i = 0; i < 320; i++) {
      const cx = x + ctx.rnd() * w, cy = y + ctx.rnd() * h;
      if (region.contains(cx, cy)) out.push({ type: 'arc', cx, cy, r: 0.2 + ctx.rnd() * 1.4, start: 0, sweep: Math.PI * 2 });
    }
    return out;
  },
}));
```

## rulings()

<include>/_sig/rulings.mdx</include>

The line generator under hatch, crosshatch and solid, for fills of your own. It returns parallel lines across the region's bounding box. Spacing is in paper millimetres here, so scale a declared length with `ctx.len`.

```ts live
import { sketch, rect, rulings } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => rect(15, 15, 70, 70, {
  fill: (region, ctx) => [...rulings(region, { spacing: 2.5, angle: 20 }), ...rulings(region, { spacing: 2.5, angle: 110, offset: 1 })],
}));
```

## fillAsset()

<include>/_sig/fillAsset.mdx</include>

A fill as a value: declared parameters, with their defaults, plus a generator. `fill(asset, params)` uses it, with `params` over the defaults. The studio's Fills page stores fill files in the same shape, and a fill file imports nothing but occlude.

```ts live
import { sketch, circle, fill, fillAsset, rulings } from 'occlude';

const combs = fillAsset({
  params: { spacing: 2, angle: 15 },
  generate: (region, params, ctx) => rulings(region, { spacing: params.spacing, angle: params.angle }),
});

export default sketch({ aspect: [1, 1] }, (t) => [circle(30, 50, 24, { fill: fill(combs) }), circle(70, 50, 24, { fill: fill(combs, { spacing: 1, angle: 105 }) })]);
```
