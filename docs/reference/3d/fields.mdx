---
title: Surface fields
description: "Light, gradient, across and curvature: the fields that surface hatch reads."
---

A surface field is a function of a surface location. The location has `position`, `normal`, `uv`, `tangentU` and `tangentV`. It also has the attributes of the point, face and corner under it. A direction field returns a vector, and the consumer projects it onto the tangent plane. A tone field returns 0 for light and 1 for dark. `t.hatch` reads both.

## light()

<include>/_sig/3d.light.mdx</include>

A tone recipe: a direction, an ambient floor, and a ramp. It returns a field that is 0 where the surface faces the light and 1 where it faces away.

```ts live
import { sketchAsync, pen, mm } from 'occlude';
import { sphere, light, view, orthographic } from 'occlude/3d';

export default sketchAsync({ aspect: [1, 1], seed: 42, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#56626A' }) } }, async (t) => {
  const ball = sphere(1.5, { segments: 32, rings: 16 });
  const sun = light({ direction: [-1, -2, 2], ambient: 0.1, ramp: 'smooth' });
  const marks = await t.hatch(ball, { spacing: 0.12, direction: (s) => s.tangentU, tone: sun, stroke: 'shade' });
  return view([ball, marks], { camera: orthographic({ eye: [4, -6, 3], span: 4.2 }), stroke: 'ink', creaseAngle: 180 });
});
```

## gradient() · across()

<include>/_sig/3d.gradient.mdx</include>
<include>/_sig/3d.across.mdx</include>

`gradient(scalar)` is the direction of the fastest rise of a scalar field, for each triangle. `across(direction)` turns a direction field a quarter turn on the surface, so the lines run across it. Meridians and parallels on a sphere are the gradient of height and its across.

```ts live
import { sketchAsync, pen, mm } from 'occlude';
import { sphere, gradient, across, light, view, perspective } from 'occlude/3d';

export default sketchAsync({ aspect: [1, 1], seed: 42, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }), warm: pen({ width: mm(0.18), color: '#A84932' }), cool: pen({ width: mm(0.18), color: '#2A6F8A' }) } }, async (t) => {
  const ball = sphere(1.6, { segments: 32, rings: 16 });
  const height = gradient((s) => s.position[2]);
  const sun = light({ direction: [-1, -2, 2], ambient: 0.1, ramp: 'smooth' });
  const meridians = await t.hatch(ball, { spacing: 0.12, direction: height, tone: (s) => 0.25 + 0.75 * sun(s), stroke: 'warm' });
  const parallels = await t.hatch(ball, { spacing: 0.12, direction: across(height), tone: (s) => Math.max(0, 1.6 * sun(s) - 0.6), stroke: 'cool' });
  return view([ball, meridians, parallels], { camera: perspective({ eye: [4, -6, 3], fovDegrees: 36 }), stroke: 'ink', creaseAngle: 180 });
});
```

## curvature()

<include>/_sig/3d.curvature.mdx</include>

The principal curvature direction of the surface, `'max'` or `'min'`, smoothed over neighbours. Hatch along it follows the form, the way a draughtsman's cross-contours do.

```ts live
import { sketchAsync, pen, mm } from 'occlude';
import { plane, curvature, light, view, orthographic } from 'occlude/3d';

export default sketchAsync({ aspect: [1, 1], seed: 42, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }), shade: pen({ width: mm(0.18), color: '#56626A' }) } }, async (t) => {
  const relief = plane(4, 4).subdivide(4).displace((p) => [0, 0, 0.6 * Math.sin(p.x * 1.6) * Math.cos(p.y * 1.3)]);
  const sun = light({ direction: [-1, -1, 2], ambient: 0.15, ramp: 'smooth' });
  const form = await t.hatch(relief, { spacing: 0.12, direction: curvature('max'), tone: sun, stroke: 'shade' });
  return view([relief, form], { camera: orthographic({ eye: [5, 7, 6], span: 6 }), stroke: 'ink', creaseAngle: 60 });
});
```

## Images on a surface

`t.image(name).surface({ channel, origin, wrap, area, uv })` samples an image over the surface through its chart, and returns a tone field like `light`. Combine fields in plain JavaScript: `(s) => sun(s) * ivy(s)` multiplies a light by an image. The marks are lines for the plotter, never a raster.

```ts live
import { sketchAsync, pen, mm } from 'occlude';
import { plane, view, orthographic } from 'occlude/3d';

export default sketchAsync({ aspect: [1, 1], seed: 42, pens: { ink: pen({ width: mm(0.2), color: '#18202A' }) } }, async (t) => {
  const sheet = plane(6, 4).subdivide(3).displace((p) => [0, 0, 0.3 * Math.sin(p.x * 0.9)]);
  const ivy = t.image('ivy.png').surface({ channel: 'dark', area: 0.01 });
  const marks = await t.hatch(sheet, { direction: [1, 0.35, 0], spacing: 0.07, tone: ivy });
  return view([sheet, marks], { camera: orthographic({ eye: [1, -6, 7], target: [0, 0, 0], span: 6.5 }), stroke: 'ink' });
});
```
