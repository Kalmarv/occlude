The 3D words come from `occlude/3d`. You build geometry in world units and edit it as immutable values. Every edit returns a new value and keeps the old one. Every example here ends with `view`. It projects the geometry into the drawable. See [View](/docs/reference/3d/view).

## plane()

<include>/_sig/3d.plane.mdx</include>

A flat quad in XY, centred at the origin, with one face. `.subdivide(levels)` splits it into a grid of quads.

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => view(plane(4, 3).subdivide(2), { camera: orthographic({ eye: [4, 6, 5], span: 6 }), stroke: 'ink', creaseAngle: 0 }));
```

## box()

<include>/_sig/3d.box.mdx</include>

A box of one size, or of a `[x, y, z]` size, centred at the origin.

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => view([box(1.6), box([0.8, 0.8, 2.6]).translate([1.6, 0.6, 0.5])], { camera: orthographic({ eye: [5, 7, 4], target: [0.6, 0.3, 0.4], span: 5 }), stroke: 'ink' }));
```

## sphere()

<include>/_sig/3d.sphere.mdx</include>

A sphere of `segments` around and `rings` from pole to pole. `creaseAngle: 180` on the view draws no fold between its faces, so only the silhouette and the boundaries show.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => view([sphere(1.2, { segments: 32, rings: 16 }), sphere(0.5, { segments: 16, rings: 8 }).translate([1.6, 0.8, -0.4])], { camera: orthographic({ eye: [5, 6, 4], span: 4.6 }), stroke: 'ink', creaseAngle: 180 }));
```

## cylinder() · cone()

<include>/_sig/3d.cylinder.mdx</include>
<include>/_sig/3d.cone.mdx</include>

Both stand on the Z axis, from `-height / 2` to `+height / 2`. The cone's apex is at the top. `caps: false` leaves the rims open.

```ts live
import { sketch, pen, mm } from 'occlude';
import { cylinder, cone, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => view([cylinder(0.7, 2, { segments: 24 }).translate([-1, 0, 0]), cone(0.8, 2, { segments: 24 }).translate([1.2, 0, 0])], { camera: orthographic({ eye: [5, 7, 4], span: 5.5 }), stroke: 'ink', creaseAngle: 180 }));
```

## torus()

<include>/_sig/3d.torus.mdx</include>

A ring in XY. `radius` is the centreline and `tubeRadius` the thickness, so the outer radius is their sum.

```ts live
import { sketch, pen, mm } from 'occlude';
import { torus, view, perspective } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => view(torus(1.2, 0.4, { segments: 36, tubeSegments: 14 }), { camera: perspective({ eye: [3, 4, 2.4], fovDegrees: 40 }), stroke: 'ink', creaseAngle: 180 }));
```

## translate() · rotate() · scale()

A mesh is born at the world origin. `.translate(triple)`, `.rotate(degreesTriple)` and `.scale(scalarOrTriple)` return new values. They pivot on the object's own origin, and `translate` moves that origin with the object. A `rotate('z', degrees)` form turns about one axis.

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => view(t.times(6, (k) => box([1.6, 0.5, 0.3]).rotate([0, 0, k * 30]).translate([0, 0, k * 0.4])), { camera: orthographic({ eye: [5, 6, 5], target: [0, 0, 1], span: 5 }), stroke: 'ink' }));
```

## subdivide()

`mesh.subdivide(levels)` splits every face and keeps the surface it represents: a quad becomes four quads, a triangle four triangles. Each level doubles the resolution. It does not round a box or smooth anything. Here the same wave moves three planes at levels 1, 2 and 3. The view draws every fold, so the grids show.

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const wave = (p) => [0, 0, 0.35 * Math.sin(p.x * 2) * Math.cos(p.y * 2)];
  const sheets = t.times(3, (k) => plane(2.2, 2.2).subdivide(k + 1).displace(wave).translate([k * 2.6 - 2.6, 0, 0]));
  return view(sheets, { camera: orthographic({ eye: [1, 6, 5], target: [0, 0, 0], span: 9 }), stroke: 'ink', creaseAngle: 0 });
});
```

## displace()

`mesh.displace(field)` moves each point by a triple from the field, or by a number along the point's normal. One pass, one new mesh.

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], seed: 4, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => view(plane(5, 5).subdivide(4).displace((p) => [0, 0, 0.7 * t.noise(p.x * 0.6, p.y * 0.6)]), { camera: orthographic({ eye: [6, 8, 5], span: 8 }), stroke: 'ink', creaseAngle: 0 }));
```

## steps()

`mesh.steps(count, rule)` is the frozen edit loop, the same as a material's. The rule reads `current` and writes `next`. The shorthand `{ move, set }` applies to every point, and a numeric `move` follows the vertex normal. Here one rule lifts the middle of a sheet a little on each step. The three sheets are the rule applied 0, 4 and 10 times.

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const sheet = plane(2.2, 2.2).subdivide(3);
  const lift = { move: (p) => [0, 0, 0.06 * Math.max(0, 1 - Math.hypot(p.x, p.y))] };
  const sheets = [0, 4, 10].map((n, k) => sheet.steps(n, lift).translate([k * 2.6 - 2.6, 0, 0]));
  return view(sheets, { camera: orthographic({ eye: [1, 6, 5], target: [0, 0, 0], span: 9 }), stroke: 'ink', creaseAngle: 0 });
});
```

## attribute() · faceAttribute()

`mesh.attribute(name, field)` adds a typed point column, and `faceAttribute` a face column. A hatch recipe's `select` reads face columns, so a column decides what gets hatched.

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#A84932' }) } }, (t) => {
  const tagged = box(2).faceAttribute('top', (f) => f.normal[2] > 0.5);
  return view(tagged, { camera: orthographic({ eye: [5, 7, 5], span: 4.5 }), stroke: 'ink', hatch: { spacing: mm(1.5), angle: 45, stroke: 'shade', select: (f) => f.top === true } });
});
```

## grid()

<include>/_sig/3d.grid.mdx</include>

A regular point grid in model space, centred at the origin: `cols` by `rows`, and `layers` deep, at `spacing`. Each point has `i`, `j` and `k` columns. It is a point domain for placement, so it goes into `instanceOnPoints` or a query batch.

```ts live
import { sketch, pen, mm } from 'occlude';
import { grid, box, instanceOnPoints, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const pts = grid({ cols: 5, rows: 5, layers: 3, spacing: 0.9 });
  const cubes = instanceOnPoints(box(0.3), pts.points, { scale: (p) => 0.4 + 0.6 * ((p.i + p.j + p.k) % 3) / 2 });
  return view(cubes, { camera: orthographic({ eye: [5, 7, 5], span: 6.5 }), stroke: 'ink' });
});
```

## extrude()

`mesh.extrude(faces, offset)` raises a connected face selection as one region. Each connected part of the selection becomes a translated cap, and every boundary edge of the region grows a wall. `offset` is a model vector, or `{ distance }` along the region's mean normal.

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const sheet = plane(4, 4).subdivide(3);
  const middle = sheet.faces.filter((f) => Math.hypot(f.center[0], f.center[1]) < 1.2);
  const raised = sheet.extrude(middle, { distance: 0.7 });
  return view(raised, { camera: orthographic({ eye: [5, 7, 5], span: 6 }), stroke: 'ink', creaseAngle: 20 });
});
```

## Topology

A row knows its neighbours: `point.edges`, `point.adjacent`, `face.points`, `face.edges`, `face.adjacent` and `edge.faces`. A selection has `.adjacent()` for one hop out, `.connected()` for everything it reaches, and `.components()` for its pieces. A face selection also has `.boundaryEdges()`. Faces are neighbours through a shared edge, not a shared corner.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#A84932' }) } }, (t) => {
  const ball = sphere(1.4, { segments: 24, rings: 12 });
  const seed = ball.faces.filter((f) => f.normal[2] > 0.95);
  const ring = seed.adjacent().subtract(seed).adjacent().subtract(seed);
  const tagged = ball.faceAttribute('ring', (f) => ring.has(f));
  return view(tagged, { camera: orthographic({ eye: [3, 4, 6], span: 4 }), stroke: 'ink', creaseAngle: 180, hatch: { spacing: mm(1.2), angle: 45, stroke: 'shade', select: (f) => f.ring === true } });
});
```

## Forces

Inside a `steps` rule, a force is a field of the point that returns a displacement. `force.attract(target, { strength })` pulls toward a world point. `force.plane({ origin, normal, side })` pushes a point back to one side of a plane. `force.project(query)` pulls onto a surface. `force.sum` adds them.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, force, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const ceiling = force.plane({ origin: [0, 0, 0.6], normal: [0, 0, 1], side: 'below' });
  const pull = force.attract([0, 0, -1.5], { strength: 0.12 });
  const squashed = sphere(1.3, { segments: 32, rings: 16 }).steps(6, (cur, next) => next.move(cur.points, force.sum(ceiling, pull)));
  return view(squashed, { camera: orthographic({ eye: [5, 6, 3], span: 4.2 }), stroke: 'ink', creaseAngle: 180 });
});
```

## polyline() · curve() · circle()

<include>/_sig/3d.polyline.mdx</include>
<include>/_sig/3d.curve.mdx</include>
<include>/_sig/3d.circle.mdx</include>

Curves are polygonal paths in 3D. `polyline` takes points, `curve` samples a function of `t` from 0 to 1, and `circle` is a closed profile in XY. A curve in a view is a wire: meshes hide it, and it hides nothing.

```ts live
import { sketch, pen, mm } from 'occlude';
import { curve, box, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => {
  const helix = curve((u) => [Math.cos(u * 12) * 1.4, Math.sin(u * 12) * 1.4, u * 3 - 1.5], { segments: 160 });
  return view([helix, box([1.2, 1.2, 3])], { camera: orthographic({ eye: [5, 6, 3], span: 5 }), stroke: 'ink' });
});
```

## revolve()

<include>/_sig/3d.revolve.mdx</include>

Turns a profile in the XZ plane around the Z axis. A profile that starts on the axis gives a closed bottom. An open end stays open.

```ts live
import { sketch, pen, mm } from 'occlude';
import { polyline, revolve, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => {
  const vase = revolve(polyline([[0, 0, 0], [0.9, 0, 0], [1.1, 0, 0.8], [0.6, 0, 1.6], [0.8, 0, 2.2]]), { segments: 28 });
  return view(vase, { camera: orthographic({ eye: [5, 6, 3], target: [0, 0, 1], span: 4 }), stroke: 'ink', creaseAngle: 180 });
});
```

## sweep()

<include>/_sig/3d.sweep.mdx</include>

Carries an XY profile along a path: a circle for a tube, an open polyline for a ribbon. `scale` and `twist` change the profile along the way.

```ts live
import { sketch, pen, mm } from 'occlude';
import { circle, curve, sweep, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => {
  const path = curve((u) => [Math.cos(u * Math.PI * 2) * 1.2, Math.sin(u * Math.PI * 2) * 1.2, u * 2.4 - 1.2], { segments: 48 });
  return view(sweep(circle(0.22, { segments: 10 }), path), { camera: orthographic({ eye: [5, 6, 3], span: 4.5 }), stroke: 'ink', creaseAngle: 180 });
});
```

## instanceOnPoints()

<include>/_sig/3d.instanceOnPoints.mdx</include>

Places one prototype mesh at every point of a point set. `scale`, `rotate` and `offset` are constants or fields on the source point rows. `alignAxis('z', normal)` gives the rotation that stands the prototype on a surface. `.realize()` makes one ordinary mesh from all the copies, for the mesh operations.

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, cone, alignAxis, instanceOnPoints, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], seed: 42, pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => {
  const ground = plane(5).subdivide(3).displace((p) => [0, 0, 0.5 * t.noise(p.x * 0.5, p.y * 0.5)]);
  const sites = t.scatter(ground, { spacing: 0.55, maxPoints: 50, maxAttempts: 3000 });
  const trees = instanceOnPoints(cone(0.14, 0.7, { segments: 8 }).translate([0, 0, 0.35]), sites.points, { rotate: (p) => alignAxis('z', p.sample.normal) });
  return view([ground, trees], { camera: orthographic({ eye: [6, 8, 6], target: [0, 0, 0.2], span: 8 }), stroke: 'ink' });
});
```

## t.sample() · t.scatter() on a mesh

Both take a mesh and return points on its surface. Each row has a `.sample`: the position, the triangle `normal`, the `face` and the barycentric weights. `t.sample(mesh, { count })` places `count` points weighted by area. `t.scatter(mesh, { spacing })` keeps points at least `spacing` apart in world units. `weight: (face) => number` biases both.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, instanceOnPoints, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], seed: 7, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const ball = sphere(1.2, { segments: 32, rings: 16 });
  const pts = t.scatter(ball, { spacing: 0.32, maxPoints: 120, maxAttempts: 4000, weight: (f) => (f.normal[2] > 0 ? 1 : 0) });
  const studs = instanceOnPoints(sphere(0.07, { segments: 8, rings: 4 }), pts.points);
  return view([ball, studs], { camera: orthographic({ eye: [4, 5, 5], span: 3.6 }), stroke: 'ink', creaseAngle: 180 });
});
```
