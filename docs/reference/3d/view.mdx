`view` projects geometry through a camera into the drawable and computes the visible lines. From there the result is ordinary ink: strokes, clips, masks and pens apply.

## view()

<include>/_sig/3d.view.1.mdx</include>

Projects geometry through a camera and returns the visible lines as ink. It takes one object or a list, a camera, and the drawing options. The default ink is the visible boundaries, the silhouettes, and the creases sharper than `creaseAngle` (30°). `pen` names the pen. The ink stays inside the drawable, or inside the view's `viewport`. A line stops at the edge of that frame.

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, sphere, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => view([box(1.5), sphere(0.7, { segments: 24, rings: 12 }).translate([1.4, 0.8, 0.9])], { camera: orthographic({ eye: [5, 7, 4], target: [0.5, 0.4, 0.4], span: 5 }), pen: 'ink' }));
```

## orthographic() · perspective()

<include>/_sig/3d.orthographic.mdx</include>
<include>/_sig/3d.perspective.mdx</include>

The two cameras. `orthographic` takes an `eye`, a `target` and a `span`, the width of the world it shows. `perspective` takes an `eye`, a `target` and `fovDegrees`. Both default the target to the origin.

```ts live
import { sketch, pen, mm, group } from 'occlude';
import { box, view, orthographic, perspective } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => {
  const row = t.times(4, (k) => box(0.8).translate([k * 1.2 - 1.8, 0, 0]));
  return [
    group({ scale: 0.5, origin: [0, 0], translate: [0, 25] }, view(row, { camera: orthographic({ eye: [3, 8, 4], span: 6 }), pen: 'ink' })),
    group({ scale: 0.5, origin: [0, 0], translate: [50, 25] }, view(row, { camera: perspective({ eye: [2, 5, 2.5], fovDegrees: 50 }), pen: 'ink' })),
  ];
});
```

## oblique()

<include>/_sig/3d.oblique.mdx</include>

A perspective camera with a `shift`. The shift moves the frame off the optical axis. It is a fraction of the frame, to the right and up. `shift: [0, 0.4]` lifts the frame by four tenths of its height, and the drawing moves down by the same amount. The eye and the direction of view stay where they are. So a level camera keeps the world verticals parallel, and the frame still covers what a tilt would reach. This is the architect's two-point view. `shift: [0, 0]` gives the same lines as `perspective`.

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, view, oblique } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => {
  const town = t.times(5, (k) => box([1.8, 1.8, 5 + k * 1.3]).translate([k * 2.6 - 5.2, k % 2 ? 1.4 : -1.4, (5 + k * 1.3) / 2]));
  return view(town, { camera: oblique({ eye: [0, -16, 0.6], target: [0, 0, 0.6], fovDegrees: 50, shift: [0, 0.4] }), pen: 'ink' });
});
```

## creaseAngle

The view draws a fold between two faces when the angle between them is larger than `creaseAngle`. The view's value is the default. An object's own value, `sphere(1, { creaseAngle: 180 })` or `style(mesh, { creaseAngle })`, wins for that object. 180 draws no creases, so a curved mesh shows only its silhouette. 0 draws every fold.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => view([sphere(1, { segments: 16, rings: 8, creaseAngle: 0 }).translate([-1.2, 0, 0]), sphere(1, { segments: 16, rings: 8, creaseAngle: 180 }).translate([1.2, 0, 0])], { camera: orthographic({ eye: [4, 7, 3], span: 5 }), pen: 'ink' }));
```

## suggestive

Suggestive contours are the lines where the surface almost turns away from the eye. They are the silhouette that a nearby viewpoint shows. The two sheets below are one dune field, drawn twice. The outline alone says nothing about the sand. The suggestive contours draw every crest. The reading is from DeCarlo, Finkelstein, Rusinkiewicz and Santella (2003).

`suggestive: {}` draws them, on one object or on the view for all of them. The default, `false`, draws none. An object's own value wins, so `style(mesh, { suggestive: false })` keeps one object plain. `threshold` is the derivative test: a larger number keeps fewer lines, and 12 is the default. The number is a ratio of the object's own size, so a model of any scale reads the same. These lines belong to one view, not to the model, so they move with the camera. The view classifies them with the silhouettes: `lines.visible.kind('suggestive')` and `lines.hidden.kind('suggestive')` select them, and the default drawing gives them the object's pen.

```ts live
import { sketch, pen, mm, strokes } from 'occlude';
import { plane, view, orthographic, style } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), shape: pen({ width: mm(0.25), color: '#A84932' }) } }, () => {
  // Crests running diagonally, over a slow drift.
  const dunes = (p) => 0.12 * Math.sin(4.16 * p.x + 3.12 * p.y + 0.4)
    + 0.054 * Math.sin(5.62 * p.x - 3.79 * p.y + 1.9)
    + 0.32 * Math.sin(0.55 * p.x + 0.35 * p.y + 1.1);
  const sand = plane(6, 4, { creaseAngle: 180 }).subdivide(6).displace((p) => [0, 0, dunes(p)]);
  return view(
    [sand.translate([0, 0, 2.4]).withKey('plain'), style(sand.translate([0, 0, -2.4]).withKey('read'), { suggestive: {} })],
    { camera: orthographic({ eye: [6.87, -8.19, 5.45], target: [0, 0, 0], span: 9.5 }) },
    (lines) => [
      strokes(lines.visible.kind('silhouette', 'boundary'), { stroke: 'ink' }),
      strokes(lines.visible.kind('suggestive'), { stroke: 'shape' }),
    ],
  );
});
```

## hatch

`hatch: { spacing, angle?, offset?, pen?, select? }` on the view adds a family of hatch lines over the faces. `spacing` is a paper length and `angle` is a paper angle in degrees, clockwise on the sheet. `select` is a face selection of the mesh, or a test on its face rows. The test gets the mesh's own row, so `roof.has(f)` works. `hatch` also takes the 2D fill: `fill('hatch', { angle, spacing, offset? })` is one recipe, and `fill('crosshatch', { angles, spacing })` is one recipe for each angle. A fill that is not parallel lines is refused, and so is a spacing field of the paper. A recipe without a pen uses the object's `fillPen`, then its `pen`, then the view's. The lines lie flat on the paper: for lines that follow the surface, see [t.hatch](/docs/reference/3d/surface#thatch).

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#A84932' }) } }, (t) => view(box([2.4, 1.6, 1.2]), { camera: orthographic({ eye: [5, 7, 5], span: 4.5 }), pen: 'ink', hatch: { spacing: mm(1.6), angle: 45, pen: 'shade', select: (f) => f.normal[2] > 0.5 } }));
```

## crosshatch

A list of recipes is several families at once. Two recipes over the same faces, at angles 90° apart, are a crosshatch. Each family keeps its own pen.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#56626A' }) } }, (t) => view(sphere(1.4, { segments: 32, rings: 16 }), { camera: orthographic({ eye: [5, 6, 4], span: 4 }), pen: 'ink', creaseAngle: 180, hatch: [{ spacing: mm(1.4), angle: 30, pen: 'shade', select: (f) => f.normal[2] < 0.2 }, { spacing: mm(1.4), angle: 120, pen: 'shade', select: (f) => f.normal[2] < -0.3 }] }));
```

## sections

`sections: [{ origin, normal, pen? }]` on the view cuts the mesh with planes in model space and draws the cut lines. Each section can name its own pen. A section is the line where a plane cuts the mesh. It does not change the mesh.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), section: pen({ width: mm(0.2), color: '#A84932' }) } }, (t) => view(sphere(1.5, { segments: 36, rings: 18 }), { camera: orthographic({ eye: [5, 6, 4], span: 4.4 }), pen: 'ink', creaseAngle: 180, sections: [-1, -0.5, 0, 0.5, 1].map((z) => ({ origin: [0, 0, z], normal: [0, 0, 1], pen: 'section' })) }));
```

## The view callback

`view(geometry, options, (lines) => tree)` replaces the default ink. `lines.visible` and `lines.hidden` are the classified line intervals. Each has `.kinds`, a set from `boundary`, `silhouette`, `crease`, `wire`, `marked`, `hatch`, `section`, `intersection`, `isoline`, `trace`, `suggestive` and `mapped`. Each reads the columns of its source as properties, `c.rim`, and `c.attributes` is the same record. `lines.visible.curves()` joins the intervals end to end into chains in drawable units, and `contours()` gives the closed chains. Thus `polygon(lines.visible.kind('silhouette'), { fill })` fills the outline of the object. `lines` holds only the folds that `creaseAngle` keeps, as the default ink does. A flatter fold is not in `lines`. `strokes` accepts them directly. `t.within(lines.hidden, area)` keeps the lines in an area and cuts the other lines at its edge. The result is projected lines again, so `strokes`, `kind` and `filter` read it. Keep the callback pure, because it can run again when the camera changes.

```ts live
import { sketch, pen, mm, strokes } from 'occlude';
import { box, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), ghost: pen({ width: mm(0.15), color: '#8A94A6' }) } }, (t) => view(
  [box(1.5), box(1).translate([1.3, 1, 0.9])],
  { camera: orthographic({ eye: [5, 7, 4], target: [0.5, 0.4, 0.4], span: 5 }) },
  (lines) => [strokes(lines.visible, { stroke: 'ink' }), strokes(lines.hidden, { stroke: 'ghost' })],
));
```

## t.toPaper()

<include>/_sig/Toolkit.toPaper.1.mdx</include>
<include>/_sig/Toolkit.toPaper.2.mdx</include>

Where a view puts a world point on the paper. One point in gives one `[x, y]` pair in drawable units. Points in give a material of the projected points. A label or a leader line can then go where the drawing put an object. The camera is the view's own, and a camera the studio committed counts. The pair lands exactly where that view's lines do.

A point behind the eye has no place on the paper. The pair is then two NaN values, and a material leaves that point out.

```ts live
import { sketchAsync, pen, mm, circle, line, label, add, sub, mul, unit } from 'occlude';
import { box, view, orthographic } from 'occlude/3d';

export default sketchAsync({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.35), color: '#18202A' }), note: pen({ width: mm(0.18), color: '#A84932' }) } }, async (t) => {
  const cube = box(2);
  const drawing = view(cube, { camera: orthographic({ eye: [5, 7, 4], span: 7.2 }), pen: 'ink' });
  const callouts = [[[-1, -1, 1], 'A'], [[1, -1, -1], 'B'], [[1, 1, -1], 'C']];
  return [drawing, callouts.map(([corner, name]) => {
    const at = t.toPaper(drawing, corner);
    // The leader runs away from the middle of the sheet, so it never crosses
    // the object it points at.
    const out = mul(unit(sub(at, [t.cx, t.cy])), 14);
    const tip = add(at, out);
    const top = tip[1] + (out[1] < -6 ? -7 : out[1] > 6 ? 2 : -2.5);
    return [circle(at, 1.2, { pen: 'note' }), line(add(at, mul(out, 0.15)), tip, { pen: 'note' }),
      label(name, at[0] + out[0] * 1.1, top, 5, { pen: 'note', align: 'center' })];
  })];
});
```

## style()

<include>/_sig/3d.style.mdx</include>

Sets the drawing of a value: `pen`, `fillPen`, `creaseAngle` and `hatch`. The hatch of an object replaces the hatch of the view for that object, as each 2D polygon has its own fill. It returns the styled value, or a styled list, and keeps the fields it does not name.

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, sphere, style, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), blue: pen({ width: mm(0.3), color: '#2457D6' }) } }, (t) => view([box(1.4), ...style([sphere(0.6, { segments: 20, rings: 10 }).translate([1.3, 0.6, 0.6]), sphere(0.4, { segments: 20, rings: 10 }).translate([-1.1, -0.8, 0.9])], { pen: 'blue', creaseAngle: 180 })], { camera: orthographic({ eye: [5, 7, 4], span: 5 }), pen: 'ink' }));
```

## opaque

A view is ink, not an occluder. It hides nothing that is earlier in the tree, and a second view does not hide the first. Put the meshes that must hide each other in one view. `opaque: true` makes the paper under the view's solids opaque, as `opaque: true` does for a shape. The view then hides the earlier ink there, and its own lines stay visible. A later opaque shape hides the view in the same way.

```ts live
import { sketch, pen, mm, polygon, rect, fill } from 'occlude';
import { box, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), grain: pen({ width: mm(0.15), color: '#8A94A6' }) } }, (t) => [
  polygon(rect(0, 0, t.width, t.height), { fill: fill('hatch', { angle: 90, spacing: mm(1.2) }), stroke: false, pen: 'grain' }),
  view(box([2, 2, 3]), { camera: orthographic({ eye: [6, -9, 5], target: [0, 0, 1.5], span: 7 }), pen: 'ink', opaque: true }),
]);
```
