`view` projects geometry through a camera into the drawable and computes the visible lines. From there the result is ordinary ink: strokes, clips, masks and pens apply.

## view()

<include>/_sig/3d.view.1.mdx</include>

The drawing boundary. It takes one object or a list, a camera, and the drawing options. The default ink is the visible boundaries, the silhouettes, and the creases sharper than `creaseAngle` (30°). `stroke` names the pen.

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, sphere, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => view([box(1.5), sphere(0.7, { segments: 24, rings: 12 }).translate([1.4, 0.8, 0.9])], { camera: orthographic({ eye: [5, 7, 4], target: [0.5, 0.4, 0.4], span: 5 }), stroke: 'ink' }));
```

## orthographic() · perspective()

<include>/_sig/3d.orthographic.mdx</include>
<include>/_sig/3d.perspective.mdx</include>

The two cameras. `orthographic` takes an `eye`, a `target` and a `span`, the width of the world it shows. `perspective` takes an `eye`, a `target` and `fovDegrees`. Both default the target to the origin.

```ts live
import { sketch, pen, mm, group } from 'occlude';
import { box, view, orthographic, perspective } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => {
  const row = t.times(4, (k) => box(0.8).translate([k * 1.2 - 1.8, 0, 0]));
  return [
    group({ scale: 0.5, origin: [0, 0] }, view(row, { camera: orthographic({ eye: [3, 8, 4], span: 6 }), stroke: 'ink' })),
    group({ scale: 0.5, origin: [0, 0], translate: [50, 50] }, view(row, { camera: perspective({ eye: [2, 5, 2.5], fovDegrees: 50 }), stroke: 'ink' })),
  ];
});
```

## creaseAngle

The view draws a fold between two faces when the angle between them is larger than `creaseAngle`. The view's value is the default. An object's own value, `sphere(1, { creaseAngle: 180 })` or `style(mesh, { creaseAngle })`, wins for that object. 180 draws no creases, so a curved mesh shows only its silhouette. 0 draws every fold.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => view([sphere(1, { segments: 16, rings: 8, creaseAngle: 0 }).translate([-1.2, 0, 0]), sphere(1, { segments: 16, rings: 8, creaseAngle: 180 }).translate([1.2, 0, 0])], { camera: orthographic({ eye: [4, 7, 3], span: 5 }), stroke: 'ink' }));
```

## hatch

`hatch: { spacing, angle?, offset?, stroke?, select? }` on the view adds a family of hatch lines over the faces. `spacing` is a paper length and `angle` is a paper angle. `select` is a test on the face rows. A recipe without a pen uses the object's `fillPen`, then its `stroke`, then the view's. The lines lie flat on the paper: for lines that follow the surface, see [t.hatch](/docs/reference/3d/surface#thatch).

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#A84932' }) } }, (t) => view(box([2.4, 1.6, 1.2]), { camera: orthographic({ eye: [5, 7, 5], span: 4.5 }), stroke: 'ink', hatch: { spacing: mm(1.6), angle: 45, stroke: 'shade', select: (f) => f.normal[2] > 0.5 } }));
```

## crosshatch

A list of recipes is several families at once. Two recipes over the same faces, at angles 90° apart, are a crosshatch. Each family keeps its own pen.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#56626A' }) } }, (t) => view(sphere(1.4, { segments: 32, rings: 16 }), { camera: orthographic({ eye: [5, 6, 4], span: 4 }), stroke: 'ink', creaseAngle: 180, hatch: [{ spacing: mm(1.4), angle: 30, stroke: 'shade', select: (f) => f.normal[2] < 0.2 }, { spacing: mm(1.4), angle: 120, stroke: 'shade', select: (f) => f.normal[2] < -0.3 }] }));
```

## sections

`sections: [{ origin, normal, stroke? }]` on the view cuts the mesh with planes in model space and draws the cut lines. Each section can name its own pen. A section is a mesh and plane intersection, not a boolean.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), section: pen({ width: mm(0.2), color: '#A84932' }) } }, (t) => view(sphere(1.5, { segments: 36, rings: 18 }), { camera: orthographic({ eye: [5, 6, 4], span: 4.4 }), stroke: 'ink', creaseAngle: 180, sections: [-1, -0.5, 0, 0.5, 1].map((z) => ({ origin: [0, 0, z], normal: [0, 0, 1], stroke: 'section' })) }));
```

## The view callback

`view(geometry, options, (lines) => tree)` replaces the default ink. `lines.visible` and `lines.hidden` are the classified line intervals. Each has `.kinds` (boundary, silhouette, crease, hatch, section) and its source attributes. `strokes` accepts them directly. Keep the callback pure, because it can run again when the camera changes.

```ts live
import { sketch, pen, mm, strokes } from 'occlude';
import { box, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), ghost: pen({ width: mm(0.15), color: '#8A94A6' }) } }, (t) => view(
  [box(1.5), box(1).translate([1.3, 1, 0.9])],
  { camera: orthographic({ eye: [5, 7, 4], target: [0.5, 0.4, 0.4], span: 5 }) },
  (lines) => [strokes(lines.visible, { stroke: 'ink' }), strokes(lines.hidden, { stroke: 'ghost' })],
));
```

## style()

<include>/_sig/3d.style.mdx</include>

Sets the drawing of a value: `stroke`, `fillPen` and `creaseAngle`. It returns the styled value, or a styled list, and keeps the fields it does not name.

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, sphere, style, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), blue: pen({ width: mm(0.3), color: '#2457D6' }) } }, (t) => view([box(1.4), ...style([sphere(0.6, { segments: 20, rings: 10 }).translate([1.3, 0.6, 0.6]), sphere(0.4, { segments: 20, rings: 10 }).translate([-1.1, -0.8, 0.9])], { stroke: 'blue', creaseAngle: 180 })], { camera: orthographic({ eye: [5, 7, 4], span: 5 }), stroke: 'ink' }));
```
