The 3D words come from `occlude/3d`. You build geometry in world units. Every example here ends with `view`. `view` projects the geometry into the drawable. See [View](/docs/reference/3d/view).

## plane()

<include>/_sig/3d.plane.mdx</include>

A flat quad in XY, centred at the origin, with one face. `.subdivide(levels)` splits it into a grid of quads.

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => view(plane(4, 3).subdivide(2), { camera: orthographic({ eye: [4, 6, 5], span: 6 }), stroke: 'ink', creaseAngle: 0 }));
```

## box()

<include>/_sig/3d.box.mdx</include>

A box of one size, or of a `[x, y, z]` size, centred at the origin.

```ts live
import { sketch, pen, mm } from 'occlude';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => view([box(1.6), box([0.8, 0.8, 2.6]).translate([1.6, 0.6, 0.5])], { camera: orthographic({ eye: [5, 7, 4], target: [0.6, 0.3, 0.4], span: 5 }), stroke: 'ink' }));
```

## sphere()

<include>/_sig/3d.sphere.mdx</include>

A sphere of `segments` around and `rings` from pole to pole. `creaseAngle: 180` on the view draws no fold between its faces, so only the silhouette and the boundaries show.

```ts live

```

## geodesic()

<include>/_sig/3d.geodesic.mdx</include>

A geodesic polyhedron: the mesh of a dome. Every triangle of the base solid carries a triangular lattice, and every point moves out to `radius`. It has triangles only, no poles and no seam, so its faces are nearly equal everywhere. `sphere()` is a grid of latitude and longitude, and its quads crowd at the poles.

`frequency` is the pair `[m, n]`: how many lattice steps along, then how many turned 60 degrees. A plain number `m` is the pair `[m, 0]`. `[m, 0]` is class I, the straight division, and `[2, 0]`, `[4, 0]` and `[8, 0]` are the shape that is usually called an icosphere. `[m, m]` is class II, which puts a point at the middle of every base edge. Any other pair is class III, whose triangles cross the base edges and give the lattice a hand. `[n, m]` is the mirror of `[m, n]`.

`base` is `'icosahedron'` (the default), `'octahedron'` or `'tetrahedron'`. The face count is `m² + mn + n²` per base face. `project: false` keeps the flat solid, with its faces divided the same way. `.dual()` gives the Goldberg polyhedron.

```ts live
import { sketch, pen, mm, group } from 'occlude';
import { geodesic, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const domes = [[3, 0], [2, 2], [3, 1]];
  return domes.map(([m, n], i) => group({ scale: 1 / 3, origin: [0, 0], translate: [i * 33.3, 33.3] },
    view(geodesic(1, { frequency: [m, n], creaseAngle: 0 }), { camera: orthographic({ eye: [4, 7, 5], span: 2.3 }), stroke: 'ink' })));
});
```

## parametric()

<include>/_sig/3d.parametric.mdx</include>

A formula as a quad grid. `point(u, v)` is read over the unit square: `u` runs from 0 to 1 across `cols` samples, and `v` runs from 0 to 1 down `rows`. The mesh carries the unit square as its chart, exactly as `plane` does, so `t.hatch({ uv })`, `isolines` and `t.mapSurface` read it.

`closeU` and `closeV` weld the seam, so a torus from a formula is as closed as `torus()`. A ring of samples that all land on one place is a pole, and it becomes one shared point. Each quad is wound `(u, v)`, `(u+, v)`, `(u+, v+)`, `(u, v+)`, so the face normal is ∂p/∂u × ∂p/∂v. Swap `u` and `v` to turn the surface inside out.

The shell below is a spiral tube that grows as it turns, hatched along `u` with the chart direction `s.tangentU`.

```ts live
import { sketchAsync, pen, mm } from 'occlude';
import { parametric, view, orthographic, light } from 'occlude/3d';

export default sketchAsync({ aspect: [1, 1], seed: 42, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#56626A' }) } }, async (t) => {
  const shell = parametric((u, v) => {
    const a = 2 * Math.PI * 2.6 * u, r = 0.12 * Math.exp(0.18 * a), tube = 0.5 * r, b = 2 * Math.PI * v;
    const radial = r + tube * Math.cos(b);
    return [radial * Math.cos(a), radial * Math.sin(a), 0.5 * r + tube * Math.sin(b)];
  }, { cols: 84, rows: 18, closeV: true, creaseAngle: 180 });
  const sun = light({ direction: [-1, -2, 2], ambient: 0.12, ramp: 'smooth' });
  const marks = await t.hatch(shell, { spacing: 0.085, direction: (s) => s.tangentU, tone: sun, stroke: 'shade' });
  return view([shell, marks], { camera: orthographic({ eye: [3, -6, 5], target: [-0.7, 0, 0.4], span: 7.2 }), stroke: 'ink' });
});
```

## obj()

<include>/_sig/3d.obj.mdx</include>

A mesh from the text of a Wavefront OBJ file: a model from Blender or any other modeller, occluded, hatched and plotted like a box. Only `v` and `f` lines are read. Normals, texture coordinates, materials and smoothing groups are read past. Polygons keep their vertex count. OBJ files are Y-up and occlude is Z-up, so the model is stood upright. `up: 'z'` keeps a file's coordinates as they are. `objects` keeps only the named `o` objects, and each face carries its `object` and `group` name as an attribute. A file's mistake is refused by line: an index past the last vertex, a face that visits a vertex twice, two faces that wind the same way along a shared edge. In a sketch, `t.asset('name.obj')` gives the text of an uploaded file.

```ts live
import { sketch, pen, mm } from 'occlude';
import { obj, view, perspective } from 'occlude/3d';

// A gabled house, Y up, as a modeller writes it. Faces wind counter-clockwise seen from outside.
const HOUSE = `o house
v -1 0 -0.8
v  1 0 -0.8
v  1 0  0.8
v -1 0  0.8
v -1 1 -0.8
v  1 1 -0.8
v  1 1  0.8
v -1 1  0.8
v -1 1.6 0
v  1 1.6 0
f 1 2 3 4
f 1 5 6 2
f 4 3 7 8
f 1 4 8 9 5
f 2 6 10 7 3
f 5 9 10 6
f 8 7 10 9`;

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => {
  const house = obj(HOUSE);
  return view([house, house.scale(0.55).translate([1.9, -0.4, 0])], { camera: perspective({ eye: [4.6, 6.2, 3.6], target: [0.5, -0.2, 0.7], fovDegrees: 36 }), stroke: 'ink' });
});
```

## translate() · rotate() · scale()

A mesh is born at the world origin. `.translate(triple)`, `.rotate(degreesTriple)` and `.scale(scalarOrTriple)` return new values. They pivot on the object's own origin, and `translate` moves that origin with the object. Translate then rotate turns the bar where it stands. Rotate then translate turns it first. The blue bar and the bar below it land in different places. A `rotate('z', degrees)` form turns about one axis.

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), blue: pen({ width: mm(0.3), color: '#2457D6' }) } }, (t) => {
  const bar = box([1.8, 0.5, 0.5]);
  return view([
    bar.translate([0, 0, 0]),
    bar.translate([0, 1.6, 0]).rotate([0, 0, 40]).style({ stroke: 'blue' }),
    bar.rotate([0, 0, 40]).translate([0, -1.6, 0]),
    bar.scale([1, 1, 3]).translate([2.8, 0, 0.6]),
  ], { camera: orthographic({ eye: [4, 7, 5], target: [0.6, 0, 0.4], span: 7 }), stroke: 'ink' });
});
```

## alignAxis() · axisAngle()

<include>/_sig/3d.alignAxis.mdx</include>
<include>/_sig/3d.axisAngle.mdx</include>

Rotation values. `axisAngle(axis, degrees)` turns around `'x'`, `'y'`, `'z'` or a direction. `alignAxis(localAxis, direction)` is the rotation that turns one local axis onto a direction. That is how a prototype stands on a surface normal. Both go into `.rotate` and into an instance's `rotate` field. `a.then(b)` composes two, and `.inverse()` undoes one.

```ts live
import { sketch, pen, mm } from 'occlude';
import { cone, alignAxis, axisAngle, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => {
  const arrows = t.times(8, (k) => { const a = (k / 8) * Math.PI * 2; const dir = [Math.cos(a), Math.sin(a), 0.6]; return cone(0.25, 1, { segments: 10 }).rotate(alignAxis('z', dir)).translate([Math.cos(a) * 1.5, Math.sin(a) * 1.5, 0]); });
  const tilted = cone(0.4, 1.4, { segments: 12 }).rotate(axisAngle('x', 40));
  return view([...arrows, tilted], { camera: orthographic({ eye: [4, 6, 5], span: 6 }), stroke: 'ink', creaseAngle: 180 });
});
```

## sdf3

<include>/_sig/3d.sdf3.sphere.mdx</include>
<include>/_sig/3d.sdf3.box.mdx</include>
<include>/_sig/3d.sdf3.capsule.mdx</include>
<include>/_sig/3d.sdf3.torus.mdx</include>
<include>/_sig/3d.sdf3.plane.mdx</include>
<include>/_sig/3d.sdf3.union.mdx</include>
<include>/_sig/3d.sdf3.intersect.mdx</include>
<include>/_sig/3d.sdf3.subtract.mdx</include>
<include>/_sig/3d.sdf3.blend.mdx</include>
<include>/_sig/3d.sdf3.translate.mdx</include>
<include>/_sig/3d.sdf3.repeat.mdx</include>

A solid can be the field that measures it. `sdf3` is the 2D [`sdf`](/docs/reference/fields) algebra in space. Each word returns a function of `(x, y, z)`. The value is how far inside the point lies, and it is negative outside. That sign is why `union` is a **maximum**: the union is inside wherever one field is inside, and inside is the larger value. `intersect` is the minimum. `subtract` cuts each later field out of the first. `blend` is a union with a fillet of `radius` at the joint. `translate` moves a field, and `repeat` folds space, so one solid fills a lattice.

The five primitives are exact. `plane` takes the normal that points out of the solid. `sdf3` reads no seed and no paper, so you import it, and you can write your own field as a plain function. `isosurface` turns any of them into a mesh.

Below, `repeat` puts one ball on a lattice, `union` threads a rod through the row, and a plane cuts a flat foot under each bead.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sdf3, isosurface, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.28), color: '#18202A' }) } }, () => {
  const beads = sdf3.repeat(sdf3.sphere(0.38), [1, 0, 0]);
  const rod = sdf3.capsule([-1.3, 0, 0], [1.3, 0, 0], 0.13);
  const standing = sdf3.intersect(sdf3.union(beads, rod), sdf3.plane([0, 0, -1], 0.2));
  const solid = isosurface(standing, { bounds: [[-1.55, -0.6, -0.3], [1.55, 0.6, 0.45]], resolution: 60 });
  return view(solid, { camera: orthographic({ eye: [3.5, -6, 1.8], span: 3.1 }), stroke: 'ink', creaseAngle: 40 });
});
```

## isosurface()

<include>/_sig/3d.isosurface.mdx</include>

The surface of a field, as a mesh. `isosurface` divides `bounds` into cells at `resolution`, and it puts a vertex on each cell edge that the surface crosses. The cells share their vertices, so the mesh is closed, and the faces wind outward. `resolution` is the number of cells along the longest side of the box, and a triple gives the three counts. `level` takes the surface at a value other than zero. `smooth` runs Laplacian passes over the result, which rounds the steps of a coarse grid.

Give the box room around the solid. A solid that touches the wall of the box is cut there, and the mesh is open along the cut. An empty box, a resolution below one cell, and a field that is nowhere inside each draw nothing.

Below, two spheres blend into one body, a box takes the top off the right one, and `light` shades the result. The straight marks on the flat top show the cut, and the curved marks show the ball.

```ts live
import { sketchAsync, pen, mm } from 'occlude';
import { sdf3, isosurface, light, gradient, view, orthographic } from 'occlude/3d';

export default sketchAsync({ aspect: [1, 1], seed: 42, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#56626A' }) } }, async (t) => {
  const pair = sdf3.blend(sdf3.sphere(0.85, [-0.8, 0, 0]), sdf3.sphere(0.85, [0.8, 0, 0]), 0.45);
  const bitten = sdf3.subtract(pair, sdf3.box([2, 2, 2], [1.0, 0, 1.05]));
  const solid = isosurface(bitten, { bounds: [[-2, -1.3, -1.3], [2, 1.3, 1.3]], resolution: 44, smooth: 1 });
  const sun = light({ direction: [-1, -2, 1], ambient: 0.1, ramp: 'smooth' });
  const marks = await t.hatch(solid, { spacing: 0.09, direction: gradient((s) => s.position[0]), tone: sun, stroke: 'shade' });
  return view([solid, marks], { camera: orthographic({ eye: [4, -6, 3], span: 4.2 }), stroke: 'ink', creaseAngle: 60 });
});
```

## hyperbolic space

<include>/_sig/hyperbolic.space.boost.mdx</include>
<include>/_sig/hyperbolic.space.rotation.mdx</include>
<include>/_sig/hyperbolic.space.apply.mdx</include>
<include>/_sig/hyperbolic.space.map.mdx</include>
<include>/_sig/hyperbolic.space.compose.mdx</include>
<include>/_sig/hyperbolic.space.inverse.mdx</include>
<include>/_sig/hyperbolic.space.distance.mdx</include>
<include>/_sig/hyperbolic.space.geodesic.mdx</include>
<include>/_sig/hyperbolic.space.polyhedron.mdx</include>
<include>/_sig/hyperbolic.space.honeycomb.mdx</include>
<include>/_sig/hyperbolic.space.camera.mdx</include>

`hyperbolic.space` carries the disk words of [Transforms](/docs/reference/transforms) one dimension up. It works in the Beltrami-Klein ball, and the disk words work in the Poincaré disk. The ball is the unit ball of `[x, y, z]`, and its rim lies infinitely far away. In this model a hyperbolic straight line is an ordinary chord. A hyperbolic plane is an ordinary flat plane. So a hyperbolic polyhedron is an ordinary mesh: `mesh(cell.points, cell.faces)` takes one, and the same `view` draws it.

The price is length. Klein coordinates are not hyperbolic lengths, and they shrink toward the rim. A hatch spacing or an isoline step over this geometry counts Klein units. `space.distance` is the one word here that answers in hyperbolic length, and `space.geodesic` spaces its samples by that length.

A transform is data, as it is in the disk: a 4×4 matrix of sixteen numbers, row-major, and a `mirror` flag. The matrix acts on `[x, y, z, t]`, where every isometry of hyperbolic space is a Lorentz matrix. `space.boost(dx, dy, dz)` moves the centre of the ball to a point of it. `space.rotation(axis, degrees)` turns about the centre. `space.reflection(plane)` takes three points and reflects in the hyperbolic plane through them. `space.lorentz(matrix)` is the door for a matrix worked out somewhere else. It checks the matrix and reads `mirror` from the determinant. `apply`, `map`, `compose` and `inverse` read a record the same way the disk words do.

`space.polyhedron(p, q, r)` builds the regular cell of the `{p, q, r}` honeycomb, centred on the centre of the ball. It is the regular polyhedron `{p, q}` with a dihedral angle of `2π/r`, so `r` cells meet around every edge. Four `{p, q, r}` have a compact cell in hyperbolic space: `{4, 3, 5}`, `{5, 3, 4}`, `{3, 5, 3}` and `{5, 3, 5}`. Every other one refuses by name, and it names the geometry it belongs to. `{4, 3, 4}` is Euclidean and `{3, 3, 5}` is spherical.

The cell keeps the Euclidean symmetry of `{p, q}` about the centre, so only its size is hyperbolic. Its circumradius `R` comes from the Gram matrix `G` of the Coxeter simplex of `{p, q, r}`:

```
cosh R = cos(π/p)·cos(π/q)·cos(π/r) / √((1 − cos²(π/q) − cos²(π/r))(1 − cos²(π/p) − cos²(π/q)))
```

The vertices sit at Klein radius `tanh R`. The sign of `det G` is the geometry: positive for the sphere, zero for Euclidean space, negative for hyperbolic space.

`space.honeycomb(p, q, r, { depth })` answers one placement for each copy of the cell, the identity first. It reflects the cell in its own walls, then reflects the copies in theirs, out to `depth` generations. Depth 1 gives the cell and its face neighbours. The sketch builds the cell once and maps its points through every placement.

`space.camera(eye, target)` is the observer. It moves `eye` to the centre of the ball and points `target` along `+Y`, with `up` along `+Z`. The Klein model is true to angle at its centre. The picture the observer takes there has the angles of hyperbolic space itself. The sketch maps the scene through the record and then takes `perspective({ eye: [0, 0, 0], target: [0, 1, 0] })`. A placement is a transform too, so `compose(cam, placement)` is one matrix for both, and no mesh moves after the sketch builds it.

A honeycomb fills space. From inside a cell, solid walls would hide every other cell, so the two drawings below take each cell as its edges. `polyline` makes a wire, and a wire hides nothing. Stand outside the ball, and `mesh(cell.points, cell.faces)` gives solid cells for the hidden-line engine to work on.

Below, the observer stands in one cube of the `{4, 3, 5}` honeycomb and looks at a wall. A boost after the camera steps the observer back. `space.distance` keeps the cells within a hyperbolic radius of the eye, and `space.inverse` finds where the eye ends up. Five cubes meet around every edge, and the right angles of a Euclidean cube become 72 degrees. A view this wide reaches past its own frame, so the callback keeps the lines the frame holds.

```ts live
import { sketchAsync, strokes, pen, mm, hyperbolic } from 'occlude';
import { polyline, view, perspective } from 'occlude/3d';

const space = hyperbolic.space;

export default sketchAsync({ aspect: [1, 1], pens: {
  ink: pen({ width: mm(0.22), color: '#18202A' }),
} }, async () => {
  const cell = space.polyhedron(4, 3, 5);
  // Every edge of the cell once: a closed cell runs each edge both ways.
  const edges = cell.faces.flatMap((f) => f.map((a, i) => [a, f[(i + 1) % f.length]]).filter(([a, b]) => a < b));
  // A little off the centre of one cube, looking at a wall. The boost
  // after the camera steps the observer back along the line of sight.
  const cam = space.compose(space.boost(0, 0.35, 0), space.camera([0.05, -0.08, 0.1], [0.8, 0, 0]));
  const eye = space.apply(space.inverse(cam), [0, 0, 0]);
  const name = (p) => p.map((v) => Math.round(v * 1e6)).join(',');
  const drawn = new Set();
  const wires = [];
  for (const place of space.honeycomb(4, 3, 5, { depth: 4 })) {
    // Depth counts reflections; a hyperbolic radius is the honest cut.
    if (space.distance(eye, space.apply(place, [0, 0, 0])) > 3) continue;
    const here = cell.points.map(space.map(place));
    const seen = cell.points.map(space.map(space.compose(cam, place)));
    for (const [a, b] of edges) {
      const id = [name(here[a]), name(here[b])].sort().join('|');
      if (drawn.has(id)) continue;
      drawn.add(id);
      wires.push(polyline(space.geodesic(seen[a], seen[b], { count: 24 })));
    }
  }
  return view(wires, { camera: perspective({ eye: [0, 0, 0], target: [0, 1, 0], fovDegrees: 100, near: 0.01 }), stroke: 'ink' }, (lines) => {
    const r = lines.visible.source.frame.paper;
    const held = (p) => p[0] >= r.x && p[0] <= r.x + r.width && p[1] >= r.y && p[1] <= r.y + r.height;
    return strokes(lines.visible.filter((c) => held(c.a) && held(c.b)), { stroke: 'ink' });
  });
});
```

The `{5, 3, 4}` honeycomb fills space with right-angled dodecahedra, four around every edge. The observer stands a little toward one corner of a cell and looks at the wall across from it. A turn about the line of sight rolls the picture. The heavier pen draws the cell the observer stands in, so the eye finds the room. Its far wall is the big rounded pentagon, and its other edges run out to the corners of the frame.

```ts live
import { sketchAsync, strokes, pen, mm, hyperbolic } from 'occlude';
import { polyline, view, perspective } from 'occlude/3d';

const space = hyperbolic.space;

export default sketchAsync({ aspect: [1, 1], pens: {
  ink: pen({ width: mm(0.18), color: '#46505C' }),
  room: pen({ width: mm(0.38), color: '#18202A' }),
} }, async () => {
  const cell = space.polyhedron(5, 3, 4);
  const edges = cell.faces.flatMap((f) => f.map((a, i) => [a, f[(i + 1) % f.length]]).filter(([a, b]) => a < b));
  const middle = (f) => [0, 1, 2].map((k) => f.reduce((s, i) => s + cell.points[i][k], 0) / f.length);
  const corner = cell.points[0];
  const toward = (p) => p[0] * corner[0] + p[1] * corner[1] + p[2] * corner[2];
  const wall = cell.faces.map(middle).reduce((a, b) => (toward(a) < toward(b) ? a : b));
  const cam = space.compose(space.rotation('y', 15), space.camera(corner.map((v) => v * 0.15), wall));
  const name = (p) => p.map((v) => Math.round(v * 1e6)).join(',');
  const drawn = new Set();
  const wires = [];
  // The identity comes first, so the room the observer stands in is the
  // first cell drawn, and it takes the heavier pen.
  space.honeycomb(5, 3, 4, { depth: 2 }).forEach((place, k) => {
    const here = cell.points.map(space.map(place));
    const seen = cell.points.map(space.map(space.compose(cam, place)));
    for (const [a, b] of edges) {
      const id = [name(here[a]), name(here[b])].sort().join('|');
      if (drawn.has(id)) continue;
      drawn.add(id);
      wires.push(polyline(space.geodesic(seen[a], seen[b], { count: 24 }), k === 0 ? { stroke: 'room' } : {}));
    }
  });
  return view(wires, { camera: perspective({ eye: [0, 0, 0], target: [0, 1, 0], fovDegrees: 100, near: 0.005 }), stroke: 'ink' }, (lines) => {
    const r = lines.visible.source.frame.paper;
    const held = (c) => [c.a, c.b].every((p) => p[0] >= r.x && p[0] <= r.x + r.width && p[1] >= r.y && p[1] <= r.y + r.height);
    return [
      strokes(lines.visible.filter((c) => held(c) && c.feature.stroke !== 'room'), { stroke: 'ink' }),
      strokes(lines.visible.filter((c) => held(c) && c.feature.stroke === 'room'), { stroke: 'room' }),
    ];
  });
});
```
