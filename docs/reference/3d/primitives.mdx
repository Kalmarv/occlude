The 3D words come from `occlude/3d`. You build geometry in world units. Every example here ends with `view`. `view` projects the geometry into the drawable. See [View](/docs/reference/3d/view).

## plane()

<include>/_sig/3d.plane.mdx</include>

A flat quad in XY, centred at the origin, with one face. `.subdivide(levels)` splits it into a grid of quads. A flat grid has no fold to draw, so the second plane below takes a gentle wave, and its grid shows.

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => view([plane(2.4, 1.6).translate([1.1, -1.1, 0]), plane(2.4, 1.6).subdivide(3).displace((p) => [0, 0, 0.1 * Math.sin(p.x * 3) * Math.cos(p.y * 3)]).translate([-1.1, 1.1, 0])], { camera: orthographic({ eye: [4, 6, 5], span: 6 }), pen: 'ink', creaseAngle: 0 }));
```

## box()

<include>/_sig/3d.box.mdx</include>

A box of one size, or of a `[x, y, z]` size, centred at the origin.

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => view([box(1.6), box([0.8, 0.8, 2.6]).translate([1.6, 0.6, 0.5])], { camera: orthographic({ eye: [5, 7, 4], target: [0.6, 0.3, 0.4], span: 5 }), pen: 'ink' }));
```

## sphere()

<include>/_sig/3d.sphere.mdx</include>

A sphere of `segments` around and `rings` from pole to pole. `creaseAngle: 180` on the view draws no fold between its faces, so only the silhouette and the boundaries show.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => view([sphere(1.2, { segments: 32, rings: 16 }), sphere(0.5, { segments: 16, rings: 8 }).translate([1.6, 0.8, -0.4])], { camera: orthographic({ eye: [5, 6, 4], span: 4.6 }), pen: 'ink', creaseAngle: 180 }));
```

## geodesic()

<include>/_sig/3d.geodesic.mdx</include>

A geodesic polyhedron: the mesh of a dome. Every triangle of the base solid carries a triangular lattice, and every point moves out to `radius`. It has triangles only, no poles and no seam, so its faces are nearly equal everywhere. `sphere()` is a grid of latitude and longitude, and its quads crowd at the poles.

`frequency` is the pair `[m, n]`: how many lattice steps along, then how many turned 60 degrees. A plain number `m` is the pair `[m, 0]`. `[m, 0]` is class I, the straight division, and `[2, 0]`, `[4, 0]` and `[8, 0]` are the shape that is usually called an icosphere. `[m, m]` is class II, and it puts a point at the middle of every base edge. Any other pair is class III, whose triangles cross the base edges and give the lattice a hand. `[n, m]` is the mirror of `[m, n]`.

`base` is `'icosahedron'` (the default), `'octahedron'` or `'tetrahedron'`. Each base face holds `m² + mn + n²` faces. `project: false` keeps the flat solid, with its faces divided the same way. `.dual()` gives the Goldberg polyhedron.

```ts live
import { sketch, pen, mm, group } from 'occlude';
import { geodesic, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const domes = [[3, 0], [2, 2], [3, 1]];
  return domes.map(([m, n], i) => group({ scale: 1 / 3, origin: [0, 0], translate: [i * 33.3, 33.3] },
    view(geodesic(1, { frequency: [m, n], creaseAngle: 0 }), { camera: orthographic({ eye: [4, 7, 5], span: 2.3 }), pen: 'ink' })));
});
```

<include>/_sig/3d.cylinder.mdx</include>

## torus()

<include>/_sig/3d.torus.mdx</include>

A ring in XY. `radius` is the centreline and `tubeRadius` the thickness, so the outer radius is their sum.

```ts live
import { sketch, pen, mm } from 'occlude';
import { torus, view, perspective } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => view(torus(1.2, 0.4, { segments: 36, tubeSegments: 14 }), { camera: perspective({ eye: [3, 4, 2.4], fovDegrees: 40 }), pen: 'ink', creaseAngle: 180 }));
```

## parametric()

<include>/_sig/3d.parametric.mdx</include>

A formula as a quad grid. The grid reads `point(u, v)` over the unit square. `u` runs from 0 to 1 across `cols` samples, and `v` from 0 to 1 down `rows`. The mesh carries the unit square as its chart, exactly as `plane` does, so `t.hatch({ uv })`, `isolines` and `t.mapSurface` read it.

`closeU` and `closeV` weld the seam, so a torus from a formula is as closed as `torus()`. A ring of samples that all land on one place is a pole, and it becomes one shared point. Each quad is wound `(u, v)`, `(u+, v)`, `(u+, v+)`, `(u, v+)`, so the face normal is ∂p/∂u × ∂p/∂v. Swap `u` and `v` to turn the surface inside out.

The shell below is a spiral tube that grows as it turns, hatched along `u` with the chart direction `s.tangentU`.

```ts live
import { sketchAsync, pen, mm } from 'occlude';
import { parametric, view, orthographic, light } from 'occlude/3d';

export default sketchAsync({ aspect: [1, 1], seed: 42, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#56626A' }) } }, async (t) => {
  const shell = parametric((u, v) => {
    const a = 2 * Math.PI * 2.6 * u, r = 0.12 * Math.exp(0.18 * a), tube = 0.5 * r, b = 2 * Math.PI * v;
    const radial = r + tube * Math.cos(b);
    return [radial * Math.cos(a), radial * Math.sin(a), 0.5 * r + tube * Math.sin(b)];
  }, { cols: 84, rows: 18, closeV: true, creaseAngle: 180 });
  const sun = light({ direction: [-1, -2, 2], ambient: 0.12, ramp: 'smooth' });
  const marks = await t.hatch(shell, { spacing: 0.085, direction: (s) => s.tangentU, tone: sun, pen: 'shade' });
  return view([shell, marks], { camera: orthographic({ eye: [3, -6, 5], target: [-0.7, 0, 0.4], span: 7.2 }), pen: 'ink' });
});
```

## obj()

<include>/_sig/3d.obj.mdx</include>

A mesh from the text of a Wavefront OBJ file, such as a model from Blender. It occludes, hatches and plots like a box. The reader takes `v` and `f` lines only, and it skips normals, texture coordinates, materials and smoothing groups. Polygons keep their vertex count. OBJ files are Y-up and occlude is Z-up, so the model is stood upright. `up: 'z'` keeps a file's coordinates as they are. `objects` keeps only the named `o` objects, and each face carries its `object` and `group` name as an attribute. The reader refuses a mistake in the file and names its line. It stops at an index past the last vertex and at a face that visits a vertex twice. It also stops at two faces that wind one way along a shared edge. In a sketch, `t.asset('name.obj')` gives the text of an uploaded file.

```ts live
import { sketch, pen, mm } from 'occlude';
import { obj, view, perspective } from 'occlude/3d';

// A gabled house, Y up, as a modeller writes it. Faces wind counter-clockwise seen from outside.
const HOUSE = `o house
v -1 0 -0.8
v  1 0 -0.8
v  1 0  0.8
v -1 0  0.8
v -1 1 -0.8
v  1 1 -0.8
v  1 1  0.8
v -1 1  0.8
v -1 1.6 0
v  1 1.6 0
f 1 2 3 4
f 1 5 6 2
f 4 3 7 8
f 1 4 8 9 5
f 2 6 10 7 3
f 5 9 10 6
f 8 7 10 9`;

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => {
  const house = obj(HOUSE);
  return view([house, house.scale(0.55).translate([1.9, -0.4, 0])], { camera: perspective({ eye: [4.6, 6.2, 3.6], target: [0.5, -0.2, 0.7], fovDegrees: 36 }), pen: 'ink' });
});
```

## translate() · rotate() · scale()

A mesh is born at the world origin. `.translate(triple)`, `.rotate(degreesTriple)` and `.scale(scalarOrTriple)` return new values. They pivot on the object's own origin, and `translate` moves that origin with the object. Translate then rotate turns the bar where it stands. Rotate then translate turns it first. The blue bar and the bar below it land in different places. A `rotate('z', degrees)` form turns about one axis.

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), blue: pen({ width: mm(0.3), color: '#2457D6' }) } }, (t) => {
  const bar = box([1.8, 0.5, 0.5]);
  return view([
    bar.translate([0, 0, 0]),
    bar.translate([0, 1.6, 0]).rotate([0, 0, 40]).style({ pen: 'blue' }),
    bar.rotate([0, 0, 40]).translate([0, -1.6, 0]),
    bar.scale([1, 1, 3]).translate([2.8, 0, 0.6]),
  ], { camera: orthographic({ eye: [4, 7, 5], target: [0.6, 0, 0.4], span: 7 }), pen: 'ink' });
});
```

## alignAxis() · axisAngle()

<include>/_sig/3d.alignAxis.mdx</include>
<include>/_sig/3d.axisAngle.mdx</include>

Rotation values. `axisAngle(axis, degrees)` turns around `'x'`, `'y'`, `'z'` or a direction. `alignAxis(localAxis, direction)` is the rotation that turns one local axis onto a direction. That is how a prototype stands on a surface normal. Both go into `.rotate` and into an instance's `rotate` field. `a.then(b)` composes two, and `.inverse()` undoes one.

```ts live
import { sketch, pen, mm } from 'occlude';
import { cone, alignAxis, axisAngle, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => {
  const arrows = t.times(8, (k) => { const a = (k / 8) * Math.PI * 2; const dir = [Math.cos(a), Math.sin(a), 0.6]; return cone(0.25, 1, { segments: 10 }).rotate(alignAxis('z', dir)).translate([Math.cos(a) * 1.5, Math.sin(a) * 1.5, 0]); });
  const tilted = cone(0.4, 1.4, { segments: 12 }).rotate(axisAngle('x', 40));
  return view([...arrows, tilted], { camera: orthographic({ eye: [4, 6, 5], span: 6 }), pen: 'ink', creaseAngle: 180 });
});
```

## distance() · length()

<include>/_sig/3d.distance.mdx</include>
<include>/_sig/3d.length.mdx</include>

`distance(a, b)` is how far apart two points are, and `length(v)` is how long a vector is. Both take triples or `{x, y, z}` rows, so a mesh point goes in as it is. Below, a sheet rises in two ripples: one around its middle, which `length` measures, and one around a drop, which `distance` measures.

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, distance, length, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const drop = [1.1, -0.7, 0];
  const sheet = plane(4, 4).subdivide(5).displace((p) => [0, 0, 0.08 * Math.cos(7 * length(p)) + 0.08 * Math.cos(9 * distance(p, drop))]);
  return view(sheet, { camera: orthographic({ eye: [4, 6, 5], span: 6.6 }), pen: 'ink', creaseAngle: 0 });
});
```

## sdf3

<include>/_sig/3d.sdf3.sphere.mdx</include>
<include>/_sig/3d.sdf3.box.mdx</include>
<include>/_sig/3d.sdf3.capsule.mdx</include>
<include>/_sig/3d.sdf3.torus.mdx</include>
<include>/_sig/3d.sdf3.plane.mdx</include>
<include>/_sig/3d.sdf3.union.mdx</include>
<include>/_sig/3d.sdf3.intersect.mdx</include>
<include>/_sig/3d.sdf3.subtract.mdx</include>
<include>/_sig/3d.sdf3.blend.mdx</include>
<include>/_sig/3d.sdf3.translate.mdx</include>
<include>/_sig/3d.sdf3.repeat.mdx</include>

A solid can be the field that measures it. `sdf3` is the 2D [`sdf`](/docs/reference/fields) algebra in space. Each word returns a function of `(x, y, z)`. The value is how far inside the point lies, and it is negative outside. That sign is why `union` is a **maximum**. The union is inside wherever one field is inside, and inside is the larger value. `intersect` is the minimum. `subtract` cuts each later field out of the first. `blend` is a union with a fillet of `radius` at the joint. `translate` moves a field, and `repeat` folds space, so one solid fills a lattice.

The five primitives are exact. `plane` takes the normal that points out of the solid. `sdf3` reads no seed and no paper, so you import it, and you can write your own field as a plain function. `isosurface` turns any of them into a mesh.

Below, `repeat` puts one ball on a lattice, and `union` threads a rod through the row. A plane cuts a flat foot under each bead.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sdf3, isosurface, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.28), color: '#18202A' }) } }, () => {
  const beads = sdf3.repeat(sdf3.sphere(0.38), [1, 0, 0]);
  const rod = sdf3.capsule([-1.3, 0, 0], [1.3, 0, 0], 0.13);
  const standing = sdf3.intersect(sdf3.union(beads, rod), sdf3.plane([0, 0, -1], 0.2));
  const solid = isosurface(standing, { bounds: [[-1.55, -0.6, -0.3], [1.55, 0.6, 0.45]], resolution: 60 });
  return view(solid, { camera: orthographic({ eye: [3.5, -6, 1.8], span: 3.1 }), pen: 'ink', creaseAngle: 40 });
});
```

## isosurface()

<include>/_sig/3d.isosurface.mdx</include>

The surface of a field, as a mesh. `isosurface` divides `bounds` into cells at `resolution`, and it puts a vertex on each cell edge that the surface crosses. Neighbouring cells share their vertices, so the mesh has no gaps. The faces wind outward. `resolution` is the number of cells along the longest side of the box, and a triple gives the three counts. `level` takes the surface at a value other than zero. `smooth` runs Laplacian passes over the result, to round the steps of a coarse grid.

Give the box room around the solid. A solid that touches the wall of the box stops there, and the mesh is open along the cut. An empty box, a resolution below one cell, and a field that is nowhere inside each draw nothing.

Below, two spheres blend into one body, a box takes the top off the right one, and `light` shades the result. The straight marks on the flat top show the cut, and the curved marks show the ball.

```ts live
import { sketchAsync, pen, mm } from 'occlude';
import { sdf3, isosurface, light, gradient, view, orthographic } from 'occlude/3d';

export default sketchAsync({ aspect: [1, 1], seed: 42, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#56626A' }) } }, async (t) => {
  const pair = sdf3.blend(sdf3.sphere(0.85, [-0.8, 0, 0]), sdf3.sphere(0.85, [0.8, 0, 0]), 0.45);
  const bitten = sdf3.subtract(pair, sdf3.box([2, 2, 2], [1.0, 0, 1.05]));
  const solid = isosurface(bitten, { bounds: [[-2, -1.3, -1.3], [2, 1.3, 1.3]], resolution: 44, smooth: 1 });
  const sun = light({ direction: [-1, -2, 1], ambient: 0.1, ramp: 'smooth' });
  const marks = await t.hatch(solid, { spacing: 0.09, direction: gradient((s) => s.position[0]), tone: sun, pen: 'shade' });
  return view([solid, marks], { camera: orthographic({ eye: [4, -6, 3], span: 4.2 }), pen: 'ink', creaseAngle: 60 });
});
```
