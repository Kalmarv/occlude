title: Surface curves
description: "Curves that live on a surface, and queries against it."

These words derive curves from a mesh, or ask it questions. The mesh hides a curve on its surface in the same way as its own lines.

## intersections()

<include>/_sig/3d.intersections.1.mdx</include>

The curve where two meshes cross. Give two meshes, or a list. In a list, every pair that can meet gives its curve. Both meshes must be in the view with it. The curves take the view's pen. `style` gives them a pen of their own, as the example does.

The call returns a description, not the computed curves. The view first drops every object outside the camera. Then it computes only the pairs that can meet. A big list of far-apart objects costs little. A direct read of the curves, such as `.edges`, computes every pair.

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, sphere, intersections, style, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), line: pen({ width: mm(0.4), color: '#A84932' }) } }, (t) => {
  const ball = sphere(1.3, { segments: 40, rings: 20 });
  const block = box([1.2, 1.2, 2.8]).translate([0.5, 0.3, 0]);
  return view([ball, block, style(intersections(ball, block), { pen: 'line' })], { camera: orthographic({ eye: [5, 6, 4], target: [0.3, 0.2, 0.3], span: 4.6 }), pen: 'ink', creaseAngle: 180 });
});
```

## isolines()

<include>/_sig/3d.isolines.mdx</include>

The level lines of a field over the surface. The field reads a point row, so `(p) => p.z` gives horizontal rings. The third argument is `at`, the same levels that the 2D `t.isolines` takes: one level, a list of levels, `{ count }` for even levels, or `{ spacing, offset? }`. The options come after it, as in 2D: `isolines(mesh, field, at, { key, pen })`. `levels` in the options is refused by name.

The result is a collection of chains. `rings.curves()` gives each chain with its `points`, `closed` and its columns, so `c.level` is the level of a ring. `filter`, `map`, `find`, `some`, `every` and `groupBy` work on the chains. `rings.filter((c) => c.points.every((p) => p.z > 0))` keeps the upper rings as curves that a view draws. `groupBy` gives a list of `{ key, curves }`.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, isolines, style, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), line: pen({ width: mm(0.18), color: '#2457D6' }) } }, (t) => {
  const ball = sphere(1.3, { segments: 40, rings: 20 });
  return view([ball, style(isolines(ball, (p) => p.z, { count: 9 }), { pen: 'line' })], { camera: orthographic({ eye: [5, 6, 4], span: 4 }), pen: 'ink', creaseAngle: 180 });
});
```

## trace()

<include>/_sig/3d.trace.mdx</include>

Follows a direction field across the surface from each seed, triangle to triangle, and returns the paths as curves. The direction is a vector or a field of the surface location. A seed is a surface sample, a location, or a curve sample that is on the traced mesh: `trace(ball, t.sample(intersections(ball, block), { count: 12 }).points, …)` starts on the seam. A curve sample that is not on the traced mesh is refused by name.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, trace, style, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], seed: 3, pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), line: pen({ width: mm(0.18), color: '#2457D6' }) } }, (t) => {
  const ball = sphere(1.3, { segments: 40, rings: 20 });
  const seeds = t.sample(ball, { count: 24 }).points;
  const paths = trace(ball, seeds, [0, 0, 1], { step: 0.05, maxLength: 2.4 });
  return view([ball, style(paths, { pen: 'line' })], { camera: orthographic({ eye: [5, 6, 4], span: 4 }), pen: 'ink', creaseAngle: 180 });
});
```

## mapSurface()

<include>/_sig/3d.mapSurface.mdx</include>

Lays a 2D material onto the surface through the mesh's stored chart coordinates. Numeric coordinates are chart units. Every mapped point lies on its triangle, so the mesh occludes the marks like its own lines.

```ts live
import { sketch, pen, mm, curve, append } from 'occlude';
import { cylinder, mapSurface, style, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.3), color: '#18202A' }), line: pen({ width: mm(0.18), color: '#2457D6' }) } }, (t) => {
  const tube = cylinder(1, 2.4, { segments: 36, caps: false });
  const zigzag = append(...t.times(8, (k) => curve(t.times(40, (j, u) => [u, (k + 0.5) / 8 + Math.sin(u * Math.PI * 6) * 0.04]), { closed: false })));
  return view([tube, style(mapSurface(tube, zigzag, { chart: 'side' }), { pen: 'line' })], { camera: orthographic({ eye: [5, 6, 3], span: 4 }), pen: 'ink', creaseAngle: 180 });
});
```

## t.hatch()

<include>/_sig/Toolkit.hatch.mdx</include>

Hatch that follows the surface. It walks from triangle to triangle in a `direction`. The direction is a vector or a field of the surface location. The lines stay `spacing` apart in world units. `tone` is 0 to 1, a constant or a field, and sets how many lanes get ink. It reads the seed, so it lives on the toolkit. It traces the lanes in a background job, so the sketch must be a `sketchAsync` and the call needs `await`. One call is one family. A second call with another direction is a crosshatch.

```ts live
import { sketchAsync, pen, mm } from 'occlude';
import { sphere, view, orthographic } from 'occlude/3d';

export default sketchAsync({ aspect: [1, 1], seed: 42, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#56626A' }) } }, async (t) => {
  const ball = sphere(1.5, { segments: 40, rings: 20 });
  const light = (s) => Math.max(0, s.normal[0] * 0.6 + s.normal[1] * 0.3 + s.normal[2] * 0.75);
  const along = await t.hatch(ball, { direction: (s) => s.tangentU, spacing: 0.14, tone: (s) => 1 - light(s), pen: 'shade' });
  const across = await t.hatch(ball, { direction: (s) => s.tangentV, spacing: 0.14, tone: (s) => Math.max(0, 0.55 - light(s)) * 1.8, pen: 'shade' });
  return view([ball, along, across], { camera: orthographic({ eye: [5, 6, 4], span: 4.2 }), pen: 'ink', creaseAngle: 180 });
});
```

## Charts and corner attributes

Every primitive stores `uv` coordinates and a `chart` name on its face corners. A plane is one unit square. A box is one square for each face. A sphere is angle and latitude. A seam or a pole keeps different coordinates on each incident corner. Each face also carries the `chart` it was built with, so `mesh.faces.filter((f) => f.chart === 'side')` selects the side of a cylinder. `mapSurface`, `mesh.cornerAttribute(name, field)` and the sampled point's `.sample.uv` all read them. `planarUV(mesh, { origin, u, v })` and `cylindricalUV(mesh, …)` store a projection of your own instead. Below, a corner column marks two of the four quarters around the side chart, and the sampled points read it back.

```ts live
import { sketch, pen, mm } from 'occlude';
import { cylinder, sphere, instanceOnPoints, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], seed: 4, pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => {
  const can = cylinder(1, 2.2, { segments: 28 }).cornerAttribute('band', (c) => (c.chart === 'side' && Math.floor(c.uv[0] * 4) % 2 === 0 ? 1 : 0));
  const banded = t.sample(can, { count: 1400 }).points.filter((p) => p.sample.cornerAttributes.band === 1);
  return view([can, instanceOnPoints(sphere(0.025, { segments: 6, rings: 3 }), banded)], { camera: orthographic({ eye: [5, 6, 3], span: 4 }), pen: 'ink', creaseAngle: 180 });
});
```

## rebind()

A sampled point remembers its triangle and its weights inside it. `samples.rebind(editedMesh)` places the same samples onto an edited revision of the mesh that kept its topology. The marks move with the surface, with no new sampling and no projection.

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, sphere, instanceOnPoints, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], seed: 3, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const flat = plane(4, 4).subdivide(3);
  const pts = t.sample(flat, { count: 70 });
  const bent = flat.displace((p) => [0, 0, 0.6 * Math.sin(p.x * 1.4) * Math.cos(p.y * 1.1)]);
  const moved = pts.rebind(bent);
  return view([bent, instanceOnPoints(sphere(0.07, { segments: 8, rings: 4 }), moved.points)], { camera: orthographic({ eye: [5, 7, 5], span: 6 }), pen: 'ink', creaseAngle: 0 });
});
```

## t.sample() on curves

`t.sample(curves, { spacing })` or `{ count }` places points along each chain of a supported curve, in world units. Open chains keep both ends. Closed chains omit the seam. The points keep their surface attachment, so they go into `instanceOnPoints` and stay on the surface.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, isolines, instanceOnPoints, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], seed: 2, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const ball = sphere(1.3, { segments: 40, rings: 20 });
  const rings = isolines(ball, (p) => p.z, { count: 5 });
  const pts = t.sample(rings, { spacing: 0.35 });
  const beads = instanceOnPoints(sphere(0.07, { segments: 8, rings: 4 }), pts.points);
  return view([ball, beads], { camera: orthographic({ eye: [5, 6, 4], span: 4 }), pen: 'ink', creaseAngle: 180 });
});
```

## query()

<include>/_sig/3d.query.mdx</include>

A prepared spatial index over a mesh. `.nearest(position, { within })`, `.ray(origin, direction)` and `.segment(from, to)` return hits with a position, a normal and the face. `pointCloud(positions)` makes a point set from the hits, for `instanceOnPoints`. `.batch()` asks many at once: `.nearest(points, …)`, `.rays(points, { direction })`, `.segments(points, { to })`, and in `sketchAsync` the batch can run on the GPU. A query reads the mesh revision that made it. Inside a `steps` rule, `force.project(query)` pulls points onto that surface.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, box, query, pointCloud, instanceOnPoints, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], seed: 5, pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => {
  const ball = sphere(1.3, { segments: 32, rings: 16 });
  const q = query(ball);
  const drops = t.times(16, (k) => { const a = (k / 16) * Math.PI * 2; return q.ray([Math.cos(a) * 3, Math.sin(a) * 3, 0.4], [-Math.cos(a), -Math.sin(a), 0]); }).filter(Boolean);
  const marks = instanceOnPoints(box(0.12), pointCloud(drops.map((h) => h.position)).points);
  return view([ball, marks], { camera: orthographic({ eye: [5, 6, 4], span: 4 }), pen: 'ink', creaseAngle: 180 });
});
```
