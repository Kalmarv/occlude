A mesh is an immutable value. Every edit returns a new mesh and keeps the old one. The rows keep their identity across edits. A selection from one revision applies again on the next.

## subdivide()

<include>/_sig/3d.Mesh.subdivide.mdx</include>

`mesh.subdivide(levels)` splits every face and keeps the surface it represents: a quad becomes four quads, a triangle four triangles. Each level doubles the resolution. It does not round a box or smooth anything. Here the same wave moves three planes at levels 1, 2 and 3. The view draws every fold, so the grids show.

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const wave = (p) => [0, 0, 0.35 * Math.sin(p.x * 2) * Math.cos(p.y * 2)];
  const sheets = t.times(3, (k) => plane(2.2, 2.2).subdivide(k + 1).displace(wave).translate([k * 2.6 - 2.6, 0, 0]));
  return view(sheets, { camera: orthographic({ eye: [1, 6, 5], target: [0, 0, 0], span: 9 }), stroke: 'ink', creaseAngle: 0 });
});
```

## displace()

<include>/_sig/3d.Mesh.displace.mdx</include>

`mesh.displace(field)` moves each point by a triple from the field, or by a number along the point's normal. One pass, one new mesh.

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], seed: 4, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => view(plane(5, 5).subdivide(4).displace((p) => [0, 0, 0.7 * t.noise(p.x * 0.6, p.y * 0.6)]), { camera: orthographic({ eye: [6, 8, 5], span: 8 }), stroke: 'ink', creaseAngle: 0 }));
```

## steps()

<include>/_sig/3d.Mesh.steps.mdx</include>

`mesh.steps(count, rule)` is the frozen edit loop, the same as a material's. The rule reads `current` and writes `next`. The shorthand `{ move, set }` applies to every point, and a numeric `move` follows the vertex normal. Here one rule lifts the middle of a sheet a little on each step. The three sheets are the rule applied 0, 4 and 10 times.

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const sheet = plane(2.2, 2.2).subdivide(3);
  const lift = { move: (p) => [0, 0, 0.06 * Math.max(0, 1 - Math.hypot(p.x, p.y))] };
  const sheets = [0, 4, 10].map((n, k) => sheet.steps(n, lift).translate([k * 2.6 - 2.6, 0, 0]));
  return view(sheets, { camera: orthographic({ eye: [1, 6, 5], target: [0, 0, 0], span: 9 }), stroke: 'ink', creaseAngle: 0 });
});
```

## attribute() · faceAttribute()

<include>/_sig/3d.Mesh.attribute.mdx</include>
<include>/_sig/3d.Mesh.faceAttribute.mdx</include>

`mesh.attribute(name, field)` adds a typed point column, and `faceAttribute` a face column. 
```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], seed: 3, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#A84932' }) } }, (t) => {
  const sheet = plane(4, 4).subdivide(3)
    .attribute('h', (p) => 0.5 + 0.5 * t.noise(p.x, p.y))
    .displace((p) => [0, 0, p.h])
    .faceAttribute('high', (f) => f.center[2] > 0.75);
  return view(sheet, { camera: orthographic({ eye: [5, 7, 5], span: 6 }), stroke: 'ink', creaseAngle: 0, hatch: { spacing: mm(1.4), angle: 45, stroke: 'shade', select: (f) => f.high === true } });
});
```

## smooth()

<include>/_sig/3d.Mesh.smooth.mdx</include>

Replaces a column by the mean of itself and its neighbours, `steps` times. It finds the domain from the name. A point column averages over the points an edge joins to it. A face column averages over the faces that share an edge with it. A corner column averages over the corners of its point and of its face. The values must be numbers, or vectors of the same length.

A hard edge in a column becomes a ramp, and every pass widens the ramp. Here one column holds 1 above a noise threshold and 0 below it. The black mesh lifts that column as it is, and the red mesh lifts it after four passes.

```ts live
import { sketch, pen, mm, group } from 'occlude';
import { plane, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [2, 1], seed: 4, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }), shade: pen({ width: mm(0.2), color: '#A84932' }) } }, (t) => {
  const b = t.bounds();
  const rough = plane(4, 4).subdivide(4).attribute('h', (p) => (t.noise(p.x * 1.4, p.y * 1.4) > 0.55 ? 1 : 0));
  const lift = (m) => m.displace((p) => [0, 0, p.h * 0.9]);
  const camera = orthographic({ eye: [5, 7, 5], span: 9 });
  return [
    group({ translate: [-0.24 * b.w, 0] }, view(lift(rough), { camera, stroke: 'ink', creaseAngle: 0 })),
    group({ translate: [0.24 * b.w, 0] }, view(lift(rough.smooth('h', { steps: 4 })), { camera, stroke: 'shade', creaseAngle: 0 })),
  ];
});
```

## grid()

<include>/_sig/3d.grid.mdx</include>

A regular point grid in model space, centred at the origin: `cols` by `rows`, and `layers` deep, at `spacing`. Each point has `i`, `j` and `k` columns. It is a point domain for placement, so it goes into `instanceOnPoints` or a query batch.

```ts live
import { sketch, pen, mm } from 'occlude';
import { grid, box, instanceOnPoints, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const pts = grid({ cols: 5, rows: 5, layers: 3, spacing: 0.9 });
  const cubes = instanceOnPoints(box(0.3), pts.points, { scale: (p) => 0.4 + 0.6 * ((p.i + p.j + p.k) % 3) / 2 });
  return view(cubes, { camera: orthographic({ eye: [5, 7, 5], span: 6.5 }), stroke: 'ink' });
});
```

## extrude()

<include>/_sig/3d.Mesh.extrude.mdx</include>

`mesh.extrude(faces, offset)` raises a connected face selection as one region. Each connected part of the selection becomes a translated cap, and every boundary edge of the region grows a wall. `offset` is a model vector, or `{ distance }` along the region's mean normal.

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const sheet = plane(4, 4).subdivide(3);
  const middle = sheet.faces.filter((f) => Math.hypot(f.center[0], f.center[1]) < 1.2);
  const raised = sheet.extrude(middle, { distance: 0.7 });
  return view(raised, { camera: orthographic({ eye: [5, 7, 5], span: 6 }), stroke: 'ink', creaseAngle: 20 });
});
```

## Topology

A row knows its neighbours: `point.edges`, `point.adjacent`, `face.points`, `face.edges`, `face.adjacent` and `edge.faces`. A row also knows its own place. A point answers `x`, `y` and `z`. A face answers `center` and `area`. An edge answers `length` and `mid`, and 2D says `mid` for the same thing. A selection has `.adjacent()` for one hop out, `.connected()` for everything it reaches, and `.components()` for its pieces. A face selection also has `.boundaryEdges()`. Faces are neighbours through a shared edge, not a shared corner. Here the cap is one selection, and the ring is its one-hop neighbours with the cap removed.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, box, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#A84932' }), blue: pen({ width: mm(0.15), color: '#2457D6' }) } }, (t) => {
  const ball = sphere(1.3, { segments: 24, rings: 12 });
  const cap = ball.faces.filter((f) => f.normal[2] > 0.9);
  const ring = cap.adjacent().subtract(cap);
  const tagged = ball.faceAttribute('zone', (f) => (cap.has(f) ? 2 : ring.has(f) ? 1 : 0));
  const pieces = box(0.6).translate([2.2, 0, 0]);
  return view([tagged, pieces], { camera: orthographic({ eye: [3, 4, 6], target: [0.6, 0, 0], span: 5 }), stroke: 'ink', creaseAngle: 180, hatch: [{ spacing: mm(1.2), angle: 45, stroke: 'shade', select: (f) => f.zone === 2 }, { spacing: mm(1.2), angle: 135, stroke: 'blue', select: (f) => f.zone === 1 }] });
});
```

## Forces

These are the 3D forces, from `occlude/3d`. They are not the material forces of [Steps](/docs/reference/steps): a 3D force takes world geometry, not rows. Inside a `steps` rule, a force is a field of the point that returns a displacement. `force.attract(target, { strength })` pulls toward a world point. `force.plane({ origin, normal, side })` pushes a point back to one side of a plane. `side` is `'above'` or `'below'`. `force.project(query)` pulls onto a surface. `force.sum` adds them.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, force, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const ceiling = force.plane({ origin: [0, 0, 0.6], normal: [0, 0, 1], side: 'below' });
  const pull = force.attract([0, 0, -1.5], { strength: 0.12 });
  const squashed = sphere(1.3, { segments: 32, rings: 16 }).steps(6, (cur, next) => next.move(cur.points, force.sum(ceiling, pull)));
  return view(squashed, { camera: orthographic({ eye: [5, 6, 3], span: 4.2 }), stroke: 'ink', creaseAngle: 180 });
});
```
