---
title: Instances and sampling
description: "Points on a surface, and one prototype placed at every point or face."
---

`t.scatter` puts points on a surface. `instanceOnPoints` and `instanceOnFaces` put a prototype with faces at each one. The result is a value of points, one for each copy, and it goes into `view` like any value with faces. `instances.realize()` makes one ordinary value from all the copies when you need the words of faces.

## t.scatter() on a surface

It takes a value with faces and returns points on its surface. The points are the one geometry, with no edges. Each point has the columns of the face under it and the point columns there. Each row also has a `.sample`: the position, the triangle `normal`, the `face` and the barycentric weights. `t.scatter(m, { count })` places `count` points weighted by area. `t.scatter(m, { spacing })` keeps points at least `spacing` apart in world units. `weight: (face) => number` biases both forms. A face selection is the surface that it names: `t.scatter(m.faces.filter((f) => f.normal[2] > 0.85), { spacing })` puts points on those faces only. The `source` of each point is the face under it. A write or a move of the points keeps each sample.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, instanceOnPoints, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], seed: 7, pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const ball = sphere(1.2, { segments: 32, rings: 16 });
  const pts = t.scatter(ball, { spacing: 0.32, maxPoints: 120, maxAttempts: 4000, weight: (f) => (f.normal[2] > 0 ? 1 : 0) });
  const studs = instanceOnPoints(sphere(0.07, { segments: 8, rings: 4 }), pts.points);
  return view([ball, studs], { camera: orthographic({ eye: [4, 5, 5], span: 3.6 }), pen: 'ink', creaseAngle: 180 });
});
```

## instanceOnPoints()

<include>/_sig/3d.instanceOnPoints.mdx</include>

Places one prototype with faces at every point of a point set. `scale`, `rotate` and `offset` are constants or fields on the source point rows. A 2D point is a 3D point at z = 0. A 2D point selection, a material or a list of `[x, y]` pairs stands on the ground plane, with its columns. `pointCloud` takes the same 2D points. `alignAxis('z', normal)` gives the rotation that stands the prototype on a surface.

The result has one point for each copy, where the copy stands. The point keeps the columns of the point under it, and that point is its `source`. The column `scale` holds the three factors of the copy. The column `rotate` holds the turn as you gave it. It is Euler degrees `[x, y, z]`, or the `quaternion` of a rotation value when a copy has one. The words of points apply: `points.set('scale', [2, 2, 2])` makes every copy bigger, and `move` and `translate` move the copies. `instances.prototype` is the prototype, and the words of points keep it. `instances.realize()` makes one ordinary value from all the copies (see below).

```ts live
import { sketch, pen, mm } from 'occlude';
import { plane, cone, alignAxis, instanceOnPoints, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], seed: 42, pens: { ink: pen({ width: mm(0.3), color: '#18202A' }) } }, (t) => {
  const ground = plane(5).subdivide(3).displace((p) => [0, 0, 0.5 * t.noise(p.x * 0.5, p.y * 0.5)]);
  const sites = t.scatter(ground, { spacing: 0.55, maxPoints: 50, maxAttempts: 3000 });
  const trees = instanceOnPoints(cone(0.14, 0.7, { segments: 8 }).translate([0, 0, 0.35]), sites.points, { rotate: (p) => alignAxis('z', p.sample.normal) });
  return view([ground, trees], { camera: orthographic({ eye: [6, 8, 6], target: [0, 0, 0.2], span: 8 }), pen: 'ink' });
});
```

## instanceOnFaces()

<include>/_sig/3d.instanceOnFaces.mdx</include>

Places one prototype at the centre of every face in a selection, aligned to the face. The same options as `instanceOnPoints`, read from the face rows.

```ts live
import { sketch, pen, mm } from 'occlude';
import { sphere, box, instanceOnFaces, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }) } }, (t) => {
  const ball = sphere(1.3, { segments: 14, rings: 7 });
  const studs = instanceOnFaces(box([0.12, 0.12, 0.3]), ball.faces.filter((f) => f.normal[2] > -0.2), { scale: (f) => 0.5 + f.area * 6 });
  return view([ball, studs], { camera: orthographic({ eye: [5, 6, 4], span: 4 }), pen: 'ink', creaseAngle: 180 });
});
```

## realize()

<include>/_sig/Material.realize.mdx</include>

Makes one ordinary value from all the copies. It has the faces, edges and points of the prototype one time for each copy, where that copy stands. Use it for the words of faces, because the instances have no faces. A row of the result has a list of two as its `source`: the prototype row, then its instance. `maxPoints` and `maxFaces` refuse a result that is too large, before the word makes it. Below, the copies of one post become one value. The tops of the posts take a face column, and the view hatches those faces.

```ts live
import { sketch, pen, mm } from 'occlude';
import { box, pointCloud, instanceOnPoints, view, orthographic } from 'occlude/3d';

export default sketch({ aspect: [1, 1], pens: { ink: pen({ width: mm(0.25), color: '#18202A' }), shade: pen({ width: mm(0.15), color: '#647767' }) } }, (t) => {
  const posts = instanceOnPoints(box([0.3, 0.3, 1]), pointCloud(t.times(5, (k) => [k * 0.7 - 1.4, 0, 0.5])).points, { rotate: (p) => [0, 0, p.index * 12] });
  const fence = posts.realize().faces.set('top', (f) => f.normal[2] > 0.9);
  return view(fence, { camera: orthographic({ eye: [3, 5, 3], target: [0, 0, 0.5], span: 2.6 }), pen: 'ink', hatch: { spacing: mm(1.5), angle: 45, pen: 'shade', select: (f) => f.top } });
});
```
