All randomness comes from the sketch's seed: `seed` in the config, or `?seed=` in the studio's URL. The same source and the same seed give the same drawing. `t.seed` is the number or string this run resolved to. Nothing here uses `Math.random`.

## t.rnd() · t.rndInt() · t.pick() · t.chance()

<include>/_sig/Toolkit.rnd.mdx</include>
<include>/_sig/Toolkit.rndInt.mdx</include>
<include>/_sig/Toolkit.pick.mdx</include>
<include>/_sig/Toolkit.chance.mdx</include>

`rnd()` gives 0 to 1, `rnd(n)` 0 to n, `rnd(a, b)` a to b. `rndInt(n)` gives a whole number from 0 to n minus 1. `rndInt(a, b)` gives a whole number from a to b, and both ends can come up. A die is `rndInt(1, 6)`. Each call is one draw from the stream. `pick` returns one element of a list. `chance(p)` is true with probability `p`.

```ts live
import { sketch, circle, rect } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 3 }, (t) => t.times(40, () => {
  const x = t.rnd(10, 90), y = t.rnd(10, 90), r = t.rnd(1, 6);
  const pen = t.pick(['pigma-005-black', 'stabilo-88-blue', 'stabilo-88-green']);
  return t.chance(0.3) ? rect(x - r, y - r, r * 2, r * 2, { pen }) : circle(x, y, r, { pen });
}));
```

## t.gaussian()

<include>/_sig/Toolkit.gaussian.mdx</include>

A normal draw. Most values land within one `sd` of `mean`, a few land far out, and no bound holds them. `t.rnd(a, b)` has hard walls, and `t.gaussian` has a typical size with no wall. The defaults are mean 0 and spread 1. Every stream has it too: `t.stream('grass').gaussian(0, 4)`.

Three tufts. The lean and the length of each blade are normal draws.

```ts live
import { sketch, stroke, add, mul, fromAngle } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 5 }, (t) => t.times(3, (k) => {
  const root = [24 + k * 26, 92 - k * 3];
  return t.times(220, () => {
    const foot = add(root, [t.gaussian(0, 2.4), 0]);
    const blade = mul(fromAngle(-Math.PI / 2 + t.gaussian(0, 0.2)), 3 + Math.abs(t.gaussian(0, 18)));
    return stroke([foot, add(foot, blade)], { pen: k === 1 ? 'stabilo-88-green' : 'pigma-005-black' });
  });
}));
```

## t.noise()

<include>/_sig/Toolkit.noise.1.mdx</include>

Seeded smooth noise from −1 to 1. Sample it at large steps for terrain and at small steps for texture. Within a seed, the same coordinates always give the same value. Two coordinates read a plane. Three coordinates read a solid. The solid changes at one rate along every axis, so it wraps a sphere with no seam. A third coordinate of 0 is a point in the solid, not the plane, so a walk through z does not jump.

```ts live
import { sketch, stroke } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 5 }, (t) => t.times(14, (k, u) => stroke(t.times(60, (i, v) => [8 + v * 84, 10 + u * 80 + t.noise(v * 4, u * 3) * 5]))));
```

## t.stream()

<include>/_sig/Toolkit.stream.mdx</include>

A random stream of its own, keyed off the seed, with `rnd`, `pick`, `chance` and `noise`. Two parts of a drawing that read separate streams do not disturb each other when one of them changes. Drag the dot count: the bars stay where they are.

```ts live
import { sketch, circle, line, ui } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 8 }, (t) => {
  const count = ui(24, { min: 4, max: 80, step: 1, label: 'spots' });
  const spots = t.stream('spots'), bars = t.stream('bars');
  return [t.times(count, () => circle(spots.rnd(10, 90), spots.rnd(10, 90), 1.5)), t.times(6, () => { const y = bars.rnd(15, 85); return line(10, y, 90, y, { pen: 'stabilo-88-blue' }); })];
});
```

## a die on every square

`rndInt` counts things. Here each cell of a grid rolls a die and draws that many dots. `title` reads the seed back from `t.seed`, and the drawing does not use it.

```ts live
import { sketch, dots, rect, mm, pen } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 9, pens: { ink: pen({ width: mm(1.6), color: '#23252B' }) } }, (t) => {
  const title = `dice, seed ${t.seed}`;
  return t.grid({ cols: 5, rows: 5, gap: 3 }).map((c) => [
    rect(c.x + 1, c.y + 1, c.w - 2, c.h - 2, { pen: 'pigma-005-black' }),
    dots(t.times(t.rndInt(1, 6), () => [t.rnd(c.x + 3, c.x + c.w - 3), t.rnd(c.y + 3, c.y + c.h - 3)]), { pen: 'ink' }),
  ]);
});
```
