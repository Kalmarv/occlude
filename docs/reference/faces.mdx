---
title: Faces
description: The regions that a planar material encloses, and what you can read from them.
---

A planar material is one whose edges meet only at shared vertices. Its edges divide the page into regions. `faces()` reads those regions. Each face knows its area, its centroid, its walls and its neighbours. A face is an area: `polygon(f)` fills it and `distanceTo(f)` measures from its walls. A material with no closed chain whose edges branch, such as a tiling or a hex field, is an area too. Its area is the union of its faces: the outer rim and the holes.

:::note
On one face every reading is a property: `face.edges`, `face.boundaryEdges`. On a collection of faces, `edges` and `points` are properties too. `boundaryEdges()` and `contours()` are calls. A collection of faces is the selection of all its faces, and it has the words of a point or edge selection. Iterate it, or use `length`, `at`, `map`, `find`, `some`, `every`, `filter` and `groupBy`. It also has `has`, `in`, `rows`, `complement`, `union`, `intersect`, `subtract`, `adjacent`, `connected`, `components` and `extract`. They have the same meanings as on the [selections](/docs/reference/selections) page.
:::

## planarize

<include>/_sig/Material.planarize.mdx</include>

<AutoTypeTable path="../occlude/src/faces.ts" name="PlanarizeOpts" />

Makes a shared vertex at every crossing and at every place where an endpoint touches an edge. The result is planar, so `faces()` can read it. Edges that do not touch stay apart. Columns carry over, and a new vertex gets interpolated values. Where the edges at a crossing do not agree, the new vertex takes the values of the edge with the lowest row. A split of that edge gives the same values. A vertex that was there before keeps its own values. `point` overrides any column. Below, the blue rings are the two new vertices, where four edges meet.

```ts live
import { sketch, circle, strokes } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const two = t.material(circle(38, 50, 30), circle(62, 50, 30));
  const planar = two.planarize();
  return [strokes(planar), planar.points.filter((p) => p.edges.length === 4).map((p) => circle(p, 2.5, { pen: 'stabilo-88-blue' }))];
});
```

## faces

<include>/_sig/Material.faces.mdx</include>

The bounded regions of a planar material, as a collection. Iterate it, or use `length`, `at(i)`, `map`, `filter` and `groupBy`. Each call returns the same collection, so a face from any call is valid everywhere. If the material has a crossing without a vertex, the call fails and the message tells you to planarize.

```ts live
import { sketch, circle, polygon, fill, mm } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const cells = t.material(circle(38, 50, 30), circle(62, 50, 30)).planarize().faces();
  return cells.map((f, i) => polygon(f, { stroke: false, fill: fill('hatch', { angle: i * 60, spacing: mm(1.2) }) }));
});
```

## face

<include>/_sig/Face.index.mdx</include>
<include>/_sig/Face.area.mdx</include>
<include>/_sig/Face.perimeter.mdx</include>
<include>/_sig/Face.bounds.mdx</include>
<include>/_sig/Face.centroid.mdx</include>
<include>/_sig/Face.contours.mdx</include>
<include>/_sig/Face.extract.mdx</include>

One region. `area` is the outer area minus the holes. `centroid` is the centroid of that filled area. `contours()` holds the outer loop and the holes as closed records. A face is an area. You can give it as it is to `polygon`, `distanceTo`, `force.boundary`, `t.within`, `clip`, `mask`, `t.material` and `t.sample`. `t.material(f)` gives its walls with their ids. To keep the faces of a collection that lie in an area, use `t.within(cells, area, { keep })`. `keep` is `'contained'` (the default), `'centroid'` or `'touching'`, the same words as for points and edges. `face.extract()` gives the face as a new material, with its edges, its corners, its columns and its ids. A face always has the same winding. The outer loop turns counter-clockwise when y points up, and each hole turns the other way. `contours()` and the walls of `face.extract()` both turn this way. A normal from `along` points to the left of the travel, so on a face's walls it points into the face.

```ts live
import { sketch, circle, strokes, distanceTo } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const cells = t.material(circle(38, 50, 30), circle(62, 50, 30)).planarize().faces();
  return cells.map((f) => [
    strokes(t.isolines(distanceTo(f), 3)),
    circle(f.centroid, 1.5, { pen: 'stabilo-88-blue' }),
  ]);
});
```

`area` and `perimeter` together say how round a face is: a disc scores 1 and a ragged sliver scores near 0. `bounds` is the box the face sits in. A wide cell takes a hatch across it, and a tall one takes a hatch down it. `index` is the face's row in the collection. That is all a drawing needs to give every third cell another pen.

```ts live
import { sketch, polygon, fill, mm } from 'occlude';

export default sketch({ aspect: [3, 2], seed: 5 }, (t) => {
  const cells = t.voronoi(t.relax(t.scatter({ spacing: 22 }), { iterations: 3 }));
  return cells.faces().map((f) => {
    const round = (4 * Math.PI * f.area) / (f.perimeter * f.perimeter);
    const angle = f.bounds.w > f.bounds.h ? 0 : 90;
    return polygon(f, { fill: fill('hatch', { angle, spacing: mm(0.5 + 2.2 * round) }), pen: f.index % 3 === 0 ? 'stabilo-88-blue' : undefined });
  });
});
```

## face.id

<include>/_sig/Face.id.mdx</include>

The identity of the face. It comes from the walls of the face. So the same face has the same id after `steps`, after a transform, and after a `planarize` that keeps its walls. Use `id`, not `index`, to find a face again in another state. Below, a round hex net stretches in one step, and each cell finds its rest shape by `id`. The hatch is tighter where a cell grew.

```ts live
import { sketch, polygon, strokes, circle, fill, mm } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 3 }, (t) => {
  const net = t.within(t.hexes({ spacing: 9 }), circle(50, 50, 38));
  const pulled = net.steps(1, (cur, next) => next.move(cur.points, (p) => [0.1 * (p.x - 50) * (1 + Math.sin(p.y / 12)), 0.1 * (p.y - 50) * (1 + Math.sin(p.x / 12))]));
  const rest = net.faces();
  return [
    pulled.faces().map((f) => {
      const before = rest.find((g) => g.id === f.id);
      const grown = before ? f.area / before.area : 1;
      return polygon(f, { stroke: false, fill: fill('hatch', { angle: 45, spacing: mm(Math.max(0.5, 0.5 + 5 * (1.45 - grown))) }) });
    }),
    strokes(pulled),
  ];
});
```

## face.edges · face.points · face.boundaryEdges

<include>/_sig/Face.edges.mdx</include>
<include>/_sig/Face.points.mdx</include>
<include>/_sig/Face.boundaryEdges.mdx</include>

`face.edges` is every edge that belongs to this face: its walls, and any loose edge that runs into it from a wall. A line that touches nothing belongs to no face. To take the edges that lie inside a face by position, use `t.within(m.edges, face)`. `face.boundaryEdges` is the walls only. A wall is an edge between this face and another face, or between this face and the outside. `face.points` holds the endpoints of `face.edges`.

:::warning
For a plain pile of shapes, `edges` and `boundaryEdges` are the same selection. They differ only when a loose line runs into a region. Use `boundaryEdges` when you want an outline.
:::

Below, one cell with a loose line that runs in from its wall. `edges` (blue) holds the line. `boundaryEdges` (black, on top) holds the walls only.

```ts live
import { sketch, rect, line, strokes, append } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const room = append(t.material(rect(15, 15, 70, 70)), t.material(line(15, 50, 60, 50))).planarize();
  const cell = room.faces().at(0);
  return [strokes(cell.edges, { pen: 'stabilo-88-blue' }), strokes(cell.boundaryEdges)];
});
```

## face.adjacent

<include>/_sig/Face.adjacent.mdx</include>

The faces on the other side of this face's walls. Two faces are neighbours when they share an edge. A shared corner is not enough. Below, the blue face has the most neighbours, and a hatch marks each of them.

```ts live
import { sketch, circle, polygon, fill, mm, strokes } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const cells = t.material(circle(38, 50, 30), circle(62, 50, 30), circle(50, 26, 18)).planarize().faces();
  const most = Math.max(...cells.map((f) => f.adjacent.length));
  const middle = cells.filter((f) => f.adjacent.length === most).at(0);
  return [strokes(cells.edges), middle.adjacent.map((f) => polygon(f, { stroke: false, fill: fill('hatch', { angle: 45, spacing: mm(1.5) }) })), strokes(middle.boundaryEdges, { pen: 'stabilo-88-blue' })];
});
```

## cells.edges · points · boundaryEdges() · contours()

<include>/_sig/FaceSelection.edges.mdx</include>
<include>/_sig/FaceSelection.points.mdx</include>
<include>/_sig/FaceSelection.boundaryEdges.mdx</include>
<include>/_sig/FaceSelection.contours.mdx</include>

The same readings for a collection or a selection of faces. `edges` is every edge that touches a selected face, once. `strokes(cells)` draws those edges, and it draws each wall one time. `boundaryEdges()` is the outline of the selected faces as one region. A wall between two selected faces is not part of it. The boundary of a hole is part of it. `contours()` is that outline as closed loops. `polygon` reads it to fill the region.

A collection of faces is several areas, so `polygon(cells)` is a type error. Write `polygon(cells.contours())` for the union, or `cells.map((f) => polygon(f))` for each face. As points, a collection of faces is the centroids of its faces: `dots(cells)`, `distanceToPoints(cells)` and `material(cells)` put one point in each face. `cells.points` gives the corners.

```ts live
import { sketch, circle, polygon, fill, mm, strokes } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const cells = t.material(circle(38, 50, 30), circle(62, 50, 30)).planarize().faces();
  const crescents = cells.filter((f) => Math.abs(f.centroid[0] - 50) > 1);
  return [polygon(crescents.contours(), { stroke: false, fill: fill('hatch', { angle: 0, spacing: mm(1.5) }) }), strokes(crescents.boundaryEdges(), { pen: 'pigma-05-black' })];
});
```

## cells.adjacent()

<include>/_sig/FaceSelection.adjacent.mdx</include>
<include>/_sig/FaceSelection.components.mdx</include>

The faces on the other side of the walls of the selected faces, one step out, the selected faces excluded. Two selected faces that share a wall are each other's inside, not each other's neighbour. `sel.union(sel.adjacent())` is the selection grown by a ring, and says so. `connected()` is the selection and every face that you can reach from it across walls. `components()` divides the selected faces into pieces that share walls, and keys them `0, 1, 2 …`. Below, the blue cells are the selection, and the hatch is its ring.

```ts live
import { sketch, polygon, rect, fill, mm, strokes } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const cells = t.voronoi(t.scatter({ spacing: 14 })).faces();
  const seed = t.within(cells, rect(40, 40, 20, 20), { keep: 'centroid' });
  const ring = seed.adjacent();
  return [strokes(cells.edges), ring.map((f) => polygon(f, { stroke: false, fill: fill('hatch', { angle: 45, spacing: mm(1.2) }) })), strokes(seed.boundaryEdges(), { pen: 'stabilo-88-blue' })];
});
```

Below, the small cells fall into towns, and `components()` finds each town. Each town gets its own hatch. `extract()` takes the left town out as a new material, and the sketch draws it again, smaller, in blue.

```ts live
import { sketch, polygon, strokes, fill, mm } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 12 }, (t) => {
  const dense = (x, y) => 0.1 + Math.exp(-((x - 35) ** 2 + (y - 40) ** 2) / 200) + Math.exp(-((x - 68) ** 2 + (y - 66) ** 2) / 150);
  const cells = t.voronoi(t.relax(t.scatter(dense, { spacing: 3 }), { iterations: 2, density: dense })).faces();
  const towns = cells.filter((f) => f.area < 25).components().filter((town) => town.length > 2);
  const middle = towns.find((town) => town.containing([35, 40]).length > 0) ?? towns[0];
  return [
    strokes(cells, { pen: 'pigma-005-black' }),
    towns.map((town) => polygon(town.contours(), { stroke: false, fill: fill('hatch', { angle: 20 + 50 * town.key, spacing: mm(1) }) })),
    strokes(middle.extract().scale(0.5, { origin: 'center' }), { pen: 'stabilo-88-blue' }),
  ];
});
```

## cells.containing()

<include>/_sig/FaceSelection.containing.mdx</include>

The faces the given places fall in. Give one point as `[x, y]` or `{ x, y }`, or give many as an array, a material, or a point selection. A place inside a face picks that face. A place on a wall picks nothing, because a wall is where two faces stop. A place outside every face picks nothing. Two places in the same face still name it once, because a selection is a set. A face with a hole does not hold what sits in the hole. The face of the hole holds it. On a selection the word answers with its own members only.

A tangle of circles and lines, and the one face under each blue mark.

```ts live
import { sketch, circle, line, strokes, polygon, fill, append, faces, mm } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 6 }, (t) => {
  const marks = [[30, 32], [62, 44], [46, 74]];
  const tangle = append(
    ...t.times(6, () => t.material(circle(t.rnd(24, 76), t.rnd(24, 76), t.rnd(14, 28)))),
    ...t.times(4, () => t.material(line(t.rnd(0, 100), t.rnd(0, 20), t.rnd(0, 100), t.rnd(80, 100)))),
  ).planarize();
  return [
    strokes(tangle),
    faces(tangle).containing(marks).map((f) => polygon(f, { stroke: false, fill: fill('hatch', { angle: 35, spacing: mm(1.2) }) })),
    marks.map((p) => circle(p, 1.2, { pen: 'stabilo-88-blue' })),
  ];
});
```

## measure

<include>/_sig/FaceSelection.measure.mdx</include>

<AutoTypeTable path="../occlude/src/measure.ts" name="MeasureOpts" />

Measures each face: `centroid`, `orientation`, `elongation`, and the largest inscribed circle as `inscribedCentre` and `inscribedRadius`. With a field you also get `integral`, `mean` and `weightedCentroid` for each face. Read one face with `forFace(f)`, or iterate the results. `step` is the side of one raster cell, a length in the units of the material. In a material with a curved `space`, the call measures `area`, `perimeter`, the inscribed circle and the field values in that space. `face.area` and `face.perimeter` are too. `centroid`, `orientation` and `elongation` stay in the coordinates.

```ts live
import { sketch, circle, strokes, line, distance } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const cells = t.material(circle(38, 50, 30), circle(62, 50, 30)).planarize().faces();
  const light = (x, y) => Math.max(0, 1 - distance([x, y], [20, 20]) / 70);
  const m = cells.measure(light, { step: 0.7 });
  return [strokes(cells.edges), [...m].map((r) => [circle(r.centroid, 1.2), circle(r.weightedCentroid, 1.2, { pen: 'stabilo-88-blue' }), line(r.centroid, r.weightedCentroid, { pen: 'stabilo-88-blue' })])];
});
```

## edge.faces

<include>/_sig/Edge.faces.mdx</include>

The faces on the two sides of an edge. A wall between two cells has two. An outer wall or a loose edge inside a face has one. An edge that no face touches has none. The material must be planar, and `edge.faces` builds the face map itself. A material that is not planar fails with the same message as `faces()`. Below, the walls with two faces are blue.

```ts live
import { sketch, circle, strokes } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const m = t.material(circle(38, 50, 30), circle(62, 50, 30)).planarize();
  const walls = m.edges.filter((e) => e.faces.length === 2);
  return [strokes(m), strokes(walls, { pen: 'stabilo-88-blue' })];
});
```

## faceAttribute() · faceAttributes()

<include>/_sig/Material.faceAttribute.mdx</include>
<include>/_sig/Material.faceAttributes.mdx</include>

A value that belongs to what the walls enclose. A face is not a row, so a face column takes the face's own walls as its key. The column then follows the material through any edit that leaves those walls alone. It follows a SPLIT of a wall too, because a child wall remembers its parent.

`transfer` says what a face does when its boundary really changes. `'nearest'`, the default, takes the value of the old face it shares the most walls with. `'drop'` stops there. A face that shares no wall with an old face starts from `fallback`. A face column is sparse, so `f.height` may be `undefined`. `faceAttributes` gives several columns at once. Inside a step, `next.setFaces(faces, values)` writes the same column.

```ts live
import { sketch, strokes, polygon, fill, mm } from 'occlude';

export default sketch({ aspect: [3, 2], seed: 9 }, (t) => {
  const cells = t.voronoi(t.relax(t.scatter({ spacing: 26 }), { iterations: 4 }));
  // Two columns, given once, to the cells as they are now. A second call
  // sees the first call's column.
  const tinted = cells.faceAttribute('tone', () => t.rnd()).faceAttributes({ turn: () => t.rnd(170) });
  // Then every wall is split and every inside vertex wanders. The walls are
  // new rows with new ids, and each one still names the wall it came from,
  // so every cell keeps the tone it was given.
  const cracked = tinted.steps(1, (cur, next) => {
    next.splitEdges(cur.edges, { at: 0.5 });
  }, (cur, next) => {
    const inner = cur.points.filter((p) => p.x > 1 && p.x < t.width - 1 && p.y > 1 && p.y < t.height - 1);
    next.move(inner, (p) => [t.noise(p.x / 14, p.y / 14) * 2, t.noise(p.y / 14, p.x / 14) * 2]);
  });
  return [
    cracked.faces().map((f) => polygon(f, { fill: fill('hatch', { angle: f.turn, spacing: mm(0.7 + f.tone * 1.6) }), stroke: false })),
    strokes(cracked, { pen: 'pigma-005-black' }),
  ];
});
```
