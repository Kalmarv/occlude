---
title: Shapes
description: "The drawables: shapes, paths, groups, clips, masks and the modifiers that change a line."
---

A shape is exact geometry with drawing options. Coordinates are drawable units. One unit is 1 % of the short side of the drawable. A square drawable runs from 0 to 100 both ways. Wrap a value in `mm()` to give it in millimetres. Every shape takes a trailing options object. See [Shape options](#shape-options).

## circle

<include>/_sig/circle.mdx</include>

A circle with its centre at `(x, y)` and radius `r`.

```ts live
import { sketch, circle } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => t.times(5, (k) => circle(50, 50, 8 + k * 8)));
```

## rect

<include>/_sig/rect.mdx</include>

A rectangle with its corner at `(x, y)`. `mode: 'center'` puts the centre there instead. `radius` rounds the corners.

```ts live
import { sketch, rect } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => [rect(10, 10, 50, 36), rect(60, 60, 30, 30, 6, { mode: 'center' }), rect(65, 12, 25, 25, { mode: 'corner', pen: 'stabilo-88-blue' })]);
```

## line

<include>/_sig/line.mdx</include>

An open stroke from `(x1, y1)` to `(x2, y2)`.

```ts live
import { sketch, line } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => t.times(12, (k, u) => line(10, 10 + u * 80, 90, 90 - u * 80)));
```

## ellipse

<include>/_sig/ellipse.mdx</include>

An ellipse with radii `rx` and `ry`, turned by `rotation` degrees about its centre.

```ts live
import { sketch, ellipse } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => t.times(6, (k) => ellipse(50, 50, 40, 12, k * 30)));
```

## ngon

<include>/_sig/ngon.mdx</include>

A regular polygon: `sides` vertices on a circle of radius `r`, the first at `rotation` degrees.

```ts live
import { sketch, ngon } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => t.times(4, (k) => ngon(16 + k * 22.5, 50, 3 + k, 11, k * 15)));
```

## path

<include>/_sig/path.mdx</include>

A builder for one path. Call `moveTo`, `lineTo`, `quadTo`, `bezierTo`, `arcTo` and `close`, then `build(opts?)` to get a shape. The builder stays usable after `build`, so one path can become several shapes.

```ts live
import { sketch, path } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const p = path().moveTo(10, 70).bezierTo(30, 10, 70, 90, 90, 30);
  return [p.build(), p.lineTo(90, 90).lineTo(10, 90).close().build({ stroke: 'stabilo-88-blue' })];
});
```

## polygon

<include>/_sig/polygon.mdx</include>

One area from its boundary. Give a loop of pairs, several loops, contour records, a [face](/docs/reference/faces), a chain [material](/docs/reference/material), or a shape. `polygon` reads the area's `contours()`. A loop that is not closed gets a closing chord. `winding` decides the fill rule where loops nest or cross: `'evenodd'` (the default) makes every enclosed loop a hole, `'nonzero'` fills through.

```ts live
import { sketch, polygon, fill, mm } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const ring = (cx, r) => t.times(24, (k) => { const a = (k / 24) * Math.PI * 2; return [cx + Math.cos(a) * r, 50 + Math.sin(a) * r]; });
  const hatch = fill('hatch', { angle: 45, spacing: mm(1.2) });
  return [polygon([ring(27, 22), ring(27, 10)], { fill: hatch }), polygon([ring(73, 22), ring(73, 10)], { winding: 'nonzero', fill: hatch })];
});
```

## label

<include>/_sig/label.mdx</include>
<include>/_sig/labelWidth.mdx</include>

Single-stroke text with cap height `h`: capitals, digits and basic punctuation. The font has capitals only, so lower case comes out as capitals. The point `(x, y)` is the top left of the text. `align: 'center'` or `'right'` moves the anchor. The default is `'left'`. `labelWidth(text, h)` is the width the same call will use.

```ts live
import { sketch, label, labelWidth, rect } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const w = labelWidth('OCCLUDE', 14);
  return [rect(50 - w / 2 - 3, 40 - 3, w + 6, 14 + 6, { pen: 'stabilo-88-blue' }), label('OCCLUDE', 50, 40, 14, { align: 'center' }), label('CAP HEIGHT 7', 50, 70, 7, { align: 'center' })];
});
```

## group

<include>/_sig/group.mdx</include>

Applies a transform, a default pen, a default `z` and default modifiers to its children. `rotate` and `scale` pivot on `origin`: a pair, or `'center'` for the middle of the drawable. Without `origin` they pivot on the user origin, the corner of the drawable.

:::warning
`origin: 'center'` is the middle of the drawable, not the middle of the group. To pivot on a shape's own middle, give that point: `origin: [cx, cy]`.
:::

```ts live
import { sketch, group, rect } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => [
  t.times(6, (k) => group({ rotate: k * 15, origin: 'center' }, rect(58, 12, 30, 12))),
  t.times(6, (k) => group({ rotate: k * 15, origin: [73, 18], pen: 'stabilo-88-blue' }, rect(58, 12, 30, 12))),
]);
```

## clip · invert

<include>/_sig/clip.mdx</include>
<include>/_sig/invert.mdx</include>

`clip` keeps only the ink of its children that lies inside the shape. The shape itself is not drawn and hides nothing. Nested clips intersect. `invert(shape)` turns the region inside out, so `clip(invert(shape), …)` keeps the ink outside.

```ts live
import { sketch, clip, invert, circle, line } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const across = t.times(24, (k, u) => line(0, u * 100, 100, u * 100));
  const down = t.times(24, (k, u) => line(u * 100, 0, u * 100, 100, { pen: 'stabilo-88-blue' }));
  return [clip(circle(50, 50, 30), ...across), clip(invert(circle(50, 50, 38)), ...down)];
});
```

## mask

<include>/_sig/mask.mdx</include>

A shape that hides what is beneath it and draws nothing. This is the hidden-line tool.

```ts live
import { sketch, mask, circle, line } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => [...t.times(20, (k, u) => line(5, 10 + u * 80, 95, 10 + u * 80)), mask(circle(50, 50, 28)), circle(50, 50, 28, { pen: 'stabilo-88-blue' })]);
```

## modify

<include>/_sig/modify.mdx</include>

Applies a stack of modifiers to its children, in order. Nested stacks compose: the inner one runs first. Each modifier also exists as a shape option of the same name.

```ts live
import { sketch, modify, smooth, wobble, mm, ngon } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => [ngon(27, 50, 5, 24), modify([smooth(2), wobble(mm(0.8))], ngon(73, 50, 5, 24))]);
```

## wobble · decimate · dash

<include>/_sig/wobble.1.mdx</include>
<include>/_sig/decimate.1.mdx</include>
<include>/_sig/dash.1.mdx</include>

Modifiers that run after occlusion, on the ink that survives. `wobble` moves the strokes with seeded smooth noise, like a hand tremor. `amount` is a length, and `wavelength` sets the scale. After occlusion the ink is a list of separate strokes. `decimate` drops a fraction of them, at random from the seed. `{ stroke, fill }` sets the fraction for the outline and the fill separately. `dash` cuts the strokes into dashes of physical length. The pattern continues through hidden-line cuts.

```ts live
import { sketch, circle, modify, wobble, decimate, dash, mm } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => [
  modify([wobble(mm(1.2))], circle(27, 30, 20)),
  modify([decimate(0.5)], circle(73, 30, 20)),
  modify([dash(mm(3), mm(2))], circle(27, 74, 20)),
  modify([wobble(mm(0.8)), dash(mm(3), mm(2))], circle(73, 74, 20)),
]);
```

## smooth · roughen · deform

<include>/_sig/smooth.1.mdx</include>
<include>/_sig/roughen.1.mdx</include>
<include>/_sig/deform.1.mdx</include>

Modifiers that run before occlusion, on the outline itself. The changed silhouette is what hides, and what a fill follows. `smooth` relaxes corners toward curves. `roughen` breaks a clean edge into jitter, resampled every `detail`. `deform` moves the outline by a vector field `(x, y) => [dx, dy]`.

```ts live
import { sketch, rect, line, smooth, roughen, deform, mm } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => [
  t.times(30, (k, u) => line(0, 5 + u * 90, 100, 5 + u * 90, { pen: 'pigma-005-black' })),
  rect(6, 20, 26, 60, { opaque: true, modifiers: [smooth(3)] }),
  rect(37, 20, 26, 60, { opaque: true, modifiers: [roughen(mm(1.4))] }),
  rect(68, 20, 26, 60, { opaque: true, modifiers: [deform((x, y) => [Math.sin(y / 6) * 4, 0])] }),
]);
```

## stroke · strokes

<include>/_sig/stroke.mdx</include>
<include>/_sig/strokes.2.mdx</include>

Draw geometry as ink. `stroke` draws one contour or one list of pairs. `strokes` draws every chain of a [material](/docs/reference/material), a [selection](/docs/reference/selections) or a list of contours, once each, all with the same options. `strokes` reads the source's `curves()`. A material never draws itself. These are the words that make ink.

```ts live
import { sketch, stroke, strokes, circle } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => [stroke(t.times(40, (k, u) => [10 + u * 80, 50 + Math.sin(u * 12) * 20])), strokes(t.material(circle(50, 50, 40)), { pen: 'stabilo-88-blue' })]);
```

## Shape options

<AutoTypeTable path="../occlude/src/api.ts" name="ShapeOpts" />

Every shape accepts these. `fill` makes the shape opaque and gives it a texture. `opaque: true` hides with no texture. `stroke: false` draws no outline, and a pen name in `stroke` draws the outline in that pen while `fillPen` keeps the texture's. `translate`, `rotate`, `scale` and `origin` are the same transform a `group` applies. `bridge` joins stroke ends across gaps up to a length after occlusion, so hatch rows become one stroke.

```ts live
import { sketch, circle, rect, fill, mm } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => [rect(10, 20, 50, 50, { fill: fill('hatch', { angle: 30, spacing: mm(1.5) }), stroke: false }), circle(60, 55, 24, { opaque: true, pen: 'stabilo-88-blue' }), circle(78, 28, 14, { rotate: 20, scale: [1.6, 1], origin: [78, 28] })]);
```

## dots

<include>/_sig/dots.mdx</include>

A tap of the pen at every point: pen down, the pen's delay, pen up. `dots` is the third way to spell ink, beside `stroke`/`strokes` along a contour and `polygon` over an area. It marks every point of any geometry that has points. That is a material, a selection, a face collection, or a plain list of pairs.

A dot hides as a point. A shape drawn over it hides the whole dot, and nothing hides half of it. The preview shows it at nib width. The plan keeps it through the cleanup that drops zero-length moves. The machine gets one pen-down with that pen's settle. No points means no ink.

A dot of its own hides nothing a pen could draw. The engine judges a tap inside a region, so every tap rides in a region a hundredth of a millimetre across. A stroke under a cloud of dots comes out whole.

```ts live
import { sketch, dots, circle, strokes } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 8 }, (t) => {
  const field = t.scatter((x, y) => 0.15 + 0.85 * t.noise(x / 26, y / 26) ** 2, { spacing: 3.4 });
  const moon = circle(64, 36, 19, { opaque: true, pen: 'stabilo-88-blue' });
  // The taps go down first, so the moon hides the ones behind it — whole.
  return [dots(field), moon, strokes(t.material(circle(64, 36, 19)), { pen: 'stabilo-88-blue' })];
});
```
