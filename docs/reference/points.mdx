---
title: Points
description: Even distributions of points, their refinement, and the cells around them.
---

A distribution is a material of loose points. `scatter` makes one from a density field. `relax` and `settle` improve it. `voronoi` reads the cells around a set of points. All of them return material, so the rest of the vocabulary applies.

## t.scatter()

<include>/_sig/Toolkit.scatter.2.mdx</include>
<include>/_sig/Toolkit.scatter.3.mdx</include>

<AutoTypeTable path="../occlude/src/points.ts" name="ScatterOpts" />

Poisson-disk points over the drawable, at `spacing` where the field is 1 and further apart where it is lower. Where the field is 0, there are no points. Each point carries a `density` column with the field's value. With no field, the points are even.

```ts live
import { sketch, circle, distance } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 2 }, (t) => {
  const tone = (x, y) => Math.max(0, 1 - distance([x, y], [50, 50]) / 45);
  return t.scatter(tone, { spacing: 3 }).points.map((p) => circle(p, 0.4 + p.density * 1.2));
});
```

## t.throw()

<include>/_sig/Toolkit.throw.mdx</include>

<AutoTypeTable path="../occlude/src/points.ts" name="ThrowOpts" />

Independent random points, `count` of them. Give an area and the points land inside it. Give a field and each point stays with the chance the field gives at that place. A field of 0 has no points. This is the random counterpart of `t.scatter`. Nothing keeps the points apart, and two can land on one spot. It writes no column.

```ts live
import { sketch, circle } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 5 }, (t) => {
  const dish = circle(50, 50, 42);
  const shade = (x) => Math.pow(x / 100, 2);
  return [dish, t.throw(shade, { count: 900, within: dish }).points.map((p) => circle(p, 0.7))];
});
```

:::note
`attempts` is the termination rule. A field that is nearly 0 everywhere makes most throws miss. After that many misses for one point, the throw returns the points it has.
:::

## t.relax()

<include>/_sig/Toolkit.relax.mdx</include>

<AutoTypeTable path="../occlude/src/points.ts" name="RelaxOpts" />

Lloyd relaxation: each point moves to the centroid of its Voronoi cell, weighted by `density` if you give one. The count, the edges and every column stay. It writes no column.

```ts live
import { sketch, circle } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 9 }, (t) => {
  const rough = t.scatter({ spacing: 8 });
  const even = t.relax(rough, { iterations: 6 });
  return [rough.points.map((p) => circle(p, 0.6)), even.points.map((p) => circle(p, 1.4, { pen: 'stabilo-88-blue' }))];
});
```

## t.settle()

<include>/_sig/Toolkit.settle.mdx</include>

<AutoTypeTable path="../occlude/src/points.ts" name="SettleOpts" />

Weighted Linde-Buzo-Gray settling: relaxation with population control. `density` is the demand at a place, 0 to 1. `spacing` is the distance between points in a full-demand area. A point whose cell holds more than one point's share splits in two. `settle` removes a point whose cell holds almost nothing. The count converges to what the density can support. Survivors keep their columns, and each one gets a `demand` column, where 1 is a full share.

```ts live
import { sketch, circle } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 4 }, (t) => {
  const tone = (x, y) => Math.max(0, 1 - Math.hypot(x - 60, (y - 45) * 1.4) / 40);
  const settled = t.settle(t.scatter({ spacing: 5 }), { density: tone, spacing: 3, iterations: 12 });
  return settled.points.map((p) => circle(p, 0.5 + p.demand * 0.6));
});
```

## m.snap()

<include>/_sig/Material.snap.mdx</include>

<AutoTypeTable path="../occlude/src/snap.ts" name="SnapOpts" />

Moves each point to the best of `samples` places tried inside the disc of `radius` around it, judged by the field. A point that is already at that place stays. Edges, columns and row order stay. To seek the least, negate the field.

```ts live
import { sketch, circle, distance } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 7 }, (t) => {
  const ring = (x, y) => -Math.abs(distance([x, y], [50, 50]) - 30);
  const snapped = t.scatter({ spacing: 7 }).snap(ring, { radius: 6 });
  return [circle(50, 50, 30, { pen: 'stabilo-88-blue' }), snapped.points.map((p) => circle(p, 1))];
});
```

## t.quadtree()

<include>/_sig/Toolkit.quadtree.mdx</include>

<AutoTypeTable path="../occlude/src/quadtree.ts" name="QuadtreeOpts" />

Divides the drawable into cells that split where the points are dense, until no cell holds more than `capacity` points. The result is a material of cell walls. A wall meets a bigger cell's wall at a T, so run `planarize()` before `faces()` reads the cells.

```ts live
import { sketch, circle, strokes, polygon, fill, mm, distance } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 3 }, (t) => {
  const tone = (x, y) => Math.max(0, 1 - distance([x, y], [35, 60]) / 40);
  const pts = t.scatter(tone, { spacing: 4 });
  const cells = t.quadtree(pts, { capacity: 4 }).planarize().faces();
  return [strokes(cells.edges), cells.filter((f) => f.area < 20).map((f) => polygon(f, { stroke: false, fill: fill('hatch', { angle: 45, spacing: mm(1.2) }) })), pts.points.map((p) => circle(p, 0.5, { pen: 'stabilo-88-blue' }))];
});
```

## t.voronoi()

<include>/_sig/Toolkit.voronoi.mdx</include>

The Voronoi cells of a set of points, as material. The vertices are the cell corners and the edges are the walls. `faces()` reads the cells. The result knows its sites: `cells.cellOf(site)` is a site's face and `cells.siteOf(face)` a face's site. The cells stop at the drawable. `bounds: { x, y, w, h }` stops them at a box instead. For any other area, cut the result with `t.within`. The cells do not follow a site that moves. Build them again.

```ts live
import { sketch, circle, strokes, polygon, fill, mm } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 5 }, (t) => {
  const sites = t.scatter({ spacing: 14 });
  const cells = t.voronoi(sites);
  const big = cells.faces().filter((f) => f.area > 160);
  return [strokes(cells), big.map((f) => polygon(f, { stroke: false, fill: fill('hatch', { angle: 45, spacing: mm(1.5) }) })), sites.points.map((p) => circle(p, 0.8, { pen: 'stabilo-88-blue' }))];
});
```

## hull()

<include>/_sig/hull.mdx</include>

The outline of a point cloud, as closed contours an area consumer reads. `alpha` sets the largest circle the outline may bite out of the cloud. At `alpha: 0` no circle is too large, nothing is bitten out, and the answer is the convex hull. Raise it and the outline follows the cloud's own hollows. Raise it further and the cloud falls into clumps, each clump with its own contour. Nested contours are holes, read even-odd the way `polygon` reads them. Fewer than three points, or every point on one line, gives no contour at all. Pure: no seed and no paper.

Three canopies over one wood. The thin black line is the convex hull of every leaf, and the green lines are the same leaves at `alpha: 1 / 5`.

```ts live
import { sketch, strokes, hull, circle } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 4 }, (t) => {
  const leaves = [[22, 30], [78, 26], [50, 72]].flatMap(([cx, cy]) =>
    t.times(90, () => [cx + t.gaussian(0, 8.5), cy + t.gaussian(0, 8.5)]));
  return [
    strokes(hull(leaves), { pen: 'pigma-005-black' }),
    strokes(hull(leaves, { alpha: 1 / 5 }), { pen: 'stabilo-88-green' }),
    leaves.map((p) => circle(p, 0.45, { pen: 'pigma-005-black' })),
  ];
});
```
