A sketch is a function that returns shapes. `sketch(config, (t) => tree)` describes it. The engine draws nothing until the sketch renders. The tree can nest arrays to any depth. The engine flattens the tree and draws it in order. It skips a falsy entry, so `condition && shape` includes a shape only when the condition holds.

## sketch()

<include>/_sig/sketch.mdx</include>

The config sets the drawable and the seed. `aspect: [w, h]` fixes the shape of the drawable. The drawable then sits centred on whatever paper renders it. `paper` names the sheet instead. `margin` is an inset from the paper edge. `seed` is a number, a string, or `'url'` to read the studio's `?seed=`. `pens` declares the sketch's pens by name.

```ts live
import { sketch, circle, line } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 12 }, (t) => [
  circle(50, 50, 30),
  t.times(6, (k) => k % 2 === 0 && line(10, 20 + k * 12, 90, 20 + k * 12)),
]);
```

## sketchAsync()

<include>/_sig/sketchAsync.mdx</include>

The same as `sketch`, for a sketch function that uses `await`. Some 3D words, such as `t.hatch`, run a job in the background and return a promise. A sketch that calls them must be a `sketchAsync`.

```ts live
import { sketchAsync, circle } from 'occlude';

export default sketchAsync({ aspect: [1, 1] }, async (t) => {
  const radius = await Promise.resolve(30);
  return circle(50, 50, radius);
});
```

## Units

<include>/_sig/mm.mdx</include>
<include>/_sig/inch.mdx</include>

A bare number is a percentage of the short side of the drawable. On a square drawable both axes run 0 to 100. On a 2:1 drawable the long axis runs to 200. `mm(v)` and `inch(v)` are physical sizes, the same on any paper. Use bare units to compose. Use physical units for what must keep its size on paper: hatch spacing, dot sizes, a wobble. `t.len(v)` converts a physical size to drawable units for arithmetic. Change the paper, and the top row keeps its proportion of the drawable while the bottom row keeps its spacing in millimetres. This page draws on a 180 mm drawable.

```ts live
import { sketch, circle, label, mm } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => [
  label('10 UNITS', 8, 22, 4), t.times(9, (k) => circle(10 + k * 10, 36, 2)),
  label('10 MM', 8, 58, 4), t.times(9, (k) => circle(10 + k * t.len(mm(10)), 72, mm(4), { pen: 'stabilo-88-blue' })),
]);
```

## paper() · pen()

<include>/_sig/paper.mdx</include>
<include>/_sig/pen.mdx</include>

`paper` declares the sheet for the config: a width and a height in physical units, and a colour. `pen` declares a pen from its nib width and colour, for the config's `pens`. The studio's pen library also supplies names, and a sketch can use a library name with no declaration. The first entry of `pens` is the pen for a shape that names none. Without `pens`, that pen is the library's first pen. The examples on this site use four of them: `pigma-005-black` (0.2 mm), `pigma-05-black` (0.45 mm), `stabilo-88-blue` and `stabilo-88-green`.

```ts live
import { sketch, paper, pen, mm, inch, circle } from 'occlude';

export default sketch({ paper: paper({ width: inch(5), height: inch(3) }), pens: { main: pen({ width: mm(0.5), color: '#2457D6' }) }, margin: 8 }, (t) => {
  const b = t.bounds();
  return t.times(9, (k, u) => circle(8 + u * (b.w - 16), b.h / 2, 6, { pen: 'main' }));
});
```

## ui()

<include>/_sig/ui.mdx</include>

Marks a literal as tweakable. In the studio it gets a slider. The slider rewrites the literal in the code, so the tuned sketch saves as seen. Anywhere else it returns its value.

```ts live
import { sketch, circle, ui } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 2 }, (t) => {
  const count = ui(24, { min: 3, max: 80, step: 1 });
  const size = ui(4, { min: 1, max: 12 });
  return t.times(count, () => circle(t.rnd(10, 90), t.rnd(10, 90), size * t.rnd(0.4, 1)));
});
```

## t.probe()

<include>/_sig/Toolkit.probe.mdx</include>

Returns the value and records it under a label. After a render, the studio's controls panel shows the count, the minimum, the mean, the maximum and a histogram for each label. Use it to learn what a field gives before you map it. It changes nothing, and it is free to leave in.

```ts live
import { sketch, circle } from 'occlude';

export default sketch({ aspect: [1, 1], seed: 2 }, (t) => t.grid({ cols: 14, rows: 14 }).map((c) => circle(c.cx, c.cy, 0.5 + 2.5 * t.probe('noise', (t.noise(c.cx / 18, c.cy / 18) + 1) / 2))));
```

## t.bounds() · t.grid()

<include>/_sig/Toolkit.bounds.mdx</include>
<include>/_sig/Toolkit.grid.mdx</include>

`bounds()` is the drawable in the sketch's units: `w`, `h`, `cx`, `cy`. `t.width`, `t.height`, `t.cx` and `t.cy` are the same four numbers, read directly. Read them when a drawing must fill whatever drawable it lands on. `grid({ cols, rows, gap? })` covers the drawable with cells, each `{ x, y, w, h, cx, cy, i, j }`.

```ts live
import { sketch, rect, circle } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const b = t.bounds();
  return [rect(2, 2, b.w - 4, b.h - 4), t.grid({ cols: 6, rows: 6, gap: 3 }).map((c) => circle(c.cx, c.cy, Math.min(c.w, c.h) / 2))];
});
```

## t.hexes() · t.triangles()

<include>/_sig/Toolkit.hexes.mdx</include>
<include>/_sig/Toolkit.triangles.mdx</include>

<AutoTypeTable path="../occlude/src/layout.ts" name="HexOptions" />
<AutoTypeTable path="../occlude/src/layout.ts" name="TriangleOptions" />

Cells that are not rectangles, as ONE material. `grid` answers with records, and these two answer with geometry. `m.faces()` are the cells, and the wall two cells share is one edge. `strokes(m)` draws each wall once, and `sel.adjacent()` answers on the cells. The lattice starts at the drawable's origin, and the drawable edge cuts the outermost cells.

`hexes` takes the centre-to-centre `spacing` of neighbouring cells. `orientation` is `'pointy'` (a vertex at the top of each cell, the default) or `'flat'` (an edge there). Each face carries its axial `i` and `j`.

```ts live
import { sketch, strokes, polygon, fill, mm } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const cells = t.hexes({ spacing: mm(15), orientation: 'flat', gap: mm(1.6) });
  return cells.faces().faces.map((f) =>
    (f.i + f.j) % 2 === 0
      ? polygon(f, { fill: fill('hatch', { angle: 90, spacing: mm(0.8) }) })
      : strokes(f.boundaryEdges.extract()),
  );
});
```

`triangles` takes the `size` of one side. Each face carries its row `j` and its place `i` along that row. An even `i` points up, and an odd one points down. `gap` shrinks every cell about its own centre, in both words. A gapped cell touches nothing, so it shares nothing. A spacing of zero, or a gap that eats the cell, draws nothing.

```ts live
import { sketch, strokes, polygon, fill, mm } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => {
  const cells = t.triangles({ size: mm(20) });
  const mod = (n, k) => ((n % k) + k) % k;
  return [
    cells.faces().faces.map((f) => mod(f.i + 2 * f.j, 3) === 1
      && polygon(f, { fill: fill('hatch', { angle: 30 + 60 * mod(f.i, 2), spacing: mm(1.1) }) })),
    strokes(cells),
  ];
});
```

## t.times() · t.range()

<include>/_sig/Toolkit.times.mdx</include>
<include>/_sig/Toolkit.range.mdx</include>

`times(n, fn)` calls `fn(k, u)` n times and returns the results. `k` is the index and `u` runs from 0 to 1 across the run. `range(n)` and `range(a, b, step?)` give integer sequences. Both refuse a runaway count.

```ts live
import { sketch, line } from 'occlude';

export default sketch({ aspect: [1, 1] }, (t) => [t.times(16, (k, u) => line(10, 10 + u * 80, 90, 50)), t.range(0, 100, 10).map((x) => line(x, 92, x, 96, { pen: 'stabilo-88-blue' }))]);
```

## space · projection

The geometry a sketch draws in is a frame setting. `space` names the metric and `projection` names the chart the sheet is drawn in. Both live on the config beside `paper` and `pens`. They have a page of their own: [Reference: Geometry](/docs/reference/geometry).
